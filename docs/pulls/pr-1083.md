## Summary

Adds a read-only 3D preview pane to `GeometryImportDialog` (OBJ/PLY/STL/GLB) so the pre-import mesh — and its repaired counterpart — can be inspected in 3D before the explicit インポート confirmation. A `QSplitter` splits the dialog into the existing scrollable declaration/repair column and a PyVista `QtInteractor` pane showing origin marker, axes, grid, dimensioned bbox, and defect-focus markers.

The preview is a **render-only adapter**: a new Qt-free `geometry_import_preview` module resolves a drawable `ImportPreviewScene` from the already-computed `RawVisualMesh` / `RawMeshDiagnosticResult` / `RepairedRawMesh` — no re-import, no QA/repair/solver-readiness recomputation, no new authority. `resolve_preview_declaration` reuses `make_mesh_import_authority` + `mesh_import_scene_transform`, so previewed vertices are identical to what the commit paths produce (asserted vertex-for-vertex in tests). Undeclared unit → raw source coordinates with a 単位未宣言 notice; unresolved axis convention → unrotated render with an explicit notice. Nothing is estimated or forced.

- 元のメッシュ / 修復済みメッシュ / 修復差分 view combo — repaired/diff items stay disabled until `_preview_repair()` produces a `RepairedRawMesh`.
- Diff fates are reconstructed from the actual repair lineage of the same mesh id (`source_raw_mesh_id` + `source_raw_mesh_semantic_hash` verified): `kept`/`flipped` by position-multiset match, `removed` when no surviving entry exists under the source primitive, `moved` only when leftover counts match, `unknown` whenever the lineage is ambiguous — never guessed.
- Defect focus: per-issue-code focus combo driven by `MeshHealthSummary.issues`; positions re-derived only for codes derivable in one pass (open/non-manifold edge midpoints, duplicate/sliver/tiny centroids); `inverted_normal`/`overlapping_face` report 判定不能 honestly.
- Bounded render: deterministic stride decimation to `PREVIEW_MAX_FACES=200k` (kept indices keep fate colors exact); display-only, never feeds import data. `unsupported_geometry` (empty/non-finite) is distinguished from VTK/GL render failures; `done()` releases GL resources.
