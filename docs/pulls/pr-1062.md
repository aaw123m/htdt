## Summary

`RoomViewport3D` gains a read-only spatial-campaign overlay: every `CampaignPoint` of a `SpatialCampaignDesign` renders a marker at its exact declared XYZ on the CURRENT `SceneRevision` (resolved via `domain_to_render`), with marker SHAPE carrying the primary role and a progress ring carrying only persisted executor state.

- `room_campaign_overlay.py` (new, Qt-free): `resolve_campaign_overlay` + `RoomCampaignOverlayController`. Role→glyph: reference→cone, optimization→sphere, **spatial_holdout→cube** (priority-ordered — a holdout point can never borrow the optimization sphere/color), repeatability→disc, diagnostic→wireframe sphere, boundary→cylinder, standards→diamond; ASCII legend (REF/OPT/HOLDOUT/REP/DIAG/BND/STD).
- Progress rings are fed ONLY by persisted authority: latest runner plan's `cell_states` joined to design points via `acoustic_reference_position` within `duplicate_tolerance_m`, plus `CampaignPointBinding` rows. No run → explicit "no executor run (unknown)". Vocabulary: 測定済み/要対応/取り込み済/未測定/スキップ済み/セル未結合/不明/失効.
- Staleness per #999/#1009: design pinned to a superseded revision → `lapsed`, markers dimmed wireframe, all progress/validity claims withheld.
- Validity comes only from declared `ListeningAreaSpec` zones (excluded/challenge/outside), `RoomPrism` bounds, and `head_height_range_m`; underivable → 不明.
- Deep link: campaign checklist 「3Dで測定位置を確認」button → `WorkspaceDeepLink(kind=MEASUREMENT_CAMPAIGN)` carrying the selected cell's `target_entity_id` (bounded marker↔cell sync) or the newest `design_id`; `focus_campaign_overlay` arms the overlay, switches to the acoustics context, and re-renders. Marker→cell sync bounded by the position join — no match surfaces a notice.
- Actors: `campaign-overlay-` prefix in `_OVERLAY_ACTOR_PREFIXES`, `pickable=False` everywhere, count honesty 表示x/全体y.

Tests: `backend/tests/test_issue_1006_campaign_3d.py` — 15 tests (exact XYZ, role legend, holdout separation, progress honesty incl. no-run, lapsed staleness, bounded focus, mount focus_kinds, button deep link, 260px narrow + DPI-200 + UIA).
