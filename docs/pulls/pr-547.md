## Summary

Issue #534 local/offline presentation mode — PM10–PM40 delivered as bounded, persisted authorities plus a read-only プレゼン workspace. Everything derives from exact design authority (pinned `SceneRevision` + content hash, optional `SystemVariant`/`DesignComparisonSet` pins); nothing mocks renders or mutates engineering state.

- **PM10** `cad_presentation_session.py`: `PresentationSession` (pins `scene_revision_id`+`scene_content_hash`, optional variant + comparison-set pins, `status_label`, sealed `session_sha256`), `PresentationViewpoint` (named, serializable, replayable `RoomCameraState` + section plane + hidden ids + focus entity), ordered `PresentationSection`s, `PresentationAnnotation`s.
- **PM20** same module + `cad_presentation_repository.py`: `SynchronizedReviewBinding` (two sides: a session OR a comparison-set alternative, exact-sha pins, `lockstep_viewpoint`), ordinal `synchronized_steps()` pairing ('pinned'/'fit'/'unavailable'), `PresentationProposal` (`variant_candidate` requires a variant pin; `annotation_only` forbids it). Decisions/comments reuse `DesignDecisionRecord`/`ReviewNote` — no parallel authority.
- **PM30** `cad_review_package.py`: deterministic offline package — `viewer.html` (self-contained JA, no network refs), per-viewpoint pinned + yaw-stepped PNG frames via `OffscreenSceneRenderer` (per-frame `pv.Plotter(off_screen=True)`, `camera.Yaw(deg)` look-around), SVG drawing sheets, canonical `semantic.json`, sealed `ReviewPackageManifest` with capability rows (`perspective_renders`/`equirectangular_panorama`/`yaw_stepped_renders`/`svg_drawings`/`offline_viewer`) and security rows (relative-paths-only, no local paths/secrets). Equirectangular is declared `unavailable` — `vtkPanoramicProjectionPass` renders empty on this box's Mesa/dzn GL stack — with yaw-stepped perspective declared as the surrogate. `verify_review_package` re-hashes every entry.
- **PM40** `cad_proposal_package.py`: `proposal.html` assembled from `build_installation_output` + `generate_drawing_set` (inline SVG) + `evaluate_comparison_set` + `DesignDecisionRecord`s; `installation-output.json` + sealed manifest pinning `installation_output_sha256`; `verify_proposal_package` re-hashes entries.
- **Persistence**: 3 new payload tables (`cad_presentation_sessions`, `_proposals`, `_sync_bindings`) registered in `NATIVE_BASELINE_DDL`/`NATIVE_SCHEMA_TABLES`, `native_row_integrity._UNBOUND_PAYLOAD_TABLES`, and `native_authority_audit` replay probes (`verify_persisted_session`/`_proposal`/`_binding` re-run save-time invariants). Also repairs two pre-existing registry gaps (`cad_acoustic_geometry_derivations`, `cad_solver_capability_manifests`) that failed `assert_row_integrity_registry_complete` on main.
