## Summary

Issue #976 (P0): Room UI に「高度な形状」セクションを追加し、傾斜天井・下がり天井・段床・腰壁・隣接領域を Room UI からセマンティック編集可能にした。`RoomAuthoringModel`/`compile_room_authoring_to_r120` が唯一のセマンティック権威であり、UI固有のgeometryフォーマットは存在しない — パネルは spec を書き、compiler が R120 音響形状を生成し、viewport は編成済み面を描画する。

**Persistence** — `SceneDocument.room_authoring` (optional, `schema_version >= 6`)。既存ドキュメントの canonical serialization は不変 → 全 pre-existing revision hash 保持。room re-embed は `authoring.room == document.room` で validation され、`replace_room`/`replace_room_topology` は `rebind_room_authoring` で再検証 — 壊れる編集 (e.g. 隣接室参照の shared edge が消える) はコミット前に `RoomAuthoringError` で拒否、原本不変。

**UI** — 部屋形状パネルの段階開示「高度な形状」: 5種類のリスト + 数値インスペクタ + 追加/適用/削除 + フィールド編集時のゴーストプレビュー (amber)。`(kind, primitive_id)` が 3D選択 ⇔ パネル selector ⇔ 保存revision を同一IDで貫く。

**Fail-closed** — `validate_room_authoring_model(model, wall_topology=…)`: footprint外、primitive重複 (riser/soffit/wall)、局所傾斜天井とのクリアランス、腰壁天井線、shared edge 重複、隣接室重複、開口高さ、topology opening 衝突 → 全て `geometry_invalid` で対象名付き reject。material binding が未対応の面は `unsupported` warning で正直に宣言 (原本はコミットする)。

**Hooks** — authoring差分 → 既存 `room_geometry` SceneChange (geometry + material_boundary axes) → #964 `build_revalidation_queue` で stale 遷移、追加 authority なし。

**Viewport** — `render_document` が `authoring-surface-{key}` actors (riser/soffit/wall flank/lintel/portal/region) を room-shell 後に描画; wireframe も `ceiling_height_at` で傾斜に追従。edit mode は primitive outline を描画してクリック選択可能。
