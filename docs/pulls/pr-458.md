## Summary

REV27 UI-shell/Qt-lifecycle audit fixes — six contract defects found reading every shell-layer file end-to-end. Each ships a regression test; no design smells touched (they're in the review report).

**Defects fixed**

1. `application_pages._populate_detail` — gate detail fields never rendered. The code derived the detail attribute as `key[:-5] + '_detail'`, producing `bundle_valid_detail` / `dependency__detail` / `alignment__detail` / `evidence_conflict__detail` — none exist on `CaptureInboxItem` (real fields: `validation_detail`, `dependency_detail`, `alignment_detail`, `evidence_conflict_detail`). Added `_INBOX_GATE_DETAIL_FIELDS` map; every gate detail was silently dropped until now.
2. `workflow_application._export_analysis_bundle` — the only bundle-pool entry point missing the `_bundle_busy` guard its siblings (`_export_project_bundle`, `_import_project_bundle`) carry; a re-entry would double-book the pool and corrupt the busy/status/close contract.
3. `workflow_application` — five project-menu handlers crashed with `AttributeError` when a restore lands on zero projects (`project_entry=None`, set by `_rebind_project_identity_after_restore`). Added `_require_bound_project()` (status hint + return) for rename/duplicate/export/deliverables, and None-safe filters for the open/archive pickers (all entries listed when nothing is bound).
4. `workflow_application._restore_rebind_note` — `f'アクティブプロジェクト: {self.document_id}'` interpolated the raw uuid into user-facing text (document_id is `str(uuid4())`, not a name). Now uses `project_entry.display_name`, matching the title bar and context-bar chip.
5. `command_registry.execute` — a deep-link handler exception bypassed `error_handler` and escaped to excepthook, while executor failures route through it. Same try/except contract now wraps the navigation dispatch; lazy shell binding (re-fetch after navigation) is preserved.
6. `workflow_help.HelpDialog.topic` — `関連操作:` rendered raw command ids (`navigation.room`). New optional `command_registry` parameter resolves display names (`部屋`), falling back to the id for unregistered commands; the composition call site passes `self.registry`.

**Tests**: `test_inbox_detail_renders_gate_detail_fields`, `test_analysis_export_refuses_during_bundle_job`, `test_project_menu_entries_survive_unbound_project_entry`, `test_restore_rebind_note_shows_display_name`, `test_deep_link_handler_failure_reaches_error_handler`, `test_topic_related_commands_render_display_names`.

Scoped pytest green: the four touched test files plus composition-adjacent suites (accessible_labels, ui_workflows, workflow_shell, navigation_model, help_registry, palette_search, project_switch_lifecycle, rev24_uxflow, ia_v2_integration, capture_receiver_composition) — 138 tests, zero failures (one known xdist/Qt teardown flake re-ran green at `-n 0`).
