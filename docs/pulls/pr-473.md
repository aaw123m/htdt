## Summary

Dynamic end-to-end verification — a real app-emitted bundle (sealed + finalized by HTDT-Capture, then frozen) — surfaced **receiver-side contract mismatches** that made the production ingestion path reject the bundle at five successive layers. Each is fixed; the verified bundle now ingests cleanly end-to-end.

**Root causes fixed**
- `RESERVED_PATH_METADATA["roomplan/captured-room-metadata.json"]` expected `producer=roomplan_builder`/`role=derived` but the app emits `capture_app`/`canonical` (with `source_refs`) — corrected to match the emitter.
- `_validate_quality_document` rejected the `usable_mesh_anchor_count` / `usable_depth_sample_count` fields the quality doc emits — now optional, shape-validated when present.
- `_load_roomplan_capture_metadata` rejected the lineage fields the app appends to the external roomplan metadata family (`processed_byte_count`, `processed_serialization_format`, `raw_byte_count`, `raw_serialization_format`, `runtime`) — now optional with per-key shape validation; `CaptureRoomPlanCaptureMetadata` gained the matching optional fields so `extra=forbid` stops rejecting them.
- `_require_schema` pinned every doc family to `1.0.0`, so the emitted `entities@1.3.0` / `measurements@1.1.0` failed as `unsupported_newer` — now consults `SUPPORTED_DOCUMENT_VERSIONS`.
- RoomPlan record/metadata equality compared `model_dump` output (explicit `null` for unset optionals) against rederived rows (which omit unset keys) — now dumps with `exclude_unset=True`.

**Contract mirror sync** (parity with the app repo's `schemas/capture-bundle-v1`): regenerated `support-matrix.json` (entities emitted/read → `1.3.0`), expanded `capture-advisory.schema.json` to cover every emitted section, added `entities-1.3.0.schema.json`.

**Verified** — real finalized bundle: `FrozenBundle → build_ingestion_plan → CaptureIngestionPlan.model_validate → _validate_source_payload_contract → commit` now completes: 28 source evidence + 2 roomplan records + 1 mesh binding + 5 authority records, `quality_state='validated'`. All `tests/test_capture*.py` (~340 tests) pass.
