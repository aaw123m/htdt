## Summary

UI half of the REV59 device-verification track (todo #21): a new app-scope destination **検証ウィザード** (`ApplicationDestinationId.VERIFICATION`) that lets a zero-knowledge user verify open issues — pick an issue, run its automated checks with one button, follow plain-Japanese instructions for the manual checks, and commit evidence — while every transition seals into the `cad_manifest_gates`/`cad_gate_run_results` ledger landed by REV59-CLOSEAUX.

- `verification_wizard.py` (Qt-free): `load_wizard_issues` parses `issue_verification_manifest.yaml` into picker rows (duplicate `issue:` keys merge under one `issue_ref`, matching how `evaluate_issue_verdict` groups sealed gates); `resolve_check_argv`/`run_check` reproduce `verify_open_issues.py`'s runner contract headless (pytest `-q -p no:warnings --tb=short -n <workers>` + isolated `--basetemp`, `{python}`/`{work_dir}`/`{report_dir}` substitution, per-check timeout with a process-tree sweep); `ManifestGateStore` seals gates and commits `GateRunResult`s on `cad-scenes.sqlite3` under `document_id='application'`, binding each run's log sha256 and each manual evidence bundle (note + file digests → bundle JSON → `AuthorityRef`).
- `verification_wizard_page.py`: `VerificationWizardPage` — issue picker with verdict suffixes, check detail panel (`自動` runs in a `QThread` worker; `実機` shows description + generated `RequiredCell` checklist + attach/attestation → `evidence_committed`), verdict banner from `MANIFEST_VERDICT_LABELS`. Worker detach-on-close mirrors `acceptance_page.py`.
- Registration: `WorkflowRegistration` + lazy import + `navigation.verification` palette command.

**Bridge fix required to consume main:** `load_manifest_gates` read `check.get('argv')` but the real manifest's script check uses `command:` — sealing the real file raised "a script gate needs an argv list" (also breaking `commit_manifest_verification.py`). Now accepts `command` (preferred) with `argv` fallback.
