## Summary

REV35-R150 slice (a): bounded arbitrary-order specular reflection chains on the multi-Portal (cross-region) lane of the deterministic GA solver — the first step of the documented R150 decomposition (`docs/IMPLEMENTATION_ROADMAP.md`: "3回以上のcross-region reflection order" was outstanding).

The slice ships as a new parallel engine version on the `HTDT_PORTAL_FIRST_ORDER_ENGINE_ID` family rather than a bump of the v2 specular-graph ref, so every order ≤2 artifact stays byte-identical and old digests still revalidate:

- `HTDT_PORTAL_SPECULAR_CHAIN_ENGINE_VERSION = '3'` + `HTDT_PORTAL_SPECULAR_CHAIN_IMPLEMENTATION_REF` declaring `maximum_reflection_order_range: [3, 4]`, `construction: 'exact_bounded_directed_portal_graph_interleaved_bounded_order_specular_reflection_chain'`, same Portal-graph bounds as v2 (crossings 1–16, 4096 search states, `bounded_exact_finite_triangles_only` contact, `coherent_phase: 'delegated_to_r150_path_response_authority'`).
- `maximum_reflection_order` literal extended `0..4` on `DeterministicGaConfiguration`/`DeterministicGaExecutionInput`; order ≥3 requires `general_planar_multi_region_portal_v1` (config builder + compile gates; single-region planar lane stays ≤2).
- Fail-closed ref matching: v2 ref with order >2 → `UNSUPPORTED_PORTAL_TOPOLOGY`; chain ref with order <3 → `UNSUPPORTED_PORTAL_TOPOLOGY`.
- `_append_portal_graph_reflections` enumerates `product(ordered_planes, repeat=K)` for K=3..4 per simple directed region path, with per-(source,receiver) eval caching keyed by surface-id tuple and `(surface_ids, decision, reason)` rejection dedup. Region slots per reflection position are filtered to nondecreasing tuples; `assemble_chain` (already K-agnostic) resolves per-leg portal crossings, region membership, and occlusion clearance.
- `_higher_order_reflection_points` generalizes the order-2 image-chain walk-back (`images[i]` mirrored through `planes[0..i-1]`, then intersect plane `i` at each step back).
- Rejection rules generalized, no fabricated geometry: immediate same-surface repeats (degenerate) and adjacent coincident planes rejected; non-adjacent repeats (e.g. ceiling→floor→ceiling across regions) are valid and emitted. Per-point finite-triangle extent, shared-edge/multi-surface contact ambiguity, leg-vs-plane graze ambiguity (each leg `i` vs plane indices `max(0,i-1)..min(K,i+1)`), zero-length segments, and unresolvable material authority all fail closed with distinct reasons.
- New `path_scope` values `multi_portal_third_order_specular`/`multi_portal_fourth_order_specular` (+ JA labels マルチポータル3次鏡面 / 4次鏡面); artifact reopen regenerates through the v3 engine via `_ENGINE_SOLVER_REF_BY_ID_VERSION`.
