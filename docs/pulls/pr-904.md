## Summary

Implements #877: a guided, resumable, evidence-sealed calibration wizard that automates all software-controlled work and prompts only for physical actions. Three lanes:

- `interface_loopback` (A): exact I/O path binding → loopback-cable prompt → #869 engine preflight → native sweep → transfer derivation → quality gate → sealed `combined_dac_analog_adc_loopback` calibration + correction evaluation.
- `spl_reference_check` (B): instrument + sealed `CadSplCheckAcceptanceProfile` → record-only window → `evaluate_reference_check` (level/frequency/stability/SNR/duration) → sealed #611 `CadInstrumentVerificationCheck` + `InstrumentFitnessState` update.
- `campaign_checks` (C): sealed `CadCampaignCheckPlan` → pre-use field checks → campaign window → post-use checks → gate evaluation that blocks dependent evidence when policy requires.

## Machine — sealed log is the sole resume authority

`CadCalibrationWizardRun` + append-only `CadCalibrationWizardTransition` events; `derive_wizard_state` folds the same log to the same state on restart. `wizard_transition` rejects every (lane, stage, event) triple outside `_ADVANCE_RULES`; `succeeded=False` lands `blocked`/`failed`. `next_permitted_events`/`pending_physical_instruction` drive the UI's menu — physical prompts use only the sealed instruction vocabulary. `retry_step` regresses to `_RETRY_TARGET`; no-op retries, retries during device disconnect, and events at wrong stages are rejected (fail closed). Clipping/low-SNR/unstable references never report a pass.

## Scene sealing — schema v101

`cad_calibration_wizard_runs`, `cad_calibration_wizard_transitions`, `cad_spl_check_acceptance_profiles`, `cad_campaign_check_plans` via `CadCalibrationWizardRepository` (bound-column re-validation on read, content-hash conflict detection). Wired into `cad_schema` (`_migrate_100_to_101` — renumbered from v100 after sibling #876 landed), `cad_schema_ddl`, `native_row_integrity`, `native_authority_audit` (`_RepositoryChain` + `_ReplayProbe`s).

## UI — `calibration_wizard` context

Reached from the calibration page's guide card (same pattern as the acquisition page, not the context rail). Lane picker → bindings → run → physical-prompt-only guidance → confirm/retry/cancel. Honest surfaces: WASAPI stub enumerates empty, missing scene DB states "session-only" persistence, run refuses to start with unbound devices.
