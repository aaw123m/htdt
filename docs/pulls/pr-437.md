## Summary

REV24-PERFACC (accuracy + compute-load track): eliminates redundant work in the acoustic numerical stack without changing physical semantics.

**Repository read/save paths** (`cad_acoustic_snapshot_repository`, `cad_acoustic_solver_dispatch_repository`, `cad_geometric_acoustics_adapter`, `cad_late_field_energy`, `acoustic_pffdtd_polyhedral_geometry`, `cad_acoustic_treatment_comparison`):

- `_validate*` chains re-loaded and re-verified the same authorities nested inside each other (artifact → request/dispatch → snapshot; each layer re-running `_validate_snapshot` including R110 model file reads). Now `get_prediction_request(..., _validated_snapshot=...)` and `get_dispatch(..., _validated_snapshot=..., _validated_request=...)` reuse an authority already validated in the same call when its identity matches (`snapshot_id` / `request_id`), falling back to the normal fetch path on mismatch — fail-closed verification preserved. `_validate_execution_input` emits its resolved bundle via a `_resolved_out` dict so the artifact `_validate` skips a second `_validated_snapshot`→`get_snapshot` pass.
- `save*()` on the repositories previously re-validated the `persisted` row even when byte-equal to the candidate; equal-semantics fast path now returns `persisted` directly.

**Deterministic GA core / multi-Portal graph** (`cad_geometric_acoustics_adapter`, `cad_geometric_acoustics_portal`):

- `_occluder_triangles(compiled)` built once per execution, shared by `_segment_blocked` instead of re-collecting `(surface_id, v0, v1, v2)` rows per segment query.
- `first_order_plane_evals` / `second_order_pair_evals` memoize path-independent plane and ordered plane-pair evaluations (`_mirror_source`, `_reflection_point`, `_point_on_surface`, `_point_has_other_surface_contact`, `_segment_grazes_plane`, material resolution, incidence) across topology paths — previously recomputed once per enumerated path (up to 16 crossings).
- `region_shell_cache` keyed by `region_id` avoids rebuilding `_region_shell_triangles` per segment; `region_membership_with_portal_caps` / `region_segment_membership_with_portal_caps` accept `shell_triangles=` to reuse it (segment fn went from 4 shell builds to 1).
- `topology_paths_cache` keyed `(src_region, rcv_region)` caches `find_topology_paths` results-or-ValueError; `portal_aperture_by_id` / `portal_region_by_id` hoisted out of the receiver loop.
- Identical `(surface_ids, decision, reason)` rejection records are now emitted once via `emitted_rejections` dedup instead of once per enumerated path.

**Late field** (`cad_late_field_energy`):

- `_segment_blocked_ignoring_triangles(..., occluder_records=)` iterates precomputed rows built once in `execute_late_field_energy` (was rebuilt per segment call).
- `source_patch_cache` per source caches the centroid/patch_area/vertices (or reject decision) of each scattering patch keyed by `interaction_key` — previously re-derived per receiver-side candidate.
