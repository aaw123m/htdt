## Summary

Read-only 3D preview of **issued** `TreatmentFabricationPackage`s — the sealed authority `cad_treatment_fabrication.py` already produces — reachable from the Room acoustics tab. Multilayer panels and 1D QRD assemblies render in the viewport with cross-section and exploded views; nothing is recomputed, nothing feeds back into the acoustic boundary model.

- `fabrication_preview.py` — Qt-free resolver following the #999/#1009 discipline: `FabricationPreviewController.arm(package)` accepts only sealed packages and `resolve()` re-pins `(head.revision_id, head.content_hash, package_sha256, …)` every render, so a revision swap or re-issue can never leave stale geometry. Panel parts stack in `package.parts` order sharing the report's P-numbers; the air gap is drawn as a `derived`/`unspecified` wireframe (`overall_depth − Σ part depth`, never a cut part). QRD fins are mapped back to their depth-grouped parts by the generator's own rule (`fin j = max(adjacent wells)`), and well labels are validated 1:1 against `well_table` (`row.well_index == i`). Unsupported families (`qrd_2d`, freeform) return `supported=False` for an honest table fallback — no forced 3D.
- Mount orientation/clearance draws as REFERENCE geometry **only** while a canonical `AcousticTreatmentPlacement` binds the definition to the current head (binding `exact` + derivable footprint); otherwise a neutral anchor + explicit notice.
- `room_viewport.py` — new `'fabrication-'` entry in `_OVERLAY_ACTOR_PREFIXES`; `render_fabrication_preview` draws non-pickable oriented `pv.Cube` parts, section clip + contour lines, part labels, REF mount ring + clearance envelope, ASCII-only status text (JA lives in `summary_ja` for Qt).
- `room_fabrication_panel.py` — non-modal `FabricationPreviewDialog` in the 音響処理 tab: issues the package from an explicit `FabricationSpec` (unchecked tolerances stay `unspecified`), mirrors parts/cut-list/well tables 1:1, row selection highlights the exact cut-list entry with material/tolerance/quantity, and exports `build_fabrication_report` — the same numbering/dimensions/counts the preview draws. Closing disarms and sweeps every `fabrication-` actor.
- `docs/issues/issue-1008-fab-preview.md` — design doc; `test_issue_1008_fab_preview.py` — 13 tests (resolver parity, canonical/lapsed placement, selection→cut-list detail, report parity, actor lifecycle, dialog signals).

Out of scope per issue: nesting optimization, structural certification, CNC export, absorption/scattering evaluation (different authority — surfaced as 設計値由来 in viewport, panel, and report).
