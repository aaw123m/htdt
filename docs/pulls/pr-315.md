## Summary

First frontend pass (rounds 1–2 covered only the Python backend). Verified findings, applied small fixes, and wrote the full report to `docs/reviews/round3-frontend.md`. No frontend test runner exists (`package.json` has only `build`/`dev`/`preview`), so verification is `tsc --noEmit` + `vite build` — both clean.

Key changes:

- **`api()` unreadable 422s**: FastAPI returns `detail` as a *list* of `{loc, msg, type}`; the wrapper typed it `string`, producing garbage error text. `describeDetail()` now normalizes string/array/object detail into a readable message — prerequisite for all the client-validation work below to be observable.
- **Race conditions**: monotonic `useRef` sequence guards on `reloadProjectData` (App), `loadProject` (MeasurementSessions), `reloadConstraintSets` (PlacementConstraints), `reload`/`generate` (SearchSpace), `preview` (RewReadonly), and `chooseMeasurementFile` — last-request-wins instead of last-response-wins; `cancelled` flags on the `projectId` effects in ComparisonReports/PlacementOverview/RewReadonly.
- **`PanelErrorBoundary`** (new `ErrorBoundary.tsx`): each of the five root panels is wrapped independently — previously one render error unmounted the whole app.
- **Client validation mirroring backend rules** (fail fast instead of 422): room dims `>0`, mic sample rate integer, comparison bands `low<high`, acoustics `max_hz≤2000` + `250<speed<400`, feature band `0<low<high≤2000` + prominence `(0,30]`, and all `placement_constraints.py` validators (`boundPair` for min/max presence/ordering/non-negativity, `entity_a≠entity_b`, `tolerance≥0`, `movement_budget≥0`).
- **Small consistency fixes**: shared `parseList` in `api.ts`; one `<main>` landmark (supplemental panels → `<div>`); `usePlot` memoizes `data`/`layout` so `Plotly.react` no longer re-runs every render, catches its rejection, and purges the captured node; file `accept` lists now match the importer (`.txt,.csv,.dat,.frd`).

Deferred (in report): keyboard-inaccessible SVG sketch tools (`PolygonSketch`, `WallEdgePicker`), polygon-room click clamping to bbox instead of footprint, placeholder-only speaker input labels, and the backend SPA catchall returning `index.html` for `/api/*` typos.

Verified clean: no XSS sinks, no duplicated fetch wrappers, no listener/timer leaks, no `any` casts; contract spot-checks (contexts, comparisons, readiness, acoustics, REW, constraint sets) all match the pydantic models.
