## Summary

Per-seat speaker coverage markers on the 3D CAD view for Issue #1001 — read-only discrete evidence spheres/labels at each sealed `receiver_reference_position_m`, resolved exclusively through `CadCoverageRepository` (the only trusted entry; it replays and verifies scene revision/content hash, variant, equipment and directivity bindings). No values are recomputed in the UI and there is no smooth interpolation between seats (#755 stays out of scope).

**New modules**
- `htdt.room_coverage_overlay` — Qt-free `resolve_coverage_overlay()` → `CoverageOverlayScene` (markers, rays, seat rows, legend, notices, per-seat A/B delta, provenance, selector options marked `[履歴]`) plus `RoomSeatCoverageOverlayController`, deliberately uncached so a scene edit / new comparison run / selector change can never leave a superseded marker on screen.
- `htdt.room_seat_coverage_panel` — the 「カバレッジ表示」 panel in the placement layout: evaluation/variant selector, frequency combo (aggregate + exact requested grid only), quantity combo (relative directivity level / off-axis loss / eligibility gate), baseline combo for A/B, seat table, detail card (ear position, angles, support states, provenance, remediation hints), legend chips, fixed 「幾何方向のみ」 disclaimer.
- `room_viewport.py` — `coverage-overlay-` prefix in `_OVERLAY_ACTOR_PREFIXES` (swept every re-render), `render_coverage_overlay`/`clear_coverage_overlay`, `pickable=False` actors, ASCII-only viewport text (Mesa/.ttc constraint); JA lives in the Qt panel.
- `room_workspace.py` — repository wiring (single shared sqlite path), render-pass composition gated to placement/acoustics contexts while the acoustics overlay is on, and two-way pin↔table selection sync via stable `seat_entity_id`.

**Honesty rules enforced**
- Verbatim `relative_level_db` / `off_axis_loss_db` / aggregate scalars on a fixed 5-band colour scale; `coverage_pass` undecided is its own state — never drawn as FAIL or 0 dB; unsupported/missing results render grey wireframe with the sealed `reason`.
- Evaluations pinned to a superseded scene revision → `historical` (stale-violet wireframe markers, labels/rays/Δ withheld); failed binding replay, unknown evaluation id or off-grid frequency → `blocked` (nothing drawn). Seat ids that no longer name an entity on the current head are never re-mapped.
- Speaker→seat rays exist only while `source_acoustic_axis` is evidence-determined and are labelled geometric direction only — occlusion is explicitly not evaluated; design-vs-observed aim mismatch surfaces as a notice.
- A/B deltas are gated to same scene revision + content hash, same aggregation mode or same requested frequency in the baseline's own grid, and byte-identical `receiver_reference_position_m` per seat — per-seat arithmetic on sealed aggregates, no all-seat-mean claim.
- Priority roles (required/diagnostic) come from `priority_aggregates` or a `CadSeatPriorityProfileRepository` profile bound to the evaluation's exact revision — shown in the legend, never standing in for all seats.

**Tests**: `backend/tests/test_issue_1001_seat_coverage.py` — 29 tests covering verbatim values at exact ear positions (3-seat), one-marker-per-seat at 10/100 seats, unknown-vs-fail honesty, stale/historical/blocked paths, A/B gating, actor teardown, panel selection sync, and workspace-level toggle→draw→clear→historical. Adjacent suites (`test_cad_coverage`, `test_issue_1005`, `test_issue_1006`, `test_issue_999`, `test_room_viewport_semantics`, `test_room_cadux`) all green.
