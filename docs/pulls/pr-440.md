## Summary

REV24-FEATURE (#434) verified that the solver stack's newest outputs — `cad_late_field_*` late-energy path contributions, `multi_portal_*_specular` deterministic path scopes, R160 stitching provenance/LateEnergyDecay, R170B provider surfaces — are persisted and audited but never surface to the user. This PR adds the promised read-only diagnostics surface over them: a **solver-output ledger** dialog mounted on the Support page next to the authority inspector (the codebase's existing diagnostics pattern — no new navigation concept).

Two pieces:

- `solver_output_ledger.build_solver_output_ledger(connection, document_id)` — a read-only projection over the 19 solver-stack tables. Each row becomes a `SolverArtifactEntry` with `binding` taken from the same classification `native_authority_audit.audit_table_modes()` reports (`replay_canonical`/`evidence_bytes` → `bound`; `structural_only` → `unbound`), plus kind, observables, produced-by, provenance/capability refs, item counts, and honest state flags. Scene-revision linkage resolves through three paths: direct columns (`scene_revision_id`, snapshot/compiled-geometry joins), payload-declared refs (R160 decay pins `deterministic_path_artifact_ref.authority_id`, stitched responses pin `exact_r130_result.result_id`), and reverse references (adapters ← dispatch bindings, policies ← hybrid results, providers ← `r160_artifact_id`, bindings/objectives ← `provider_id`). Rows resolving to no revision of the document are `link_state='unresolved'` (the orphaned payloads); rows whose `payload_json` fails to parse are `payload_state='unreadable'` with all payload-derived fields empty — nothing is fabricated.
- `solver_output_diagnostics_ui.SolverOutputDiagnosticsDialog` — revision-filtered table （種別 / 観測量・スコープ / 生成元 / 検証 / 記録時刻） plus a detail form (artifact ID, provenance, capability+item count, hash, payload/link state with `SemanticState.WARNING` on honest-failure states). All user-facing strings go through `_*_LABELS` maps (19 kinds, path scopes, observables, capability states, domains) — raw enum/table names never reach the UI. Empty states are honest Japanese sentences; a `（リビジョン未解決）` filter bucket appears only when orphaned rows exist. Read-only: the only action is row selection; no write paths.

Mount: `WorkflowApplicationComposition._open_solver_diagnostics` builds the ledger at open time (projection never persisted) and is wired into `SupportPage` beside 権威グラフを開く via the existing optional-callback button pattern.
