**Layer shape**



- `room_operational_clearance.build_operational_clearance_preview(document, enabled_kinds=…)` resolves each `OperationalZone` to the exact `operational_zone_footprint` polygon plus conflict render items derived solely from `operational_clearance_conflicts` (clash region = intersection / room-difference, plus the other side's own geometry).

- `RoomViewport3D.render_operational_clearance_overlay` draws `opclear-*` non-pickable actors: kind-colored floor fills + outlines (開閉/リクライニング/引出し/サービス/回転), a faint prism only for zones with declared `height_max_m`, red clash regions + dual-side outlines (conflicting entity footprint / other zone / room-boundary segment + contact points), dim wireframe UNKNOWN beads for unevaluatable zones, dim 未宣言 discs on physical entities declaring none.

- `RoomOperationalClearancePanel` on the placement column: preview toggle, five kind filters, honest counts (`表示x/全体y · 干渉… · 未宣言… · フィルタ外…`), disclaimer.

- `RoomOverlayState.operational_clearance` / `.operational_zone_kinds`; `RoomWorkspace._render` rebuilds the preview from `controller.document` every refresh — drag previews follow live, no stale-revision results.



**Honesty contract** — legend/disclaimer state XY-projection only (NOT an exact 3D swept-solid collision test); height-less zones get no volume and no "clear in height" claim; UNKNOWN zones and 未宣言 entities render as 判定不能, visually and in counts distinct from "no interference".
