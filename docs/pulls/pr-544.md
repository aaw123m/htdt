## Summary

Implements the remaining AI-executable software slices of issue #533 (active low-frequency control: MIMO / support-speaker graphs / wavefront control beyond independent EQ). All new authorities are fail-closed: undeclared evidence yields `UNKNOWN`, never an invented capability.

**`cad_active_lf_design` (new)**

- `evaluate_source_group_eligibility(group, evidence, control_band_hz, strategy)` — deterministic geometry/capability gates: members declared, positions recorded, usable band covers the control band, declared headroom (required for `cross_channel_support`/`wavefront_array`, advisory for `multi_sub_optimization`/`independent_eq`), multi-emitter count, array span/spacing, boundary declared.
- `classify_matrix_path` — `diagonal` (same member sets), `content_feed` (input is a pure content channel), `cross_channel_support` (disjoint emitter sets), `unknown` (undeclared group).
- `evaluate_plan_eligibility(plan, groups, evidence)` — per-path verdicts with a `support_members_distinct` check that rejects self-support.
- `DspResourceEnvelope` + `evaluate_dsp_feasibility(plan, envelope, filter_demands)` — outputs, allowed output groups, cross-term count, processing paths, simultaneous routes, FIR/IIR budgets, gain/delay/latency limits. A declared budget without a declared per-path demand reports `UNKNOWN`.
- `classify_lf_control_strategy` — distinct capability labels: `none`, `independent_channel_eq`, `bass_management_only`, `multi_sub_sum_optimization`, `cross_channel_support_control`, `wavefront_active_control` (requires support paths + `wavefront_control` objective + an actually wavefront-eligible array), `external_proprietary_control`, `unknown`. JA labels in `ACTIVE_CONTROL_LABEL_JA`.
- `lf_control_objectives(plan, candidate_id, seat_responses, ...)` — binds a sealed plan to band-scoped seat-pairwise objectives (`lf.seat.pairwise_*`), per-seat target objectives, and `lf.mean/max_seat_rms_difference_db`; every metric's `ObjectiveDefinition` pins `plan_sha256`.

**`cad_active_lf_control_repository` (new)** — append-only store `cad_active_lf_control_plans` + lifecycle journal `cad_active_lf_control_events`. Legal edges only (`proposed→exported→applied→read_back→verified`, `→rejected`); `applied`/`read_back`/`verified` require an evidence reference; endpoints must be persisted; the event binds both sealed plan hashes.

**Registries** — both tables registered in `NATIVE_BASELINE_DDL`/`NATIVE_SCHEMA_TABLES`, `native_authority_audit._TABLE_POLICY` (`STRUCTURAL_ONLY`), and `native_row_integrity._ROW_BINDINGS` (all duplicated columns bound to payload fields).

**Tests** — `test_issue_533_active_lf_slices.py`: ALF10–ALF50 fixtures covering bass-management-only vs multi-sub optimization vs support-control vs wavefront distinctions, ineligible-member exclusion, DSP-limit rejection of a physically valid graph, geometry flips, and the full design → exported → applied → read-back → verified journal (with fail-closed edge cases and tamper detection).

No proprietary ART/WaveForming semantics are reverse-engineered or claimed; the manifest remainder for #533 is narrowed to physical validation.
