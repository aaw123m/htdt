## Summary

Round-4 review+fix pass over the FastAPI surface (`backend/src/htdt/main.py`, ~40 legacy/dev-only routes). Full audit trail with verified-clean and deferred items: `docs/reviews/round4-api.md`.

**Fixed:**

- **SPA catchall swallowed API misses.** With `frontend/dist` present, any unmatched `/api/*` path — a typo'd route, or the deliberately gated-off `/api/docs`/`/api/openapi.json` — fell through `/{path:path}` and returned `index.html` as **200 text/html**. Now `api_route` fallbacks on `/api` + `/api/{path:path}` (GET/HEAD/POST/PUT/PATCH/DELETE, registered after all concrete routes) answer JSON 404; `_is_api_path` inside `frontend()` also catches case variants like `/API/x`. `OPTIONS` is intentionally unclaimed so preflights keep the router 405.
- **Non-finite floats validated.** `json.loads` accepts `Infinity`/`NaN` and pydantic defaults `allow_inf_nan=True`, so e.g. `{"room": {"width_m": Infinity}}` passed `gt=0` and got stored — later response serialization would then emit invalid JSON. `allow_inf_nan=False` added to the nine `models.py` classes carrying floats (the constraint-set and search-spec trees already rejected non-finite).
- **Follow-on fix:** FastAPI's default 422 handler echoes the offending `input`; `inf` can't be encoded by the strict JSON encoder, so rejecting the request would have crashed → 500. Registered a `RequestValidationError` handler running `exc.errors()` through `_finite_safe_error_detail` (non-finite floats → string form, `{"detail": [...]}` shape preserved).
- **Error-mapping gaps closed** (`KeyError`→404, `ValueError`→422, integrity→409, store faults→500): `create_constraint_set` lacked `except KeyError`; all 7 project-scoped list endpoints returned `[]` for a missing project (now 404; `context_id` filters 404 for foreign context); `_store_asset`'s missing-on-disk `ValueError`→422 became `AssetIntegrityError`→500 — store corruption isn't a client error.

**Deferred with sketch** (in the doc): unbounded `fetchall()` pagination on `list_*` endpoints (needs `{items,total}` response-shape change + TS updates), `response_model` coverage (only `/api/health` has one — contract-test sketch instead).

**Tests:** 31 new regression tests in `test_review_round4_api.py` (api-typo 404s across methods + case, SPA fallback preserved, real routes not shadowed, missing-project 404s, KeyError→404, non-finite→422, missing-asset→500, body-limit 413). Full `pytest -q -n 4` run in progress at PR time; scoped suite (api/security/frontend/round3/round4): 116 passed.
