## Summary

Re-importing a revised IFC previously created a brand-new unrelated subject — nothing compared it against the already-imported model. This PR adds the diff path: `import_revised_ifc_source` computes an honest element correspondence, a new review panel lets the operator accept/skip each row, and `apply_ifc_diff` writes a NEW `ifc_diff_merge` subject transactionally — never mutating the pinned import, never silently overriding operator decisions, never counting `unknown` as `removed`.

**Correspondence (`cad_ifc_diff.py`)** — `IfcDiffRow`s keyed primarily by IFC `GlobalId`: same gid → `matched`/`changed` (`geometry_changed` vs `semantics_changed`, materials/openings flag `acoustically_relevant`); duplicated gids on either side → `ambiguous`/`duplicate_global_id`; prior-only↔new-only orphans paired by (type, name, parent) → `ambiguous`/`ambiguous_rebind` (a rename is a rebind decision, not add+remove); unpairable → `removed`/`added`; no-GlobalId elements that can't pair uniquely → `unknown`/`unmatched_identity` — painted gray in the UI and explicitly never counted as removed. A coordinate-authority change between artifacts adds a project-level row.

**Apply (`geometry_intake_controller.apply_ifc_diff`)** — accepted rows take the new mapping, skipped/pending keep the prior side. Reconciliation marks are re-sealed *before* `build_ifc_diff_subject` so merged parts pin marked rows; the merged subject then flows through the same fail-closed `diagnose_geometry_intake` + `propose_geometry_repairs` chain as #866. Marks + `IfcDiffApply` (`ida:`) + report + proposal commit in one `BEGIN IMMEDIATE` via new `*_in_connection` repository helpers (#996 pattern). After apply the diff base becomes the merged set, so successive revisions diff against visible state. `resume_diff_state` recomputes rows deterministically and restores the operator's decisions from the latest apply — skipped rows stay visibly flagged on re-open.

**UI** — `IfcDiffReviewPanel` docked next to the intake panel: 区分/要素/GlobalId/旧・新ジオメトリハッシュ/決定 columns, per-row 承認/スキップ/位置 buttons (locate reuses #977 anchors), 全て承認/全てスキップ/選択を適用 bulk actions, category colors (unknown gray, ambiguous amber) and a summary line reporting all six counts.

**Schema** — v117 adds `cad_ifc_diff_applies` (sealed `ida:` records: delta ref, both artifact refs, merged subject sha, every decision, per-category counts); replay-probed via `native_authority_audit`, JA label in `application_pages`.
