## PR 本文 (原文復旧 — devin-75f9a053)

## Summary

REV24-UX audit track: the shell's user-facing surfaces rendered raw internal identifiers inside Japanese sentences — enum values, preference keys, diagnostic codes, authority vocabulary, entity kinds. This PR localizes each leak at the presentation layer (the codebase's established convention: authority/diagnostic text stays English, keyed JA label maps live next to the widget) and fixes two command-coherence issues. Behavior is unchanged except display text and one menu item's shortcut column.

**Localization fixes**

- `workflow_settings.py` — the 環境設定 tab rendered `definition.key` as the row label, the English `description` as tooltip, and raw enum ids in combos; the write-refused banner interpolated `load_state.value` (e.g. `corrupt`). Adds `_PREFERENCE_LABELS` / `_PREFERENCE_DESCRIPTIONS` / `_PREFERENCE_VALUE_LABELS` (per-key, raw-id fallback for future keys) and `_LOAD_STATE_LABELS`; committed values stay the canonical enum ids (`userData` unchanged).
- `navigation_target.py` — new `navigation_kind_label()` over `_NAVIGATION_KIND_LABELS` (all 25 kinds); `_TARGET_UNSUPPORTED_REASON` now formats the JA name instead of `kind.value`.
- `workflow_navigation.py` — new `destination_label()` (workspace + application destinations) and `workspace_context_label()` (normalizes aliases, then scans all workspaces' contexts so a foreign/stale link still names its section in JA).
- `workflow_shell.py` — router focus refusal (`{kind}の個別フォーカスはこの画面では未対応です`), unregistered-destination, and missing-section status messages all use the new label helpers.
- `authority_inspector_ui.py` — lifecycle (`current`→現在…), `authority_class` (`room:scene_revision`→`部屋・シーンリビジョン`), and node labels (`Document`/`SceneRevision`/`測定 (measured)`→JA) localized in the dialog; `authority_graph` labels stay English for `to_snapshot` diagnostics.
- `geometry_import_dialog.py` — QA table 検査/推奨対処 columns, `音響体積` readiness, repair-checkbox risk-class tooltips, and applied/unresolved repair lists rendered English identifiers; now localized via `_ISSUE_CODE_LABELS`, `_ISSUE_ACTION_LABELS`, `_ACOUSTIC_VOLUME_LABELS`, `_REPAIR_OPERATION_LABELS` (covers all 14 `_REPAIR_RISK` kinds), `_REPAIR_RISK_LABELS`, and `_unresolved_finding_label()`. Also fixes the 演算子 (math-operator) mistranslation → オペレーター, `format_specification` → フォーマット仕様, and `C/unsupported…失敗クローズ` jargon in the repair hint.
- `room_workspace.py` — `isolate_kind` status showed the raw kind (`「speaker」のみ表示`); now reuses `SelectionInspector.KIND_LABELS`.
- `capture_retention_ui.py` — purge-blocking dependents rendered `semantic_promotion`/`mesh_composition` raw; now `_DEPENDENT_KIND_LABELS`.

**Coherence fixes**

- Archive terminology unified on `アーカイブ解除` (menu item + picker title), matching the library-page button and recovery text — previously `アーカイブから復元` vs `アーカイブ解除`.
- Room viewport context menu appended shortcuts as text (`label    M`); items now carry real `QAction` shortcuts (native shortcut column + working accelerators while open). Menu gets `WA_DeleteOnClose`, so the parented popup — previously kept alive after `exec()` — no longer accumulates or leaves stale shortcut grabs.
