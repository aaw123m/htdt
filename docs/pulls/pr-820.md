## Summary

Adds the single-channel live-observation authority — the complement to #663's dual-channel transfer-function authority — as a new sealed `cad_*` domain module at native schema v80.

**Domain module** (`cad_live_spectrum.py`): five sealed record types — `RealtimeMeasurementSession` (`rms-`), `LiveSpectrumObservation` (`lso-`), `SPLTimeHistory` (`sth-`), `CapturedLiveTrace` (`clt-`), `LiveEventAnnotation` (`lea-`) — plus nested parameter bindings for each live mode (#1):

- `SpectrumEstimatorBinding` pins the #749 estimator identity (FFT size, `WindowKind`, record length, overlap, averaging, detector, scaling, resolution, smoothing, peak-hold, update rate, version) — the math stays #749's.
- `FractionalOctaveBinding` makes `iec_61260_class_1/2_eligible` expressible only with a pinned `IEC 61260-1@<edition>` revision AND bound class evidence; `banding_eligibility()` self-downgrades forged claims even on validator-skipping models (#4, #18).
- `SplQuantityBinding` requires frequency/time weighting, integration/Leq interval, peak-detector and reset semantics — a bare `quantity_value_db` is rejected without them (#5).
- `SpectrographBinding` pins method/window/time-step/grid/range/weighting/normalization; `display_palette` is visualization metadata only (#7).
- `TimeHistoryPoint` kinds (`missing`/`session_boundary`/`calibration_changed`) carry markers and no level; `evaluate_time_history_integrity` flags >1.5×interval jumps with no marker as `gap_unmarked` (#6).
- `channel_semantics: Literal['single_channel']` makes TF claims unrepresentable (#11); `claim_kind` admits only contextual values so annotations can't assert causality (#9); `spatial_average` requires `combination_semantics_ref` (#15); `exposure_interpretation` delegates to #602 (#13); `overload_detected` limits quantitative claims (#695).

Nine evaluators all fail closed — no instrument identity → `diagnostic_only`, uncalibrated SPL → `uncalibrated`, display-only banding → `banding_display_only`, live view → `preview_only` for #580 (never qualified noise), safety alerts on uncalibrated input → `alert_denied_uncalibrated`.

**Repository** (`cad_live_spectrum_repository.py`): five `_SealedStore` tables — `_assert_sealed` re-verification on save, idempotent same-sha writes, `LiveSpectrumConflictError` on sha divergence, every bound column re-verified on `get()`, `document_id` on `list()`.

**Schema v79→v80**: `cad_realtime_measurement_sessions`, `cad_live_spectrum_observations`, `cad_spl_time_histories`, `cad_captured_live_traces`, `cad_live_event_annotations` + indexes, `_ROW_BINDINGS`, audit `_REPLAY_PROBES` (replay_canonical under a `live_spectrum` factory), `_LIFECYCLE_TABLE_LABELS` JA labels, `live_observation_line()` helper. Note: main was already at v79 (sibling #800 landed first) so this claims v80, per the +1-from-base rule.

**Tests**: `test_issue_793_live_spectrum.py` — 71 tests, every verdict path incl. all fail-closed branches, forged-sha/id rejection at save, column-tamper detection, round-trip, fresh-migrate table check, and the LIVE10–LIVE80 fixtures (calibrated RTA, HVAC correlation, momentary-vs-qualified noise, overload, event gap, RTA≠TF, multi-input, long Leq).

**Pre-existing rot** (not this PR): `test_native_authority_audit*` and `test_authority_audit_coverage` red on `capture_mission_rebase_decisions` — #800's table lacks audit coverage registration on main.

No UI wiring, no manifest edits, no sibling modules touched.
