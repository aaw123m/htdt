## Summary

One click on the measurement campaign page now executes the registered runner plan with the HTDT-native sweep engine end-to-end: materialize → read-only preflight → explicit arm approval → unattended drive that pauses only at physical mic moves. Pause/resume/cancel are journaled on the sealed event log, so an app restart re-materializes the same deterministic `mcplan-` and resumes with zero double-recording.

- `cad_campaign_native.py` (new): `materialize_native_campaign_plan` converts a `MeasurementRunnerPlan` into the canonical `mcplan-` plan — position = measurement target, channel = role+speaker-set binding, `campaign_ref`/`scene_ref` pinned. Fails closed (`NativePlanConversionError`) on unknown entities, missing/empty routings, gapped or non-uniform repeats, and any queue that doesn't cover the runner matrix 1:1. `resolve_cell_assignments` exact-binds entries to cells; ambiguous/unbound cells park for manual review. `build_native_preflight` runs a real `MeasurementAcquisitionEngine.configure()` PRECHECK per distinct routing; `NativeCampaignDrive` wraps `CadCampaignExecutionRepository.runner_for` so rebuilding from the journal IS restart-resume. `cell_native_labels` renders per-cell JA status with a ` SIMULATED` suffix — fake evidence is labeled, never promoted.
- `measurement_workflow.py`: `materialize_native_campaign` (deterministic plan id per inputs → reopen re-attaches the existing journal via append-only `save_plan`), `native_preflight`, `native_campaign_drive`, `native_campaign_status`, `native_campaign_for_runner_plan`.
- `measurement_page_workspace.py`: new "HTDTネイティブ自動実行" card — 準備 → preflight dialog (`アーム承認` disabled while PRECHECK is blocked; SIMULATED banner) → drive; position-move prompt "マイクを「...」に移動してください" blocks until confirmed; pause/resume/cancel buttons; progress + remaining + missing-evidence lines; ネイティブ実行 column in `campaign_table`. The arm provider echoes the approved routing+level — an engine presenting different parameters is refused (`arm_confirmation_unavailable`), so saved settings never substitute for the approval click. REW/manual paths untouched.

Test evidence (`test_issue_956_campaign_native.py`, 17 tests): exact matrix mapping, deterministic id, fail-closed conversion, WASAPI-stub blocked arming, full E2E (1 arm → same-position cells auto → position gates only → completed, sealed `swrun-` assets reopenable), restart-resume with `factory.calls` proving no re-recordings, clipping retry, timeout/routing-change/ambiguous-cell honesty, workspace one-click path with `_commit/_skip_campaign_cell` patched to fail (per-cell clicks = 0).

Note: `test_measurement_workflow_ux130.py::test_measurement_workspace_is_page_based_and_shell_mountable` is red on HEAD already (asserts 7 pages vs 8 since the calibration-wizard page) — pre-existing, not this PR.
