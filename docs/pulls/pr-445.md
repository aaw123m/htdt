### Findings (each demonstrated numerically before fixing)

| # | Site | Bug | Demo | Fix |
|---|------|-----|------|-----|
| F1 | `cad_hybrid_late_energy` late-energy injection | Scattered fraction leaving the specular channel was `arriving * s`, omitting `(1 - alpha)`. The R150 authority itself declares the scattered complement as `(1-alpha)*s`; per reflection the bookkeeping then violated conservation (`specular + late + absorbed = 1.02*E0` for alpha=0.1, s=0.2) | E0=1, alpha=0.1, s=0.2: injected 0.20 vs correct 0.18; with alpha=0.3, s=0.5 the error created 0.15*E0 of phantom energy per bounce | `late += arriving * (1-alpha) * s`; `R160_LATE_ENERGY_ARTIFACT_VERSION` -> `r160-late-energy-decay-2` |
| F2 | `cad_late_field_energy` surface-scattering emergent bound | `emergent = 1/(4*pi*d2^2)` treats re-emission as full-sphere isotropic; a boundary patch cannot emit through its own surface — the interior hemisphere is `2*pi` sr, so the declared `isotropic_energy_upper_bound` could undershoot the physical maximum by up to 2x | patch bound 0.5x the true hemispheric intensity | `emergent = 1/(2*pi*d2^2)` |
| F3 | `cad_late_field_energy` wedge/aperture diffraction emergent bound | Same 4*pi normalization; the air-side dihedral of an edge whose incident faces block `2*w_material` sr (`w_material = pi +/- sigma`, `sigma` = face-normal separation) is at most `2*(pi - sigma)` sr — the bound could undershoot by up to 4x for a 90-degree room edge | sigma=126°: bound 6.67x under; sigma=90°: 4x under | `emergent = 1/(2*(pi-sigma)*d2^2)`, sigma clamped to 179° to keep the bound finite; `LATE_FIELD_ADAPTER_VERSION` -> `2` |
