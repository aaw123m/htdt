## Summary

REV26-PERF2: residual-performance pass on the headroom declared by #437, #442 and #449. Two lanes landed, two measured-and-skipped. Solver `execute` on the pinned order-2 fixture is 22–27% faster with **bit-identical** artifact, path-id and rejected-candidate digests; every cache is content-keyed per the #449 pattern.

### Landed

**1. Prepared occluder-row geometry (PERFACC-adjacent hot lane).** `_UniformOccluderGrid` now precomputes per-row `(edge1, edge2, lengths, self-dots, normal, normal_length)` once; `prepared_candidates`/`prepared_point_candidates` expose them to three consumers that each recomputed the same per-triangle math on every call:

- `_segment_blocked` (adapter): prepared Möller–Trumbore with segment direction/length hoisted out of the loop.
- `_point_has_other_surface_contact` (adapter): prepared point-on-surface/in-triangle tests, indexed branch threaded at all 5 call sites.
- `_segment_blocked_ignoring_triangles` (late field) + 3 portal sites (boundary check, parity rays, crossing check).

All prepared helpers replicate the exact float operation sequence of the raw path — `_dot` keeps compensated `sum()` (CPython 3.12 Neumaier summation; unrolling changed last-ULP bits on ~32% of inputs) so verdicts and `t` parameters are **bitwise identical**, verified by four 1500-case equivalence tests (segment, point-surface, point-in-triangle, portal ray).

**2. Validation-skip artifact construction.** `revalidate_instances='never'` on the eight nested path/artifact models + `_make_path` now builds model objects once and injects them into an `init_payload`, while `core` keeps the same literal dicts for the semantic digest. Per-`validate_python` cost dropped ~21%; a `_frozen_model_json_payload` lru_cache kills repeated `model_dump(mode='json')` of the same `solver_implementation_ref`.

**3. Content-keyed underlay assets (UIPERF residual).** Two real caching misses fixed:

- `RoomWorkspaceController.underlay_render_items` re-read the blob and re-decoded the PNG on every aux-state sync → memoized per `render_blob_sha256` (a true content key; ~13ms per underlay per sync eliminated, misses never cached).
- `_render_underlays` rebuilt `pv.PolyData` quad + `pv.Texture` + line mesh on every signature-differing render → content-keyed memo on `(underlay_id, quad, segments, opacity, elevation, missing_source, id(image))` (~7ms per underlay per render for a 1024² raster + 400 segments).
