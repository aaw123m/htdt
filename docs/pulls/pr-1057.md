## Summary

Refs #1013

Adds a read-only 「照明シーン」 preview to Room/Video that draws the *configured* state of the currently selected `LightingScene` onto the 3D room — keeping `desired` / `commanded` / `read_back` / `measured` as four visually separate channels that are never merged into one "actual" state.

**Preview shape** (`htdt/room_lighting_preview.py`, pure model — no I/O):
- `LightingScenePin` — a pin exists ONLY when a scene-referenced fixture's `entity_id` exact-binds to a document entity. Anchor disc on the entity position (zone-role color), plus a row of four stage beads above the entity top: stage color when known, dim `不明` bead when the stage was never recorded — never 0%, never the desired echo.
- `LightingUnplacedFixture` — `entity_id=None` (control-only) and dangling bindings stay in the `3D未配置` list with a reason, never drawn or guessed.
- `LightingZoneRow` — zone-level commissioning evidence stays zone-level; a `zone:` read-back never fills member pins' device stages.
- Commissioning records participate only when bound to the exact scene identity (`scene_id`+`version`+`scene_sha256`); foreign records are counted as `ignored_records`. Missing scene refs surface in `missing_refs` instead of silently dropping.
- Capability-mismatched state (`level` on non-dimmable, `cct`, `color`) marks `unsupported` → `非対応:...`; recorded non-desired stages without `observed_at_utc` flag `stale`.

**Viewport** (`room_viewport.py`): `render_lighting_scene_preview` draws anchor + 4 beads + `※複合割当` wireframe + bias-target link + `stage_bead_label` (`目30% 送– 応0% 測–`) per pin, plus summary/unplaced/disclaimer text and a stage+zone legend. All actors are non-pickable and swept via the `'lighting-'` prefix in `_OVERLAY_ACTOR_PREFIXES`; `lighting_scene` joins `RoomOverlayState`.

**Panel/workspace**: `RoomLightingPreviewPanel` on the placement page (toggle, scene identity, counts, `3D未配置・ゾーン` list, disclaimer). `RoomWorkspace` resolves the scene via `CadLightingRepository.current_scene(document_id)`; a `lighting_inventory_provider` seam supplies `(fixtures, zones, records)` — inventory persistence doesn't exist yet, so the empty default honestly reports scene refs as unresolved.

**Honesty contract**: marker colors are explanation symbols of configured state — never lux/beam-spread/room illumination; the legend/disclaimer says so. `read_back` is a device report, not photometric evidence (`desired 30% + read_back 0%` renders `目30% 応0%`, never "on"). The preview sends nothing — 「適用」「実機読出し」 stay on the approved `cad_hue_lighting` path.
