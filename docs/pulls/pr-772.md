## Summary

REV59-UNITS — four sealed append-only authorities for issues #728 (P0), #730, #720, #719, plus native schema v53 (11 new tables), row-integrity bindings, audit replay probes, and JA lifecycle labels.

### #728 Typed physical-quantity / unit authority — `cad_typed_quantity.py`

`CadTypedQuantity` (`tqty-`) separates three axes that a bare float collapses: `quantity_kind` (44 semantic kinds — gauge vs absolute pressure, electrical vs acoustic vs radiometric power, frequency vs angular frequency never interoperate), `DimensionFamily` (25 families — unit conversion is legal only inside one family; W shared by four power kinds is *not* a warrant for arithmetic), and `value_kind` (absolute / difference_delta / gauge_relative / normalized / count). ~70 `CadUnitDef` entries carry `scale` (+ affine `offset` for °C/°F only); `to_canonical` drops the offset for `difference_delta` values so ΔT 5 °C = ΔT 9 °F.

`evaluate_quantity_operation` (`tqop-`) is fail-closed: `compare`/`add`/`subtract` require full identity (kind + value_kind + angle/ratio semantics + declared reference); `multiply`/`divide` compute only named derivations in `_PRODUCT_KINDS`/`_QUOTIENT_KINDS` (`unlisted_derivation` otherwise); `ratio_of` never crosses kinds; affine add/subtract works only across declared `_ABS_DIFF_PAIR` (abs+Δ→abs, abs−Δ→abs, abs−abs→Δ, Δ−abs→incompatible). Linear→log conversion defers to the #691 typed-dB authority (`requires_log_quantity_bridge`).

### #730 Engineering assumption / permissible-use ledger — `cad_assumption_ledger.py`

`CadEngineeringAssumption` (`asm-`) seals `assumption_kind` (13, incl. non-physical `user_preference_target`/`commercial_project_constraint` which cannot claim physical evidence states), `evidence_state` (unknown ⇒ no value; non-unknown ⇒ value required), declared `CadAssumptionValue`, and non-empty `permissible_uses` — an empty use-set (default valid-anywhere) is validator-rejected, which is exactly the failure this ledger exists to prevent. `supersedes_ref` keeps versioned lineage (`assumption_lineage_issues` flags dangling/cyclic chains); `CadAssumptionResolution` (`asmres-`) records measured/superseding resolution with evidence refs.

`evaluate_permissible_use` (`asmpu-`) gates via `_VALIDATION_GRADE_STRICTNESS` (exploratory=0 … rp22_design_evaluation=5): a `literature_assumed` material may support `concept_design` but yields `use_blocked` for `claim_or_reporting`/`rp22_design_evaluation`/`commissioning_evidence`; unresolved assumptions in scope produce `assumption_blocks_use`.

### #720 Perceptual relevance / audibility authority — `cad_audibility.py`

`CadPerceptualModelProfile` (`pprof-`) pins `CadAudibilityThreshold` per `AudibilityObservable` (level dB, frequency JND, timing ms, spectral irregularity peak/dip, reverberance JND, masking, …) with a sealed `literature_ref`. `applicable_as_reference` for `iso226_equal_loudness` is enforced at seal time to ISO 226:2023's declared scope (pure_tone + free_field_frontal + normal_hearing_18_25); `iso532_loudness` requires `requires_level_calibration`.

`evaluate_audibility` (`aud-`) is fail-closed: outside-scope model or mismatched `CadListeningConditions` → `outside_model_scope`; missing `level_reference_ref` for level observables → `insufficient_evidence`; no matching threshold → `indeterminate`; |Δ| ≤ threshold → `not_distinguishable_under_profile` (sub-threshold differences can never be ranked); |Δ| > threshold → `potentially_audible` (never "definitely heard").

### #719 Residual diagnostic-hypothesis authority — `cad_diagnostic_hypothesis.py`

`CadDiagnosticCase` (`diagcase-`) binds prediction ref + observation ref + `CadResidualSignature` (polarity/frequency/spatial/temporal/magnitude shape with sha-pinned symptom refs). `CadDiagnosticHypothesis` (`diahyp-`) seals a `cause_family` (16 — `model_form_inadequacy` and `multiple_faults` are first-class), `required_evidence`, and `discriminating_symptoms` separately from any verdict. `CadDiagnosticTest` (`diatest-`) requires `predeclared_prediction` + `executed_at_utc` + `result_evidence_ref` for a confirmed verdict, and `intervention_label` + `held_constant_label` for `controlled_intervention`.

`evaluate_diagnostic_verdict` (`diaverdict-`): `_derive_hypothesis_state` ladder = contradicted > confirmed (controlled_intervention / independent_remeasurement / loopback_check / isolation_measurement with `confirmed_by_intervention_and_remeasurement` only) > test_supported > model_supported > confounded > candidate. Case verdicts: confirmed → `root_cause_confirmed_within_declared_scope` (multiple confirmations keep `multiple_faults`); all contradicted → `unresolved`; ≥2 confounded or supported+open → `diagnostically_confounded` with `confounded_hypothesis_ids`; `diagnostic_claim_allowed` blocks every non-confirmed cause claim — a residual pattern match is a hypothesis, not a cause.
