## Summary

Round-8 product-level review+improve over the shipped `RoomWorkspace` editing surface (selection/manipulation, inspector/viewport polish, command palette, undo depth). Full audit + deferred sketches: `docs/reviews/round8-cadux.md`. Legacy `room_editor.py`/`TheaterWorkflowWindow` are not part of the shipped shell — untouched.

**Fixed**

- **Dead daily shortcuts**: `CAD_SHORTCUT_COMMAND_IDS` omitted `room.edit.delete`/`toggle_hide`/`toggle_lock`/`room.measure`, so the palette showed Delete/H/L/T badges but no `QShortcut` existed — keys did nothing. Added them plus `room.select.all`/`room.select.invert`; `room.edit.delete` gains a `Backspace` alias. Safe because `CommandShortcutBinder.execute()` re-checks live availability and `deactivate()` unbinds (inert no-op elsewhere).
- **No keyboard nudge**: `RoomEntityTransformController.nudge_selection(dx_m, dy_m)` — arrows nudge the entity selection by `grid_step_m` (Shift = ×10) through the same `begin_group_move → preview_group_move → commit_gate → commit_preview → propagate_constraints` path as a mouse drag (one keypress = one undo step); `RoomGeometryInputController._key_press` nudges the selected vertex via `set_selected_vertex_coordinates` / wall via `move_wall` while `mode == "edit"`.
- **Zoom-to-selection only panned**: `focus_entity` did `camera.set_focal_point`; new `focus_entities` computes the union of `position ± size_m/2` bounds (0.25 m per-axis floor for sizeless points) and calls `plotter.reset_camera(bounds=…)`.
- **Measure ignored the display-unit policy** (round6 D3): `format_measure_result(result, policy=None)` keeps byte-identical SI output by default; `RoomMeasurePanel.set_length_policy` re-renders label + clipboard, subscribed to `display_input.*` preference changes in `_make_room`.
- **Underlay clicks swallowed**: `_underlay_clicked` now falls through to `_empty_clicked` when no calibration is armed — deselect / measure free-point work over plan images.
- **Delete dead in geometry edit**: `delete_selection` routes to `delete_selected_vertex`/`delete_selected_wall`; command availability accepts a geometry vertex/edge selection.
- **New commands**: `room.select.all` (Ctrl+A), `room.select.invert` (Ctrl+I), `room.select.none` — non-mutating, hidden entities excluded; Esc clears selection as final `cancel_active_operation` fallback.

**Deferred (sketched in the report)**: rubber-band box select, click-through occlusion cycling, constraint edits bypassing the undo stack (authority design call).

**Tests**: new `tests/test_room_cadux.py` (14 tests) + a display-policy case in `test_cad_measure.py` + the `room.select.*` ids in the `test_command_registry.py` mutation allowlist. Targeted runs green; full `pytest -q -n 4` suite result reported in the session summary.
