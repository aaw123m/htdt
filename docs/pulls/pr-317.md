**Implemented**
- `main.py` — `/api/docs` + `/api/openapi.json` now off by default, opt-in via `HTDT_LEGACY_API_DOCS=1` (round2-security deferred item).
- `cad_spatial_reproduction.py` — `load_sofa_dataset_profile` feeds `h5py.File` the bounded+hashed `file_bytes` via `io.BytesIO` instead of re-opening the path; `source_file_sha256` provably covers the parsed bytes (TOCTOU closed). - `data_management.py` — `DataManagementController` destroyed-detach mirrors `native_worker`: module-level `_LINGERING_OP_THREADS` re-owns a running `(QThread, _OperationWorker)` pair when the controller dies mid-operation.
- **`native_worker.py` + `data_management.py` — pre-existing dead safety net fixed.** `QObject.destroyed` connected to a bound method (with or without `@Slot`) is *silently never delivered* under PySide6 6.11 — verified: `connect()` returns a `Connection`, the slot never runs, and deleting a live pool/controller aborts with `QThread: Destroyed while thread is still running`. Both `destroyed` hooks now connect a `lambda`, and the new regression tests exercise real destruction — on the old wiring this aborts the interpreter rather than failing an assert.
- Lax canonical-JSON trio (round2-arch A): `application_preferences._canonical_json`, `cad_acoustic_environment._canonical`/`_hash`, `cad_search_models.canonical_search_{json,sha256}` now alias `canonical_json`/`canonical_sha256` — NaN fails closed like every sibling helper. Companion: `PreferenceDefinition.validate` rejects non-finite numbers before min/max (NaN comparisons are False, so NaN passed bounds checks); `AcousticEnvironmentProfile` gains `allow_inf_nan=False` (air-density/pressure/humidity were bounded only by `gt`/`ge`, which admit `inf`).

**Leftovers fixed**: `test_acoustic_bakeoff_mfem_{concave,modal,transient}_experiment.py` `PLAN_PATH` anchored to repo root via `__file__` (was CWD-relative — 26 tests failed under the mandated `cd backend && pytest`); `search_timestamp_utc` and environment `created_at_utc`/`updated_at` use `htdt.clock.utc_now_iso`.
