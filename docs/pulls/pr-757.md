## Summary

Six fail-closed, hash-pinned evidence authorities for loudspeaker acoustic models (#654/#655/#656/#690/#684/#681, all P1). Each authority seals its declared domain and evaluates capability requests strictly inside it — an undeclared or out-of-domain claim returns `insufficient_evidence` / a refusal verdict rather than an optimistic read. Native schema v46 → v47 (14 tables, registered in `NATIVE_SCHEMA_TABLES`), audit replay probes, row-integrity bindings, JA lifecycle labels + one-line display summaries, 71 regression tests.

- **#654 `SourceReferenceOriginProfile` (sorprof-)** — declared reference-point kinds + per-band `AcousticCenterEstimate` (evidence class, method, position, valid band). `band_limited_center` requires a band; `no_single_center_model` cannot assert a position; `absolute_phase_reference` requires a phase/time reference or measured-delay evidence. `evaluate_source_origin` → `origin_qualified` / `origin_limited` (geometry-inferred, assumed, boundary mismatch) / `origin_unverified` (dataset frame only) / `insufficient_evidence` (nothing declared). The cabinet CAD pose is never silently promoted to the propagation origin.
- **#655 `SourceFieldProfile` (sfldprof-)** — `MeasurementGeometrySpec` (mic distance, distance-reference kind, environment; `gate_window_s` required for quasi-anechoic gated) + per-band `BandFieldRegime` (applicable distance range; `transition_distance_m` requires a basis). `origin_ref` sha-pins the #654 authority. Verdicts: `distance_too_close_for_selected_far_field_model`, `nearfield_only` vs `applicable_with_approximation` when a `NearFarDerivation` is declared, gate-window low-band → `insufficient_evidence`, multi-radiator semantics on polar-only data → `requires_explicit_multi_radiator_model`.
- **#656 `DirectivitySamplingProfile` (drsprof-)** — measured grid pinned (coverage class, direction count, nominal step); `AngularInterpolationSpec` enforces method/domain compatibility (SH requires `ShRepresentation`, complex-TF methods require complex data, `custom_validated` requires declared validation). `DirectivityInterpolationRecord` (dinterp-) records a denser output grid without raising the information ceiling. `evaluate_direction_query` → `measured_direction` / `interpolated_eligible` / `interpolated_limited` (per-band states like `spatial_aliasing_risk`) / `extrapolated` / `outside_coverage` / `sh_order_unsupported`.
- **#690 `SourceCoherenceProfile` (mscprof-)** — members pin their own profile + stimulus/filter refs; per-pair `CorrelationRelation` requires an evidence basis (partial coherence requires CSD or measured basis); `CsdEvidence` requires a sorted positive grid + `hermitian_declared`. Incoherent energy summation on deterministic/coherent groups → `incompatible_combination`; undeclared relations allow only `bounded_scenarios` (when declared) or `insufficient_evidence`.
- **#684 `SurfaceReflectionModelProfile` (scatprof-)** — the coefficient→distribution mapping is explicit and mandatory: ISO 17497-2 directional-diffusion coefficients and other non-fraction kinds are rejected as `solver_input` (documentation role only), unit-energy mappings must have fractions summing to 1, `measured_kernel` laws need multi-incidence measured data. Geometry needing directional redirection on a non-redirecting model → `directional_redirection_unsupported`. No silent Lambert.
- **#681 `EdgeDiffractionProfile` (edfprof-)** — model family declared at construction (`unknown` rejected), finite edges require a length, `DiffractionBenchmarkResult` (difbench-) sha-pins the profile (a `pass` cannot contain mismatches). Capability ladder: any failing fixture → `unqualified`; zero fixtures → `insufficient_evidence` (except `numerical_wave_reference` → `physical_reference_capability` with limitation); weak fixtures only → `physical_approximation_capability`; IIR approximations cap at `perceptual_approximation_capability` without strong fixtures; rigid-boundary model on non-rigid wedge → downgrade + `boundary_limited`; no convergence evidence → reference caps at approximation.

## 文献根拠

- **位相中心**: Keele, "The Acoustic Center of a Loudspeaker" (JAES 1977); Vanderkooy, "The Acoustic Centre: A Small-Driver Approximation" (JAES 1983) — 帯域・幾何依存 → band_limited / no_single_center を別 model_kind で表現。
- **近接/遠距離場**: Fraunhofer d > 2D²/λ 基準; AES/CEA-2010 測定距離宣言慣行 — transition distance に basis 必須; ゲート窓分解能 Δf ≈ 1/T_gate で低域 claim を機械拒否。
- **空間サンプリング/補間**: Rafaely, *Fundamentals of Spherical Array Processing* (2015); 球面サンプリング定理 (N ≈ kr) — SH 次数と実測刻みを pin、補間密度 ≠ 情報密度。
- **多源相関**: Beranek & Mellow, *Acoustics: Sound Fields and Transducers*; ISO 3745 パワー和前提 — deterministic 群への energy sum を `incompatible_combination` で拒否。
- **散乱**: ISO 17497-1/-2; Vorländer, *Auralization* (2008) §4.3; Christensen & Rindel — 散乱係数は角度分布を定めない → 写像を必須化し ISO 17497-2 を solver input から構造排除。
- **回折**: Biot & Tolstoy (1957) / Medwin (1981) BTM; Keller (1962) GTD; Kouyoumjian & Pathak (1974) UTD; Svensson et al. (1999) — モデル族・幾何・収束・ベンチを pin、未検証は insufficient_evidence。
