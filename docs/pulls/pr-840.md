## Summary

Issue #812: R160's hybrid composition (wave solver below crossover, GA above) is a new model-form assumption — R130 PASS + R150 PASS does not imply R160 PASS. This PR adds a sealed V&V authority for the hybrid composition itself.

**New records (schema v90, `hvspec-`/`hve-`/`hvv-`):**
- `HybridCompositionValidationSpec` — pins `subject` + wave/GA qualification refs, expected `HybridStitchRegionKind`s, a versioned `crossover_rule` (rule_id + version + required agreement evidence kinds), a pre-registered `sensitivity_requirement`, a disjoint `ownership_policy` covering every expected region × contribution kind, and the `applicability` envelope that bounds any pass.
- `HybridValidationEvidence` — per-`evidence_kind` field contracts (component qualification, common-input binding, per-region evaluation incl. gap rows, crossover-selection discharge, eight phase/time checks, grid reconciliation error, crossover sensitivity sweep, external benchmark with reference class, late-field decomposition, numerical verification). Malformed rows are rejected at validation.
- `HybridValidationVerdict` — carries `region_results` (per-region states) plus `gap_domains` as `HybridStitchGap`s, and sub-state fields for crossover/ownership/phase/grid/sensitivity/late-field.

**`evaluate_hybrid_validation`** is fail-closed and ordered: `components_unqualified` → `common_inputs_unverified` → `component_inheritance_denied` (the signature state — component passes alone with zero hybrid-specific evidence) → `region_evaluation_failed` → `crossover_selection_unsupported` → `double_count_unchecked` (unassigned/`not_present` ownership) → `coherent_claim_unvalidated` → `early_field_unverified` (late-field masking early reflections) → `crossover_sensitive` → `insufficient_evidence`, then `numerically_verified` or `validated_bounded` only when `measured_external`/`independent_numerical` benchmark evidence passes. `same_code_fine_reference` and `fitted_calibrated` can never qualify the external gate.

Region identities reuse the existing `cad_hybrid_stitching` vocabulary (`wave_only`/`crossover_blend`/`ga_only`, `HybridStitchGap`) verbatim. Wiring: `_migrate_89_to_90`, 3 tables + indexes, `_ROW_BINDINGS`, authority-audit factory branch + 3 `_ReplayProbe`s, `CadHybridCompositionValidationRepository` (append-only), JA labels on `measurement_evidence_display`.

47 new tests cover every verdict path, seal/id integrity, evidence kind contracts, and repository round-trip/tamper.
