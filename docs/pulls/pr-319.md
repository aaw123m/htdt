## Summary

Round 4 audits the changes the three review rounds themselves merged (15 merge commits on `main`) and fixes three regressions they introduced. Full audit matrix and convergence assessment live in `docs/reviews/round4-regression.md`.

**Fix 1+2 — orphaned loading flags from stale-call guards (rev3-frontend).** The stale-response guards added in round 3 use a sequence number read inside `finally`:

```ts
finally {
  if (seq === seqRef.current) setLoading(false)
}
```

When the guard's invalidation (measurement change in `RewReadonly.preview()`, context change in `App.checkMeasurementReadiness()`) fires mid-flight, the stale `finally` skips the clear — `loading`/`readinessLoading` stays `true` forever and the button (`disabled={loading}`) is permanently dead until reload. The effects that bump the sequence refs now also release the flag they orphaned. Other seq users (`runAcoustics`, `chooseMeasurementFile`, `reloadProjectData`) have no loading flag and are unaffected.

**Fix 3 — opaque preference keys could poison every save (rev3-deferred).** `application_preferences._load` carries unknown (future-build) keys verbatim into `_opaque_values` so durable writes round-trip them. After rev3-deferred routed `_persist` through strict `canonical_json` (`allow_nan=False`), an unknown key holding `NaN`/`Infinity` — which `json.loads` happily parses — made *every* subsequent `set()`/`update()` raise `ValueError` in `_persist`, while `PARTIAL_INVALID_VALUE` remained a writable state: the store could never self-repair. `_load` now screens each opaque value with `_canonical_json`; unserializable values are dropped and reported via `_load_error` with `PARTIAL_INVALID_VALUE`. New test: `test_unserializable_opaque_key_dropped_not_poisoned`.

**Audited clean:** the `canonical_json` NaN sweep (all other callers feed finite/validated data), the 109-site `connect_sqlite` consolidation (identical trio everywhere; `_repoint_lineage_parent` commits before `PRAGMA foreign_keys=OFF` — the pragma is inert inside a transaction), `ParetoEmptyError` narrowing, vectorized `_interpolate_prepared` (bit-identical modulo unreachable NaN-grid inputs), `FrozenBundle`/`migration_guard`/`capture_receiver` bounded reads, `xml_guard` coverage, `native_cad` lazy exports vs all `setattr` test targets, `destroyed.connect` lambda sites, `QTimer.singleShot` receiver scoping.

**Convergence:** near-dry. Remaining LOW-risk items (pre-existing, not regressions): the `connect_sqlite` sweep never added `PRAGMA foreign_keys=ON` where it was missing (27 files still open FK-less connections), 8 unbounded `read_bytes()` on operator-controlled paths, 116 non-canonical `json.dumps` sites awaiting per-site strictness audit, unhandled `api()` rejections in some frontend loaders.
