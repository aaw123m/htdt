## Summary

REV37-GUIDANCE-SCRUB wires the reflection-guidance scrub session into the 「ガイダンス」 dock tab (mounted by REV36-GUIDANCE-PROD). A new 音源スクラブ（プレビュー） section lets the user adjust a candidate source position and re-derive preview frames — interactive treat-zone exploration without touching committed authority.

**Minimal input decision (spec item 1).** The scrub session needs: the pinned `ReflectionDiagnosticRequest` + direct/reflection `GeometryPath` pair, `receiver_position`, `plane_point`, `plane_normal`, and a per-frame `candidate_source`. All of it now resolves strictly from persisted authority on `ReflectionGuidanceEntry`:

- `receiver_position` — the snapshot payload's `receivers[]` binding matched on `receiver_id` AND `entity_id` (`world_position`).
- `source_reference_point` (spin default / reset target) — the payload's `sources[]` binding matched on `source_entity_id`.
- Specular plane — `plane_point` = the reflection path's proven `ordered_interaction_points[0]`; `plane_normal` = normalize(departure − arrival), the first-order specular identity (arrival = departure − 2(departure·n)n). Degenerate input (departure == arrival) blocks with `plane_derivation_failed`.
- Candidate position — three JA-labelled `QDoubleSpinBox`es (X/Y/Z, ±200 m, 0.001 m precision) prefilled with the committed source point. An entity selector adds no information the spins lack, and a committed speaker would be the wrong authority (the scrub explores hypothetical positions).

**Honesty model / documented subset (spec item 2).** `scrub_source` frames are exact image-method replays over pinned request/path authority — real replay only. The committed report's ranked `items` are authority and are never re-ordered or re-written: "re-rank" here means each candidate gets a direction verdict (改善/悪化/変化なし vs the baseline excess delay) plus the moved first-reflection point (the treat-zone centre). Entries whose snapshot bindings are missing or unreadable degrade to a named `ScrubUnavailableReason` blocker shown in JA with all controls disabled — never a guessed position.

**UI (spec item 3).** Readout shows `フレーム N: {direction}`, the candidate's excess delay and Δ vs baseline, the new reflection point, both path lengths, and the running frame count; 改善 renders `SemanticState.SUCCESS`, 悪化 `WARNING`. 確定位置に戻す restores the committed position.
