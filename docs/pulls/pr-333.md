## Summary

Round 9 audited every user-facing write/export surface (analysis bundle, web comparison report, installation handoff, deliverables catalog, mission package, standards profile, commissioning registry, diagnostics ZIP) and fixed the defects that produced dishonest or corrupt artifacts; full findings and byte-level verification notes live in `docs/reviews/round9-report.md`.

Real defects fixed:

- **`report._svg_chart` misaligned data.** The web report filtered `grid_hz`/`a_db`/`b_db` independently, so a mid-series NaN silently re-paired every later x with the wrong y, and a non-positive frequency crashed `log2` (report endpoint 500). Now (f,a,b) rows are dropped jointly, with the existing honest fallback below 2 rows.
- **`analysis_export._plot_svg` linear Hz axis.** A 20–20 kHz trace compressed the entire bass decade into ~2.5 px. Frequency series now render on a log₂ x-axis with octave ticks (20–50000) and a `Frequency (log)` axis label; per-point finite filtering keeps `nan` out of polylines.
- **`_export_analysis_bundle` overwrote and half-wrote.** Fixed `analysis_export.*` names meant a re-export clobbered the previous generation and a crash mid-sequence left a partial bundle. New `export_io.claim_export_stem` + `write_export_files` claim a fresh `analysis[-N]` stem and publish all three members atomically or not at all.
- **Deliverables catalog promised phantom artifacts.** `installation.handoff` advertised `md`; `drawing_set` advertised `svg`/`pdf`; BOM/labels claimed standalone exports; `commissioning.report` showed `available` + `('md','html')` though no generator exists; the equipment catalog claimed `csv`. Formats now match reality, non-standalone rows name their exact handoff member file, and the commissioning report reports `blocked` when plans exist.
- **Non-atomic writes** in `export_mission_package`, `_export_profile`, `CommissioningPlanRepository._store` (a corrupt half-store would load as an *empty* registry and silently drop all plans) and the diagnostics ZIP — all staged-then-promoted via `export_io` / `_staged_zip_archive`.

Feature implemented (round-8 §9 deferred sketch): per-comparison export on the comparison page — **この比較をCSVで保存…** writes an analysis CSV containing the persisted A, B and A−B series plus verdict metadata, and **差分プロットをPNGで保存…** snapshots the difference plot. Both only activate on a saved comparison, never a preview.

Recorded non-defects: SOFA/REW are import-only (no export surfaces exist); no print support exists anywhere; handoff/backup/bundle writers were already atomic.
