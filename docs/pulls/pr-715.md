## Summary

REV58-NUMERIC: three fail-closed, hash-pinned evidence authorities covering issues #683 / #685 / #687 — solver results may only claim numerical accuracy inside a declared, evidence-backed domain.

- **#683 `WaveNumericalFidelityProfile`** (`wnfprof-`): seals solver formulation (family/equation/element/source+receiver discretization), discretization (sha-pinned `mesh_identity`, declared `points_per_wavelength_rule`), and a family-required numerics block — `FdtdTimeStepping` (CFL rule/number, declared `stability_state`), `FemNumerics` (element order + pollution mitigation), `BemNumerics`. `ArtificialBoundarySpec` keeps the computational PML separate from the physical `AdjacentTerminationSpec` and carries optional `measured_reflection` leakage evidence — an unmeasured PML never implicitly claims anechoic. `evaluate_wave_fidelity` scores each error class separately (numerical_dispersion / fem_pollution / cfl_stability / artificial_boundary / algebraic_tolerance / geometry_discretization): fixture failure, running outside declared stability, or a nonconverged solve → `not_qualified`; any unresolved class or zero convergence evidence → `insufficient_evidence`; limited or two-level-only refinement → `qualified_with_limitations`; all applicable classes qualified plus strong convergence → `qualified_for_declared_domain`.
- **#685 `GeometricalNumericalFidelityProfile`** (`gnfprof-`): `GaAlgorithmIdentity` (image_source / ray_tracing / beam/tree / radiance_transfer / hybrid) + path-class declarations. Deterministic-capable families must declare `PathTruncationSpec` (≥1 rule) + `VisibilitySpec` with per-case results; stochastic-capable families must declare `RayLaunchSpec` (count, scheme, `rng_name` when seeded) + `ReceiverEstimatorSpec` (spherical/adaptive require `radius_m`, exact path intersection forbids it, optional `radius_sensitivity` study). `RaySamplingConvergence` (`raysconv-`) requires real sweep/seed-spread evidence to claim `converged`; `PathEnumerationQualification` (`pathqual-`) is the exact-GA-path gate (`exact_ga_path_eligible` only when `deterministic_state='qualified'` — the #677 hook). `evaluate_geometric_fidelity` scores deterministic and stochastic axes separately; `radius_unevaluated` caps at `qualified_with_limitations`.
- **#687 `HybridCompositionProfile`** (`hybprof-`): sha-pins wave+geometric predictions and their fidelity-profile refs with per-component `qualified_band_hz`. `TransitionBandSpec` enforces low<nominal<high with a required `selection_basis` (Schroeder estimate informational only); filtered/overlap/blend kinds require `CrossoverFilterSpec`. `SourceNormalizationSpec` blocks mixing pressure and energy components without a normalization authority pin; `TimeAlignmentSpec` declares the group-delay policy; `PhenomenonDeclaration` splits each phenomenon to wave|geometric. `evaluate_hybrid_handoff` derives `gap_in_capability` from disjoint declared bands, flags shared phenomena without `decomposition_note` as `double_count_risk`, requires `ContinuityEvidence` (magnitude step / ripple / phase discontinuity / group-delay artifact, per-metric) or returns `transition_unqualified`; holdout tuning, uncompensated group delay, or phase-capability mismatch cap at `qualified_with_limitations`. `composition_spec_ref` binds the R160 `numerical_hybrid_composition_spec` authority.
