## Summary

Implements #811: a solver result's confidence is now mechanically bounded by the weakest *materially relevant* input authority and by the solver validation domain — a high-fidelity solver with weak boundary/source/geometry inputs can no longer inherit a high-confidence result.

New sealed authority module `cad_solver_confidence_bound.py` (+ `_repository`, six append-only tables, schema v85):

- **Per-dimension input authority records**: `MaterialInputAuthority` (measured complex boundary / measured energy coefficient / manufacturer / fitted / `derived_conversion` pinned to a `BoundaryConversionArtifact` / scalar-absorption-only / undeclared), `SourceDirectivityAuthority` (`provenance_class` kept strictly separate from `format_compliance` — an AES69/SOFA-compliant file is never acoustic quality validation; coverage + angular/frequency sampling + interpolation + frame/normalization retained), `GeometryInputAuthority` (exact revision / as-built / surveyed / simplified / assumed), `PoseInputAuthority` (surveyed acoustic center / measured / intended, plus `modal_sensitivity` — a low-frequency position error is modal sensitivity, not a cosmetic tolerance).
- **`SolverInputEnvelope`** binds a solver request to sha-pinned refs of every input-authority record plus `EnvironmentalBinding`s. `evaluate_input_envelope` resolves refs by id+sha (positional lookup would be a forgery path) and seals one `ClaimBoundRecord` with a row per claim class — no single opaque score.
- **Fail-closed evaluator** (`evaluate_claim_bound`): `unbounded_input` when a required authority is undeclared → `claim_denied` when a declared class cannot support the claim at any level (e.g. scalar absorption feeding `phase_coherent_field`) → `solver_unqualified` when no accuracy envelope covers the claim's observable or the capability manifest marks its phenomenon `UNSUPPORTED` → `solver_bounded`/`bounded_by_input` at the weakest rank's ceiling → `envelope_inherited`. Every non-inherited verdict names `weakest_dimensions` for the operator.
- Dependency-aware environmental staleness: an undeclared aspect stales only claims that materially need it (door state stales coverage/STI, not decay). `late_diffuse_field` demotes material support without ISO 17497-1 scattering evidence; modal-sensitive claims demote unevaluated poses.

Integration: consumes `AccuracyEnvelopeRecord` (per-observable validation state) and `SolverCapabilityManifest` (SUPPORTED is a gate, never accuracy evidence) as the solver-domain ceiling; reuses `BoundaryPhysicalQuantity`/`EvidenceMethodClass`/`DirectivityCoverage` vocabulary — no new provenance terms. JA labels via `CONFIDENCE_BOUND_LABELS` + `measurement_evidence_display` helpers; `_RepositoryChain`/`_ReplayProbe`/`_ROW_BINDINGS` fully wired (`solver_confidence`).

Tests: 44 cases covering every verdict path, weakest-input identification, sha-mismatch/missing-ref failures, append-only conflict, column + payload tamper detection, and JA label coverage. `backend/tests/test_issue_811_confidence_bound.py` plus the v85 ledger row in `test_cad_schema.py`; schema/audit/row-integrity regressions all green locally.
