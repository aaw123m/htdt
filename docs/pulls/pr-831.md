## Summary

REV63/#813: owned-room holdout campaign authority (schema v90). ASME V&V-20 logic — a prediction is only honest against evidence the model never saw. This seals the minimum field campaign that can close the owned-room context-of-use gap.

Three sealed records:

- `CampaignPreregistration` (`cad_campaign_preregistrations`, crc-) — hash-bound protocol frozen BEFORE holdout acquisition: protocol/version, scene/SystemVariant/solver/adapter/input-authority refs (all sha-pinned), `calibration_condition_ids` and `holdout_condition_ids` (**structurally disjoint**), holdout dimensions (receiver/seat/config/candidate/source/independent-session), positions, candidates, metrics, uncertainty method, decision thresholds, allowed exclusions, stop conditions (required — a campaign must be allowed to conclude failure), environmental requirements, spatial claim. `supersedes_campaign_ref` + `leakage_reason` are pair-required: holdout leaking into calibration forces a new campaign identity, never a quiet reuse.
- `CampaignMeasurement` (`cad_campaign_measurements`, crm-) — declared role (`calibration`/`holdout`/`repeatability`/`perturbation`/`screening`) + raw asset sha256 + full measurement authority (#813 §7): mic calibration, calibration file, SPL calibration (required when `claims_absolute_level`), routing, AVR/DSP state, position/orientation authority, uncertainty budget, quality report.
- `CampaignVerdict` (`cad_campaign_verdicts`, crv-) — separate `ClaimVerdict`s per claim family: absolute/shape/modal/arrival vs candidate direction/ranking/pareto/robustness (passing verdicts require pinned evidence). Nine promotion gates; `recommendation_eligible` structurally requires every gate pinned + zero stale refs; trend/domain/eligible outcomes require `holdout_residual_ref`.

`evaluate_campaign_promotion(prereg, measurements, verdict)` — fail-closed ladder: `not_evaluated` → `external_only` → `owned_room_insufficient` (missing prereg, prereg after earliest holdout acquisition, holdout↔calibration leakage, missing repeatability/uncertainty/separation pins, stale refs, no decision-claim pass) → `owned_room_absolute_prediction_limited` (decision pass + absolute fail — common bias doesn't kill decision usefulness) → `owned_room_trend_validated` → `owned_room_domain_validated` → `recommendation_eligible`.

Tests: `test_issue_813_owned_room_campaign.py` — 19 tests covering disjointness, SPL-calibration requirement, gate requirements, every ladder rung, leakage detection, prereg-after-acquisition rejection, seal/id integrity, repository round-trip + tamper detection. Manifest entry keeps the physical campaign as the manual remainder (VERAUTO evidence path noted).
