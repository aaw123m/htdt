## Summary

Sealed **Decision Brief** authority for #937: converts optimization candidates into a ranked, explainable next-action recommendation without collapsing evidence into a single score and without auto-recommending unverified candidates.

- `htdt/cad_decision_brief.py` — `CadDecisionBrief` (`dbrief-…`) over a pinned scene revision: baseline `AuthorityRef`, ranked `DecisionAction`s, derived `top_tier`/`ready_count`/`ranking_explanation`. Each `DecisionAction` (`dact-…`) carries five declared-order `DecisionGate`s (`solver_gate`, `channel_verify`, `deployment`, `campaign`, `production_gate`) whose `DecisionEvidencePin` + observed verdict derive `tier` (`ready`/`conditional`/`not_ready`), `disposition` (`recommended` ⇔ ready only; else `requires_verification` = 要検証の候補), and precise `gaps` (`evidence_missing`/`evidence_stale`/`verdict_failed`/`not_comparable`). Tier/gaps/disposition/rank are re-derived in validators so a forged tier can't survive construction; only `ready` may carry `apply_candidate` recommendations. `build_decision_brief` re-ranks deterministically — same inputs → byte-identical `brief_sha256`. `DecisionCost(state='unknown')` forbids any amount/provenance; `known` requires full provenance. `brief_freshness` reports `stale` when the pinned revision no longer matches the head so old conclusions aren't re-shown.
- `cad_decision_brief_repository.py` + native schema **v113**: new `cad_decision_briefs` table (DDL + migration + `NATIVE_SCHEMA_TABLES` + `_ROW_BINDINGS` + audit `_ReplayProbe`/`_RepositoryChain` + JA lifecycle label + schema ledger row). `save_brief` re-resolves every pinned/identity ref via `ExactAuthorityResolver`; reads re-resolve resolvable identity refs.
- `decision_brief_panel.py` wired into the optimization workspace 比較 page: renders the newest brief (freshness banner, tiers, per-action gates/gaps/deltas/cost/recommendation) and 「最新の比較セットから再計算」 composes from the latest `DesignComparisonSet` — declared-pins only, so composed briefs honestly land `not_ready`/`evidence_missing` until real gate verdicts are wired; no fabricated recommendations.

Tests: `backend/tests/test_issue_937_decision_brief.py` — 28 cases covering every tier/gate/gap path, deterministic byte-identical briefs, blocked-with-gap honesty, seal forgery rejection, repository round-trip + tamper detection; all pass, plus `test_cad_schema`/`test_authority_audit_coverage`/`test_native_row_integrity` green.

Doc: `docs/issues/issue-937-decision-brief.md`.
