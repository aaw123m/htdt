## Summary

Speaker directivity-balloon overlay for the 3D room viewport (#1000): pick a speaker and see its *measured* per-frequency relative-level balloon, oriented by the speaker's installed aim so aim-vs-measurement mismatches are visually obvious.

**Authority chain** — nothing is synthesized:
- Equipment binding comes from `SpeakerInstallationContext` (`CadInstallationContextRepository`); datasets come from `CadDirectivityRepository.list_datasets_for_definition`, which re-verifies the bound equipment def, the managed source asset, and the recorded import replay on every read — missing asset / tampered row → `blocked`, fail closed.
- Orientation keys to `entity.aim_xyz` through the same `explicit-aim-body-up-source-frame-1` convention as the coverage evaluator (`cad_coverage._source_frame`): aim is the acoustic reference axis; body +Z supplies only roll. `aim_xyz is None` → honest UNKNOWN wireframe, never a guessed direction.
- `CadAcousticAimState` axes (design / as-built / cabinet) draw as separate arrows next to the installed aim; ≥0.5° divergences surface as JA notices.

**Display honesty**:
- Exact measured grid frequencies only — off-grid requests are `blocked`, never interpolated.
- Vertices sit at declared grid angles, each round-tripped through `direction_to_directivity_angles`; cells the declared semantics cannot reach are reported as `unreachable_under_declared_semantics` gaps, not drawn wrong.
- Faces span only complete measured quads (grid-like `signed_180` seam bridging only, matching `_periodic_bracket`'s bound); `hv_cuts_suspect`/partial grids render measured point clouds; `full_sphere_grid` renders a `pv.PolyData` surface + grid points.
- Radius is a display mapping `r = r_min + (r_max−r_min)·clamp((gain−floor)/(0−floor))` of *relative dB* — labeled as such; never physical distance, SPL, or a propagated field.
- ~6000-vertex budget: denser grids index-decimate with a recorded `decimated` gap — LOD never fabricates samples.

**Overlay discipline**: `RoomDirectivityOverlayController` (Qt-free, `room_directivity_overlay.py`) re-reads `current_head` per render; the cache key pins head revision + content hash + every bound authority identity (context sha, dataset payload hash, asset presence, aim sha), so scene edits/authority changes lapse the drawn balloons. Viewport pair `render_directivity_overlay`/`clear_directivity_overlay` under the new `directivity-` prefix in `_OVERLAY_ACTOR_PREFIXES` (non-pickable, swept with all overlays); `RoomDirectivityPanel` in the placement column (toggle, speaker/exact-frequency/floor combos, JA status + disclaimer); wired in `RoomWorkspace._render` for placement/acoustics contexts with 音響 overlay on.
