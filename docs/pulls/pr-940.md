## Summary

Implements #891 — a versioned, provenance-safe **Reference Theater** fixture plus a deterministic self-test lane that exercises the whole sealed-authority pipeline on a fresh install.

**Fixture.** `reference_theater_v1.json` ships a bounded real-shaped theater project (`doc-reference-theater-v1`: 5.4×4.2×2.6 m room, 6.1 speaker layout, seats, screen, declared equipment/materials/measurement evidence/optimization candidates) plus a *simulated* `avr-lan` deploy spec and a real sealed `CadCalibrationExportSnapshot`. `REFERENCE_THEATER_MANIFEST` (`rtman-…`) pins the payload's canonical content sha256, the expected `scene_content_hash`, and the export semantic hash; `load_reference_theater_payload` and `materialize_reference_theater` fail closed with `ReferenceTheaterDriftError` on any pin mismatch — including a divergent user-edited HEAD under the fixture's document id. Fully synthetic: no customer/proprietary data (provenance block in the manifest).

**Lane.** `run_reference_theater_self_test` walks `open → authority → analysis → compare → deploy → verify → export`, landing a step verdict (`verified|diverged|unverified|unauthorized|blocked|skipped`) per step and rolling up to `passed|failed|unauthorized|blocked|fixture_drift`. Deploy runs the real `DeploymentPipelineService` over `FakeAvrLanTransport` — `deploy_is_simulated=True`, `deploy_evidence_strength='machine_readback'`; no real-device claim. The result seals as `CadReferenceTheaterRun` (`rtrun-…`) into the new `cad_reference_theater_runs` table (native schema v111, `_migrate_110_to_111`, row bindings, `_RepositoryChain`/`_ReplayProbe` wiring, JA lifecycle label `リファレンスシアター検証`).

**CLI.** `htdt selftest run [--fixture-version rt-v1] [--authorize-apply OP] [--out PATH]` — sealed verb, dry-run/`unauthorized`/`blocked` exit lattice matches the other lanes; `records list/export --kind reference_theater_run` reads the runs.

**Hooks.** #886 first-run wizard gains an `offer_reference_theater` offer on stage 1 (intent wiring only — materializes the fixture and switches to it). #867: `reference_theater_benchmark_entry()` exposes the versioned fixture as a stable benchmark manifest entry.

Tests: `test_issue_891_reference_theater.py` — every step/outcome path, seal + repository tamper detection, CLI lattice, wizard gating, Qt-free headless import probe. Verified locally: 24 new tests plus the schema/row-integrity/authority-audit/wizard/headless-CLI batteries (222 tests) all pass.
