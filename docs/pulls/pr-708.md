## Summary

REV57-INST adds four append-only sealed-record authority modules to HTDT's native CAD database (schema v40, 16 tables + replay/integrity/UI wiring), covering the installation/commissioning slice of the REV57 program:

- **#616 HVAC co-design** (`cad_hvac_authority` / `cad_hvac_repository`): a duct path is only "qualified" when *both* acoustic contribution and ventilation adequacy hold — a quiet but under-ventilated path is `ineligible_airflow`, and lab evidence never becomes installed truth.
- **#618 Playback reference calibration** (`cad_playback_reference_authority` / `cad_playback_reference_repository`): reference-calibrated SPL claims need an exact stimulus, complete meter semantics, and a declared tolerance — undocumented AVR-internal tones cap at `device_profile_only`, and the LFE +10 dB figure is in-band reproduction gain, not a broadband meter delta.
- **#631 As-built treatment** (`cad_treatment_asbuilt_authority` / `cad_treatment_asbuilt_repository`): per-parameter evidence states (`field_measured`/`hidden_unverified`/…) — deviations mark the acoustic prediction `stale`, and a substituted product is a deviation even with matching αw datasheets.
- **#612 Tactile / seat vibration** (`cad_tactile_vibration_authority` / `cad_tactile_vibration_repository`): seat vibration is measured at the seat, never inferred from transducer watts; occupancy and physical timebase are part of the measurement identity; building coupling is judged independently.

## Literature basis

- **ASHRAE duct acoustics**: insertion loss, regenerated noise, and pressure loss kept as distinct silencer terms; ISO 7235 (laboratory) vs ISO 11820 (in-situ) methods strictly separated; a bare broadband loss scalar cannot construct a quantitative path leg — band-by-band data or an explicit `unsupported` marker is required.
- **Ventilation co-design**: required airflow is a declared scenario (`CadVentilationScenario` with occupancy/loads/requirement source), never an HTDT estimate; under-ventilation fails independently of noise performance.
- **SMPTE / THX / ITU BS.775-4**: test-signal level → device output → listening-position SPL is one calibration chain; channel trim, weighting/time/integration semantics, and the LFE channel's +10 dB *in-band* reproduction gain are separate axes. Redirected bass and bass-managed sums are never conflated with native LFE.
- **ISO 354 / 11654 / 20189**: laboratory ratings bind their mounting/specimen condition; field substitution is not equivalence; hidden build-up (air gap, backing) stays UNKNOWN rather than being promoted by surface appearance.
- **ISO 2631-1/-2**: seat acceleration measured per axis/contact point; ISO 2631-1:1997+Amd is the current profile while the FDIS Ed.3 draft is `research_only` and cannot carry production targets; ISO 2631-2:2026 building-domain coupling is an independent outcome — a good seat never hides structural transmission.
