## Summary

REV63/#801: the product-level credibility gate (schema v91). One sealed adoption decision binds the entire production-readiness chain — equipment authority → #813 preregistered campaign → calibration/holdout/repeatability → #809 solver qualification → #810 residual evaluation → #811 applicability → adoption → recommendation enablement. Software PASS is never presented as physical-model validity: this authority binds the landed answers, never claims them.

- `ProductionReadinessDecision` (`cad_production_readiness_decisions`, prd-) — `scene_ref`/`system_variant_ref`/`equipment_authority_refs`/`solver_version_ref` all sha-pinned; `outcome` ∈ `no_go`/`limited`/`production_ready` with `outcome_rationale` required even for failures (auditable NO_GO, never implicit fallback). `production_ready` structurally requires `campaign_ref` + `solver_qualification_ref` + `residual_evaluation_ref` + `applicability_ref`; `limited` requires campaign + qualification; a `hybrid` solver path additionally requires the #812 `hybrid_validation_ref` (and a non-hybrid path may not carry one); any `stale_authority_refs` rejects `production_ready`.
- `RecommendationSurfaceDecision` (`cad_recommendation_surface_decisions`, rsd-) — issued enablement map for `inspect_prediction`/`compare_candidates`/`automatic_recommendation` (same tokens as #814). `automatic_recommendation` may only be `enabled` when `outcome_at_issue == 'production_ready'`.
- `evaluate_surface_enablement(decision)` derives the canonical map (ready → all enabled; limited → inspect enabled/compare limited/auto disabled; no_go → all disabled); `verify_surface_decision` replays it and raises `ProductionReadinessIntegrityError` on forged or stale maps; `issue_surface_decision` composes the canonical record.

Tests: `test_issue_801_production_readiness.py` — 17 tests covering full-chain requirement, hybrid extra gate, stale rejection, limited minimum, surface derivation + replay verification, forgery/outcome-drift detection, seal/id integrity, repository round-trip + tamper detection. Manifest keeps the first real adoption decision (after the #813 physical campaign) as the manual remainder.
