## Summary

Round-7 review pass on spec inconsistency and API/docs usability (report: `docs/reviews/round7-docapi.md`). The legacy FastAPI surface is dev-only, so the changes split between (a) safe additive filters the UI was missing, and (b) real parity fixes on the **production** capture-receiver HTTPS surface.

**API usability (legacy `main.py` + `database.py`):**
- `GET /api/projects/{id}/measurements` gains `?context_id=` and `?session_id=` — the UI was fetching every row and filtering client-side (`MeasurementSessions.tsx` does `measurements.filter(m => m.session_id === ...)`). Unknown/foreign entity ids → 404, same convention as the existing `constraint-sets`/`search-specs` `context_id` filter.
- `GET /api/projects/{id}/attachments` gains `?context_id=`, `?measurement_id=` (both 404-checked) and `?kind=` (validated by the `AttachmentKind` Literal → 422 on bad values).

**Capture receiver parity (production surface):**
- `POST missions/{id}/receipt` now requires `X-HTDT-Capture-Instance-ID` like `GET missions`/`GET missions/{id}` — previously a receipt with no header skipped the pairing's device binding entirely.
- `GET .../capabilities/<suffix>` and `POST .../deliveries/<suffix>` now 404 instead of silently ignoring trailing path segments, matching the strict `missions` routes.

**Script fix:**
- `scripts/run-local.ps1` was broken: it invoked `python -m htdt` bare, which exits 2 without `--data-dir`/`--allow-default-data-root` (the #598 isolation guard). Now takes `-DataDir` defaulting to repo-local `.local\dev-data` (gitignored via `.local/`).

**Verified clean, unchanged:** uniform `{'detail': ...}` error shape on both HTTP surfaces; round-4 error-code mapping holds; snake_case everywhere; no PUT/PATCH/DELETE; only unbounded route (`search-specs/{id}/generate`) already paginates; all doc claims spot-checked (README commands/flags, REW_API endpoint table, version chain, doc links) are accurate.

Tests: `backend/tests/test_review_round7_docapi.py` — 7 new regression tests covering each fix. Full suite: 5305 passed, 1 failed (`test_ctrl_s_commits_focused_inspector_position` — confirmed failing on unmodified `main`, preexisting GUI regression unrelated to this branch).
