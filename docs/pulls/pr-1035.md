## Summary

Implements #999: projects the sealed `SpatialFieldResult` into the Room 3D CAD viewport — grid-aligned colored slices, iso contour, conditional volume, and a 3D probe — with bounded display budgets and sha-pinned staleness.

**The confirmed defect:** `field_explorer_panel` judged session currency against the session's *own pinned* `SceneRevision` (`scene_repository.get(session.scene_revision_id)`), so STALE could never trigger — a field built on an old head stayed "最新" forever. Both `refresh_sessions` and `_load_session` now compare against `scene_repository.current_head(document_id)`, and `refresh_sessions` re-validates the loaded session (the head can advance without a session switch).

**New layers:**
- `field_volume_visual_adapter.py` (Qt/VTK-free): `SpatialFieldResult` + live head → `FieldDisplayView`. Canonical `(iz*ny+iy)*nx+ix` order ≡ `reshape((nx,ny,nz), order='F')`; domain +Y maps to render −Y by reversing the sample axis and moving origin to `-(oy+(ny-1)*dy)` so VTK spacing stays positive. `clim` is computed on the **full-resolution** quantity values before display decimation; `FIELD_DISPLAY_POINT_BUDGET` (1M) is separate from canonical `MAX_FIELD_SAMPLES`; budget-collapse and unsupported quantities fail closed via `FieldDisplayBlocked`.
- `room_field_overlay.py` (Qt-free): `RoomFieldOverlayController` holds the armed `FieldOverlay3DRequest`; `resolve()` re-checks the live head every frame — STALE/UNKNOWN blocks instead of painting an old field.
- `RoomViewport3D.render_field_overlay` / `clear_field_overlay`: `acoustic-field-*` actors (`pickable=False`, swept by `_OVERLAY_ACTOR_PREFIXES`), content-keyed `ImageData` cache, honest `add_volume` GPU fallback (`ボリューム表示不可 → 断面のみ`), status header naming producer/mode/freq/run/revision + normalized-display honesty.
- Panel `3D CAD表示` group (`音場を3D表示` deep link) → workspace gating on acoustics context + overlay ON + CURRENT head; probe clicks intercept selection only in probe mode; Esc disarms.

**Tests:** `test_issue_999_field_viewport.py` — 19 tests (head-currency, axes/flip correspondence vs canonical samples, decimation clim, fail-closed paths, slice/iso/probe, panel + viewport cleanup offscreen). Existing `test_cad_field_explorer.py` and `test_room_viewport_semantics.py` stay green.
