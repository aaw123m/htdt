## Summary

Automates the objective parts of the UX160 acceptance matrix (#804) as an evidence runner plus a sealed authority. A retained bundle record is *evidence* — it never claims the row is accepted; visual/subjective criteria stay a human gate.

- `scripts/ux160_acceptance_run.py` — one command records one matrix row: build/commit/dirty/toolchain/screen/GL binding (#833 pattern), launch+reset to a required state, golden-path checkpoints via the existing `ux160_driver` stable hooks (navigate/geometry/overflow/focus/disabled-reasons/palette/reopen) — no pixel macros. Output is a deterministic bundle per row at `<work>/<matrix>/<row>/attempt-<NNN>/` (`manifest.json`, `shots/`, `report.md`, driver result+log, `clean_exit.marker`) plus a stable `latest.json` pointer carrying `{bundle_ref, bundle_id, bundle_sha256}` — the ref surfaces like `scripts/issue_lifecycle.py` can wire to (those manifests intentionally untouched).
- `cad_ux_acceptance_evidence*.py` — `CadUxAcceptanceBundleRecord` (`uxbnd-<sha>`) + `CadUxAcceptanceEvidenceRepository` on `_SealedStore` (new table `cad_ux_acceptance_bundle_records`, schema v104 with `_ROW_BINDINGS`, `_ReplayProbe`, `_RepositoryChain`, JA label, ledger row).
- Vocabulary stays honest: `verdict ∈ {evidence_captured, capture_incomplete, capture_failed}` describes capture state only; `review_state` is structurally `manual_review_remaining` whenever the 4-item manual checklist is non-empty (overclaim rejected at record validation); `offscreen_fixture` bundles must carry an offscreen non-claim. Findings never downgrade a verdict — a finding *is* captured evidence.
- The VTK/GL probe runs in a subprocess so a native crash (observed on this box: access violation) degrades to a fail-closed `probe_crashed(rc=…)` string instead of killing the run.
- Runner exit codes: `0` captured / `3` incomplete / `2` failed; `--profile offscreen-fixture` is the bounded self-test lane (non-VTK destination subset) used by tests.

Tests: `test_issue_880_ux_acceptance.py` — every verdict/state path, seal/id integrity, repository round-trip + tamper detection, bundle assembly + attempt allocation + baseline compare, audit/row-integrity wiring, and a real offscreen self-test that boots the composition and produces a sample bundle (14 tests, all pass; audit/schema suites 72 pass). Device-only remainder (real DPI rendering, pointer feel) is documented in `docs/issues/issue-880-ux-acceptance-evidence.md`.
