## Summary

REV50-PERFUX sweep on `ka0923s-a11y/HTDT`: compute-load, speed, design-break and usability findings, with HIGH/MED implemented and before/after measurements (sqlite statement counts + wall time, same fixture: 50 evaluations / 2 pareto sets / 7 runner plans / 2 speakers / 8 joint specs).

### Backend compute load

- **Journey counters were replaying full authority.** `OptimizationWorkflowWorkspace._refresh_journey` did `len(list_evaluations)` etc. just to show counts — each `list_evaluations` replays per-evaluation attestation. Added metadata-only `COUNT(*)` reads: `count_evaluations` (489ms/203 stmts/51 conns → 2.9ms/2/1), `count_pareto_sets` (170ms/72/23 → 5.9ms/2/1), plus `count_for_search_spec` on the campaign and model-validation repositories. Docstrings follow the `count_candidates` "metadata only, never for payload claims" contract.
- **`assess_spec_staleness` re-resolved the baseline per spec.** `_refresh_saved_specs` loops it over every saved joint spec — 8 specs meant 8 full baseline resolves (resolve_baseline → `latest_evaluations_by_candidate` → full replay). New `baseline=` keyword (`_UNSET_BASELINE` sentinel keeps lazy single-spec callers unchanged); the panel resolves once and shares. 8 specs: 3904ms/1720 stmts/440 conns → 263ms/215/55 (~15×).
- **`runner_progress` re-read and re-checked inline.** New `CadMeasurementRunnerRepository.progress_for_run` returns `(plan, cell_states)` in one read with the same fail-closed checks; `MeasurementWorkflow.runner_progress` just wraps `RunnerError`. 22ms/12/5 → 10ms/7/3.
- **Install summaries were 2×N per-entity queries.** `latest_bindings_for_document` / `latest_contexts_for_document` batch reads (ORDER BY seq DESC, first row wins) with shared head/definition decode caches; used by `InterventionPlannerPanel._refresh_install_summary` and `InstallationRecordSurfaces.reload`. 2 speakers: 32ms/22/10 → 28ms/17/8, and constant vs. N-scaling.
- **Runner plan listings decoded every document's payloads.** `list_plans`/`list_plan_created_at_utc` now filter `WHERE json_extract(payload_json,'$.document_id')=?`; created_at reads no longer decode payloads at all.

### Design breaks

- **`音場エクスプローラー…`-style disabled buttons were nearly invisible** (reported): `QPushButton:disabled, QToolButton:disabled` had a transparent border on a disabled surface `#181E25` vs base `#141A21`. Border now uses `separator` (#2A3542).
- **`GeometryImportDialog` content was ~1130px** — `resize(680,720)` hid the lower groups and the import button. The four group boxes now live in a `QScrollArea` (buttons pinned outside). `ProjectorSpecDialog` (738px measured) got the same treatment (sizeHint 738→336px).

### Unit consistency (#496)

- `room_video_panel`: 16 metre fields (screen/display aperture, offsets, frame clearance, sightline clearance, seat eye/head Z + head radius) and `DisplaySpecDialog`'s 5 chassis/active-area fields are now `MetricSpinBox` — SI metres stay authoritative, display unit follows the length policy. `bind_length_policy_widget(workspace.video_panel, preferences)` wired in `_make_room`; the dialog inherits `video_panel.length_policy()`; seat rows rebuilt on signature change re-apply the stored policy. `room_workspace` pose save/load reads/writes `value_m`/`set_value_m`.
