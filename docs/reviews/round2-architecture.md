# Round 2 review — Architecture, consistency & dead code

Branch: `devin/rev2-arch`. Scope: `backend/src/htdt` (591 modules) plus
`backend/tests`, `frontend/`, `scripts/`. Picks up the round-1 deferred
items (`docs/reviews/round1-architecture.md`) where they were mechanical
and behavior-preserving, plus new findings.

## Verified clean (no action)

- **Top-level runtime import cycles**: still none; deferred-import convention holds.
- **canonical-JSON equivalence**: every aliased/delegating wrapper produces byte-identical output to the leaf, including the `ValueError` fail-closed on NaN/Infinity.
- **pydantic aliasing audit**: none of the 30 migrated classes has a second aliased field, so `serialize_by_alias=True` only renames `schema`; no `field_validator('schema')`/`getattr(m,'schema')`/`model_fields['schema']` references exist.
- **`_connect` variant safety**: the 25 non-delegated defs verified to differ in contract (no-FK, `closing`, `str()`/`db_path`, read-only URI), not just formatting.
