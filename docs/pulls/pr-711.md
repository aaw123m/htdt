## Summary

#620: CAD placement never implies mountable. This adds a fail-closed
mounting/structural-support evidence authority: seven sealed records
(`cad_mount_assemblies` / `cad_mount_load_evidence` /
`cad_mount_support_elements` / `cad_mount_manufacturer_requirements` /
`cad_mount_structural_approvals` / `cad_mount_inspection_records` /
`cad_mount_qualifications`) plus `evaluate_mounting_support`, a
deepest-defect-first verdict ladder:

`stale_after_change` → `manufacturer_mounting_incompatible` →
`support_unknown` → `as_built_mismatch` → `support_capacity_insufficient`
→ interference conflict → `structural_approval_required` (overhead
suspension without professional approval; suspended-loudspeaker layer
unknown; isolation mount without professional; no approval bound at all)
→ duty uncovered → `installation_inspection_required` →
`approved_with_limitations` → `design_support_evidence_complete`.

Design anchors on the issue:

- Assembly = equipment (kind `installed_instance`, sha-pinned) →
  per-component mount hardware (role/manufacturer/model/
  `identity_state` declared vs verified_observed) → secondary
  retention → duty state → cable-route pins (`cable_run`) → pose.
- Declared demand vs declared capacity only — `CadDeclaredCapacity`
  pins (value, unit, source class, document); HTDT never derives
  structural capacity from BIM/scan geometry (`geometry_ref` is an
  evidence pin, hidden conditions stay `inaccessible`/`unknown`).
- Suspended loudspeakers keep the three §7 layers independent:
  enclosure capability (E1.8/manufacturer rated), building support
  point, field rigging assembly. E1.8 enclosure evidence never
  approves the support point; `suspended_ceiling_grid` can never be
  `verified` support (validator-rejected).
- Approval evidence classes separate manufacturer instructions,
  engineer/professional/permit/proof-test (professional-tier),
  rigging-standard profile (sha-pinned `standards_profile`, #599
  binding), installer declaration, field inspection, and
  assumed/unknown (which cannot carry declared ratings).
- `duty_coverage` (`static_only`/`static_and_dynamic`/`moving_system`)
  keeps motorized/moving equipment from inheriting static-only
  qualification.
- Inspection records carry per-point observations +
  `inaccessible_points` + `next_due_at_utc`; findings='pass' rejects
  mismatch/absent observations. No invented inspection intervals.
- `substitution_flags` (mass/CG, mount, support point, orientation,
  duty, equipment identity) produce `stale_after_change` — the #596
  invalidation input.

Literature basis (per issue research): ANSI E1.56-2026 rigging support
points (supersedes 2018; support point as separately-documented
element), ANSI E1.8-2018 (R2023) loudspeaker-enclosure suspension
(enclosure ≠ building structure), ANSI E1.47-2020 inspection guidance
(2026 revision stays a separate #599 profile), AVIXA AV/IT higher-ed
2021 (structural-engineer review for fall-hazard equipment — overhead
suspension requires professional-tier approval, not installer
declaration), VESA interface patterns (declared mismatch check).
Local code/jurisdiction stays external free text on the approval
record — HTDT embeds no building code.

Schema: native v40 → v41 (`_migrate_40_to_41`, baseline DDL +
`NATIVE_SCHEMA_TABLES` + audit replay probes + row-integrity bindings
+ lifecycle JA labels + `mounting_qualification_line` display).

Tests: `backend/tests/test_rev57_mount.py` (23 tests) — MNT10–MNT70
issue scenarios, validator rejections, full verdict ladder,
repository round-trip + tamper IntegrityError; schema/audit/
row-integrity regressions green.
