## Summary

Adds the #978-style search/filter idiom to `StandardsCriterionPanel` (the 配置基準 panel in RoomWorkspace's right dock) so a crowded evaluated-standards list can be narrowed before opting criteria into `explicit_hard_constraint_gate`.

- **Controls** (new rows above the tree): `standardsSearch` QLineEdit (cross-field, casefold — name/id/quantity/publisher/document_title/reference/raw + JA domain labels via `_criterion_search_haystack`), `standardsStatusFilter` (全て/適合/不適合/判定材料不足/対象外/未評価/制約に選択済み), `standardsDomainFilter` (built per-profile from `applicable_domains`), `standardsFilterReset` (enabled only while filtering), `standardsResultStatus` count line.
- **Result line** leads with the hidden-selection warning: `フィルタ外の制約選択 K 件 · 基準 N 件 · 制約選択 M 件 · 表示 X/N`. Checked-but-filtered-out criteria stay in `_selected_constraints` (criterion_id-keyed) and keep blocking the gate — the K件 count makes that visible instead of silent.
- **Tree** keeps its original 5 column indices; 領域 (5) and 出典 (6) are appended at the tail. Zero-match and empty-profile states render as a spanning disabled row (`setFirstColumnSpanned` **after** `addTopLevelItem` — pre-insert is a silent no-op).
- Narrow-dock legibility: controls split across three compact rows to keep `minimumSizeHint` under the ~280px budget (`test_placement_column_content_stays_inside_right_stack`), and リセット sits at the left of the result row so dock h-scrolling can't clip it.

No new decision authority: verdicts still come only from `evaluate_standards_profile`; the gate is still `explicit_hard_constraint_gate`.

Refs #972
