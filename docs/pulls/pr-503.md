## Summary

R150 slice (b): a bounded **stochastic-ray receiver estimator** for geometric acoustics, following the REV35-R150 (#491) lane pattern — separate module, own policy authority, own engine marker/artifact/table/repository, fail-closed gates.

The stochastic lane **rides the deterministic GA dispatch** (request still resolves `('deterministic_paths',)`), then runs a seeded Monte-Carlo trace whose energy semantics are declared as `monte_carlo_point_estimate_with_convergence_evidence` — an estimate, not an upper bound. Registered as engine `htdt.r150.stochastic_ray_receiver_estimate` v1 so canonical exact-path engines are untouched (a dedicated bit-stability test asserts `_execute` output is identical before/after).

### Estimator (`cad_stochastic_ray_receiver.py`)

- Per-ray direction from a sha256 counter stream `(seed, ray_index)` → uniform on the sphere; per-band emission weight = `directivity.energy_factor`; each specular bounce applies `specular_energy_factor`; occluders absorb; open portal apertures transmit (consuming an interaction slot); receiver captures on first-leg closest approach within the declared capture radius.
- Estimate `E = 4·Σw / (r²·N)` reproduces the deterministic `w/L²` inverse-square convention.
- Convergence evidence: per-level prefix accumulators over the declared `ray_budgets`; `deviation = |E_last − E_prev| / max(E_prev, floor)`; verdict `WITHIN_DECLARED_BOUND` / `OUTSIDE_DECLARED_BOUND` / `NO_EVALUABLE_ESTIMATE` recorded on the artifact.
- Gates: policy bounds (budgets strictly increasing within [64, 10⁶], bounces ≤ 8, capture radius > 10×tolerance and ≤ 0.25×min scene extent), single-region or explicit-list portal topology, kernel-identity engine check, region membership evaluated on raw triangle shells incl. portal aperture fans.
