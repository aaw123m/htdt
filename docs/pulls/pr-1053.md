## Summary

Finishes the #1017 residual on top of #1023 — the ActivityPage could still hide deep history behind a fixed window and offered no per-event typing or detail. Three gaps closed, all #1023 invariants kept:

- **期間 gains arbitrary bounds.** Fifth option `期間を指定` arms two `QDateEdit`s (`range_start_edit`/`range_end_edit`, yyyy/MM/dd calendar popup, inclusive `start ≤ occurred_at_utc < end+1d`); any other option disables them so stale bounds can never silently narrow a preset view.
- **Numbered pages → cursor load-more.** `_pager` became `_more_pager` (`さらに読み込む` + `全N件 · X–Y件を表示`, latest-50 initial window kept). Timeline continues from the last shown `(occurred_at_utc, event_id)` pair in the freshly filtered projection — arrivals at the top can never duplicate/skip rows. Revisions walk a keyset SQL cursor via new `list_revisions_page` (`seq < ?`, `LIMIT limit+1` lookahead, opaque `'seq:<n>'` token, fail-closed `ValueError` on garbage) — stable under concurrent commits where OFFSET windows drift.
- **Read-only 出来事の詳細 inspector.** `event_evidence_class` types every event: `evidence` (default) / `assumption` (operator-attested applies: as-built, calibration/preset) / `historical` (inherited, 非ヘッド履歴 detached revisions, superseded captures) / `failed` (rejected capture) / `note`. 「メモ」is a document, not canonical proof — its gloss says so. Panel shows 時刻/プロジェクト/種類, 区分, 内容, 詳細, primary `source_ref` (`kind: ref_id（sha256 …）`), 相関 refs, event_id with （継承元の記録）— read-only, keyboard-selectable, cleared on empty selection (driven by the selection model, not `currentRow`).
- **`activity_focus` walks to depth** — a deep link to an event/revision older than the window keeps loading more until the row exists (row-growth guard stops a stalled cursor), so the oldest row is reachable instead of reporting missing.

`ActivityPage(list_revisions)` signature changed to the cursor API `(document_id, limit, after) -> (rows, next_cursor)`; `_make_activity` wiring + sibling test lambdas updated accordingly. `list_recent_revisions`/`count_recent_revisions` unchanged.

Doc: `docs/issues/issue-1017-activity-history.md`.
