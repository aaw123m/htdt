## Highlights

**受入検証ウィザード**
- `unavailable`/`deferred` check results merge to `pending` instead of permanently `blocked` — a transient env gap (REW offline) no longer bricks a run.
- `check_persistence_probe` binds `CheckContext.boot_id`: the "restart verified" marker is no longer provable within one process; same-boot → deferred, foreign boot → `verified_after_restart`, legacy markers → re-issued.
- Stale worker results tagged with `run_id` are dropped; step-detail text cleared on step change; page `closeEvent` detaches the running `QThread`; env snapshot records `code_sha` from `git rev-parse HEAD`.

**映像調整**
- `_session_target` fails closed instead of silently substituting the currently selected profile when the session's `target_sha256` can't resolve.
- `_compatibility_reasons` covers patch size / APL / pattern generator / signal path (encoding+bit-depth was the whole check).
- `_max_luminance`/`_min_luminance` restricted to achromatic samples — a blue primary was being reported as 黒床輝度; `_metric_row` gains polarity so `peak_white` changes are `inconclusive` not `regressed`.
- `latest_readiness_report` orders by `rowid` (composite-PK table, no `seq`); `save_proposal` requires a persisted diagnosis; import assembly failures return `malformed` instead of raising; truncated HCFR level rows warn; several workspace selection/rebind UX fixes.

**プレゼン**
- Step replay applies `hidden_ids`/`section`/`focus_entity` — was camera-only, so replayed steps lied about what was shown.
- `build_review_package` takes an explicit `yaw_steps_deg` override; the workspace no longer rebuilds the session with `yaw_step_deg=30`, which made the manifest pin a `session_sha256` no persisted session has. `derived_yaw_steps()` exported.
- Export reads `currentData()`; variant-pinned `as_built` guarded; note save wrapped.

**Auralization** — `verify_review_package` cross-checks each entry's pinned `capability_semantic_sha256`/`routing_sha256`/artifact+spec pins against the embedded payloads (was payload-shape validation only).

**Active LF** — a bounded latency envelope with a silent `total_latency_s` is `UNKNOWN` not `PASS` (`demand_expected`); `lf_control_evaluation_spec` binds the resolved seat ids (`seat-N` fallback) into the spec hash.

**Solver authority** — `build_acoustic_geometry_derivation` rejects `portal_authority=None`/`boundary_termination_authority=None` when the compiled geometry binds the corresponding ref (mirror of the existing check).

**Promotion** — `world_to_scene` resolved per `coordinate_space_id` (was a single space's matrix applied to all annotations); entity scale uses the composed scene transform.

`eps = 1e-6` orthogonality tolerance verified adequate (float32 rotations deviate ~1e-7; ~3–10× margin) — documented, unchanged.
