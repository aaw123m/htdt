## Summary

Three P1 authorities for REV56-BUILDING, all sealed-record + fail-closed, on schema v32 (13 tables):

**#576 — `cad_isolation_authority.py`** (`cad_isolation_authority_repository.py`): room-to-adjacent-room isolation qualification on top of #559's direct-path estimator.

- `IsolationConstructionElement` (`ise:` sealed) carries build-up + `IsolationElementEvidence` (lab TL spectrum / lab rating / field / declared / generic_label — a sales label like "double stud wall" can never carry TL values).
- `InterRoomIsolationScenario` (`irs:`) declares ordered source→receiving regions + transmission-path taxonomy (direct / flanking / floor-ceiling / door / window / duct / penetration / portal / structure_borne / unknown), source stress profile (content class, LFE, per-band source spectrum), receiving criteria, and a fail-closed construction lifecycle.
- `InterRoomFieldMeasurement` (`irm:`) is ISO 16283-1-shaped: banded source/receiving/background levels, RT/absorption normalization, volumes, opening/operating-state anchors. `standard_conformant` is computed — informal measurements persist but cannot drive verdicts.
- `SoundIsolationQualification` (`siq:`): per-band evidence states + LF validity domains — below 100 Hz, bands without measured/modelled backing land in `below_validated_domain` (no Rw/STC extrapolation ever). Declared-but-unmodelled paths demote *modelled* bands to declared and are listed as `limiting_path_ids`; conformant measurements survive demotion because they capture real combined transmission. Receiving SPL is only ever `declared source band − measured banded level difference`, never from single-number ratings. Claimed lifecycle states are verified — `field_measured` without a bound conformant measurement degrades to `as_built_unverified`.
- `IsolationCalibrationRecord` (`isc:`) enforces fit/holdout disjointness by construction.

**#589 — `cad_mechanical_noise.py`**: rattle / structure-borne noise qualification where FR conformance is explicitly *not* evidence.

- `MechanicalNoiseTest` (`mnt:`) binds the exact stress stimulus — `stepped_sine` / `slow_sine_sweep` / `band_limited_noise` / `lfe_program_content` / `single_tone` / `other`; `frequency_response_measurement` is excluded from `RATTLE_STRESS_STIMULI` by construction.
- `RattleEvent` (`rte:`): 11-kind taxonomy, onset level/band, hysteresis/intermittency, repeatability, acoustic + vibration evidence (consumer accelerometers stay `relative_diagnostic` without `calibration_ref`), a `localization_state` machine (suspected → correlated → `confirmed_by_intervention` requires `suspected_object_refs`), and `attribution` separating room objects from loudspeaker self-noise (#192 boundary).
- `RemediationAction` (`rma:`) is append-only with (id, sha) pinned event refs; `MechanicalNoiseQualification` (`mnq:`) only reaches `resolved_*` verdicts via a *retest* at stress level — remediation + no retest = `insufficient_evidence`. Targets above tested level cap the overall verdict at `qualified_with_limitations`.

**#590 — `cad_seating_acoustics.py`**: seating/occupancy authority composed with #1038's solver-gate and ListenerPoseAuthority.

- `SeatAcousticModel` (`sam:`) keeps `SeatGeometryEvidence` and `SeatAcousticEvidence` as **separate layers** — `measurement_grade=True` is rejected for `literature_generic`/`user_assumed`/`unknown` classes; derived `geometric_model_state`/`acoustic_model_state` can never upgrade each other.
- `OccupancyScenario` (`ocs:`) gets a content-derived `comparability_key`; `evaluate_occupancy_comparability` returns compatible/incompatible/unknown so measurements taken under different occupancy can never be compared silently.
- `DirectSoundClearanceEvaluation` (`dce:`) is a geometric *eligibility* gate (not an attenuation estimate): `unknown_geometry` → `occluded` (enumerable reasons: seat_back / preceding_row / bar_furniture) → `clear_with_position_tolerance_risk` (< 10 cm grazing) → `clear`.
- `SeatingCommissioningResult` (`scr:`) reports enumerable failure reasons — EQ cannot fix direct-sound blockage and now cannot hide it either.

## Literature basis (primary sources)

- **ISO 16283-1:2014** — rooms 10–250 m³, 50 Hz–5 kHz; required 1/3-oct bands 100–3150 Hz, optional LF 50/63/80; standard vs low-frequency procedures → `method_profile`, `LF_EXTENSION_BANDS_HZ`, `standard_conformant` minimum evidence.
- **ISO 12354-1:2017** — detailed model 1/3-oct 100–3150 Hz, Annex I extension to 50 Hz with element+junction data; energetic sum of direct Dd + flanking Ff/Fd/Df paths → path taxonomy, junction evidence, `extended_low_frequency_modelled`.
- **ISO 717-1:2020** — single-number ratings are a derived view over the standard bands and say nothing about ~125 Hz-and-below LFE isolation → LF honesty domains.
- **CEDIA/CTA-RP22 v1.2 §8.4, §5.6.3.1** — rattle stress-test procedure; seating occlusion/ear-position requirements → `RATTLE_STRESS_STIMULI`, clearance gate.
- **Temme/Brunet/Keele, AES 127th (2009), AES 129th (2010)** — rub & buzz is stimulus-dependent and invisible to FR/THD sweeps → "FR conformance ≠ no rattle" fail-closed core.
- **Beranek, JASA 99(4) 2458 (1996); JASA 101(5) (1997)** + **Bradley, JASA 99(2) 990 (1996)** — occupied-seat absorption scales with perimeter/area ratio and upholstery class → `SeatingZoneBlock.perimeter_m/occupied_area_m2`, `UpholsteryClass`, occupancy-state evidence separation.
- **Lee & Jeong 2024, Building and Environment 255:111465** — seat absorption varies with position/occupancy/upholstery/under-seat geometry → separate evidence classes.
