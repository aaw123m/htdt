## Summary

Fourth-pass review of REV52's merged changes (PR #560 `_promote/_park` + `_ASSET_TABLES` bundle + fingerprint + `pre_restore_live` journal; PR #561 GA emit + `MatrixRunVerification`; `e7769acf` `NON_BUNDLE_SCHEMA_DOCUMENTS`). Six real defects found — each confirmed by a failing regression test before the fix — plus a set of surfaces verified clean (documented with verification method in `docs/reviews/rev53-pass4.md`).

Defects fixed:

1. **`data_relocation` rollback `os.replace` trap** — the journal rollback leg still used raw `os.replace(parked, source)`, which fails on Windows even when the post-crash `source` residue is an *empty* dir (the forward paths were fixed in REV52, the rollback site was missed). Recovery then cleared the journal and reported the source unrestorable while the generation sat parked. Now routed through `_promote_directory`.
2. **Restore rollback blessed its own staged payload** — when `pre_restore_live.database=False`, the canonical rollback slot was free at evac time, so the interrupted swap's staged db round-tripped through the slot back into live and was adopted as "recovered". `_recover_journaled_swap` now passes `restored_database_sha256`; a canonical-cycled match is re-parked, not blessed.
3. **Journaled-absent assets adopted live** — same rollback ignored `pre_restore_live.measurement_assets` for the canonical slot; an `expected_assets` gate keeps journaled-absent assets parked.
4. **Bundle export/import `relative_path` asymmetry** — export accepted any path under the data root while import pins rows to `measurement-assets/<digest>`; a corrupt row pointing at real bytes at a wrong path exported cleanly but produced an unimportable bundle. Export now pins symmetrically and both sides reject non-`[0-9a-f]{64}` digests before touching the filesystem.
5. **`MatrixProviderVerification.coverage_complete` counted cells, not receiver coverage** — a provider covering receivers the matrix never ran still got `coverage_complete=True` → promotion over-claims validation evidence. Now requires `provider.receiver_responses ⊆ verified_receivers` per entry.
6. **Fingerprint directory components folded only the dir's own stat** — inner-file edits inside a future `is_directory` INCLUDE component would never invalidate the backup fingerprint (latent; today's INCLUDE set is flat files). Now folds a per-member `name:size:mtime` subtree signature.

Verified clean (details in the report): `pre_restore_live` old-journal strict fallback and write-ordering; `save_descriptor` declared-manifest emit idempotency (content-addressed `manifest_id` + dedup); produced-emit narrowing fails closed on undeclared observables; `MatrixRunVerification` mutation detection (per-cell transfer sha + `cell_state_counts` reproduction + terminal-state gate); `NON_BUNDLE_SCHEMA_DOCUMENTS` honesty test covers both rot directions; multi-source-same-provider first-match provably uniform.
