## Summary

Round-11 visual/design audit of the Qt app (JP-localized) + legacy SPA, verified by offscreen renders at 1366×768 and 1024×768 plus `minimumSizeHint` measurements. Full writeup: `docs/reviews/round11-design.md`.

Two structural defects dominated; both are fixed:

1. **The window's minimum height grew past the screen, permanently.** `QStackedWidget.minimumSizeHint` is the max over all children, and the router mounts workspaces lazily — after visiting Room the shell minimum was 1366×**950**; after Optimization→比較, 1366×**1267**, on a 768px screen. The comparison page and the acoustics tab stack were the only unscrollable surfaces in their chains; both are now `widgetResizable` scroll pages. Shell minimum after mounting *everything* is now 885×544.
2. **The fixed-width right dock (248–320px) hard-clipped content.** Several pages used `ScrollBarAlwaysOff` and the geometry/acoustics panels had no scroll wrap at all — anything wider than ~300px was unreachable. All dock pages now scroll honestly (`ScrollBarAsNeeded`, new `_dock_scroll_page()`); `set_context` targets the wrappers.

Contained fixes along the same axis:

- `Vector3Editor` had a circular layout bug: `_WIDE_BREAKPOINT = 278` could never trigger because the wide layout's own ~500px minimum kept the widget ≥570px inside the dock. Now `minimumSizeHint()` reports the 162px narrow floor and `_relayout` compares against `_wide_minimum()` — the stacked layout actually engages.
- Standards + prediction combos no longer impose 386–641px minimums (`setMinimumContentsLength(12)` + `AdjustToMinimumContentsLengthWithIcon`).
- `TreatmentDefinitionDialog` shadowed `QWidget.width()`/`height()` with `self.width`/`self.height` spinboxes (callers got `TypeError`); renamed `width_m`/`height_m`.
- Projects/Activity timestamp columns elided (`2026-09-28T1…`) because only column 0 stretched — non-stretch data columns are now `ResizeToContents`.
- Objects-panel 5-button row → `ControlSize.COMPACT`; video section heading wraps; 診断 checkbox caption shortened into label + wrapped note.
- The one hardcoded UI-text color (`#b45309` stale warning) → `set_semantic_state(SemanticState.WARNING)`.

Regression tests in `backend/tests/test_round11_design.py` (shell-min bound, scroll-wrap invariants, Vector3Editor dock fit, dialog accessor contract, combo caps, table resize modes). All pass; affected suites re-run green. `npm ci && npm run build` pass.
