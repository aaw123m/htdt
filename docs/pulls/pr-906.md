## Summary

Implements #883 (REV67): crash-safe autosave + deterministic session recovery. The app now journals unsaved state to a bounded, SHA-256-chained, append-only journal per session (`<data_dir>/session-journal/<id>/`), classifies how each previous session ended strictly from evidence, and surfaces a recovery offer at launch — while the canonical sealed authorities remain the source of truth and are never overwritten by recovery.

**New modules**

- `session_recovery.py` — `SessionJournal` (envelope + `journal.jsonl` sha-chained entries + hashed sidecar payloads; secret-key rejection; compaction + retention), `classify_session_ending` (evidence-ordered: `clean` → `incompatible` → `still_running` → `os_restart_or_power_loss` → `application_crash` → `forced_termination`), `inspect_recoverable_sessions` producing `SessionRecoveryReport` with `available`/`blocked` items plus reconciliations, and `apply_session_restore`/`discard_session`/`decide_session`/`record_reconciliation` sealing append-only lineage.
- `session_recovery_repository.py` — sealed stores for `session_recovery_journals`, `session_recovery_decisions`, `session_recovery_reconciliations` (new native schema **v100**, `NATIVE_TABLES`/`_ROW_BINDINGS`/`_RepositoryChain`/`_ReplayProbe` wired).
- `session_recovery_dialog.py` — Japanese launch-time dialog: 復元する / 復旧データを破棄 / あとで決める, per-session.

**Recovery never infers success.** Declared-but-unsealed operations reconcile as `DEVICE_STATE_UNKNOWN`/`RECONCILIATION_REQUIRED` (device apply), `ACQUISITION_INCOMPLETE` (sweep/commissioning), `WRITE_COMPLETION_UNKNOWN` (file intents, resolved only by hash match); a machine `readback` hook can resolve to `confirmed`. Canonical authorities are checked, not trusted, before any item is offered.

**Wiring**: `_run_gui` opens/binds the journal (heartbeat + workspace-state provider), inspects prior sessions after `annotate_launch`, offers recovery post-window (skipped in Safe Mode), and writes `closed_clean` last on exit. Domain hooks (`declare_*`) mirror scene drafts, pending imports, apply transactions, sweep stages, commissioning runs into the active journal.

**Tests**: 32 tests incl. a real `taskkill`/`os._exit` crash-injection on Windows; lifecycle manifest entry added.

Remaining acceptance gate: physical operator check on owned Windows (journal-led restore of a real project GUI session).
