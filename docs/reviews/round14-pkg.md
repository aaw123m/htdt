# Round 14 — Packaging / Deployment Surface Truth

Scope: the shipped Windows artifact — PyInstaller bundle (`scripts/build-native.ps1`,
no .spec file), Inno Setup installer (`installer/HTDT.iss`), entry point
(`scripts/native_entry.py` → `htdt.native_cad:main`), bundled data, first-run
data dir, frozen-mode detection, version stamping. Verified locally; no GitHub
Actions on this repo.

## Packaging surface enumerated

- **Build**: `scripts/build-native.ps1` — inline `PyInstaller --onedir --windowed
  --name HTDT`, `--paths backend\src`, `--collect-submodules htdt`,
  `--collect-all pyvista --collect-all pyvistaqt`, `--add-data` for the runtime
  icon (`htdt_branding`) and stamped `build_info.json` (`htdt_build`), icon
  generated by `prepare_branding_assets.py` (Pillow, locked). Build venv comes
  from `backend/requirements-n05-windows.lock` via `--require-hashes` +
  `check_dependency_lock.py --verify-installed`.
- **Installer**: `installer/HTDT.iss` — per-user install to
  `{localappdata}\Programs\Home Theater Digital Twin`, HKCU file associations
  `.htdtproject` / `.htdtcapture` / `.htdt-backup` →
  `"{app}\HTDT\HTDT.exe" "%1"` (quoted `%1` — space-safe), `[InstallDelete]`
  clears `{app}\HTDT` so in-place upgrade is honest, `AppVersion` falls back to
  `htdt.__version__` via `build-native.ps1`/`build-installer.ps1` stamping.
- **Entry**: `scripts/native_entry.py` → `htdt.native_cad:main` — thin launcher,
  module stays importable without Qt (all heavyweight deps behind
  module-`__getattr__` lazy tables).
- **Version truth**: `htdt.__version__` is the single source; frozen builds
  resolve `sys._MEIPASS/htdt_build/build_info.json` for `+g<sha>` provenance;
  `build-installer.ps1` refuses to package a version that diverges from the
  canonical string.
- **Data dir**: `%LOCALAPPDATA%\HomeTheaterDigitalTwin` (per-user, writable,
  no CWD/install-dir assumptions); bootstrap redirect pointer at
  `%LOCALAPPDATA%\HTDT\htdt-bootstrap.json`; single-instance via `msvcrt`
  byte-lock. Install under read-only `Program Files` is unaffected — nothing
  writes into the install tree.

## Findings

| # | Severity | Finding | Status |
|---|----------|---------|--------|
| F1 | HIGH | `htdt/capture_contract/` (45 JSON schemas + `support-matrix.json`) is declared as setuptools package-data but was **not** collected into the PyInstaller bundle — `--collect-submodules` ships modules only, so every `.htdtcapture` ingest would fail in packaged builds with "payload support matrix unreadable" while dev works. | **Fixed** — added `--collect-data htdt` to `build-native.ps1`; new parity test guards it. |
| F2 | MED | `capture_receiver.generate_self_signed_cert` shells out to `openssl`, which is not bundled and not present on stock Windows. A missing exe raised raw `FileNotFoundError` → user saw the generic "file not found / check the path" message with no hint that openssl is the prerequisite. | **Fixed** — `OSError` from the spawn now surfaces as `CaptureReceiverError` naming openssl (JP message, preserved verbatim by the error mapper). |
| F3 | LOW | `cad_candidate_wave_execution.capture_candidate_runtime` queries `importlib.metadata.version()` for shipped deps — frozen bundles have no dist-info, so numpy/h5py provenance degraded to `'not-installed'`. | **Fixed** — `--copy-metadata numpy --copy-metadata h5py` added (both are locked deps); numba/scipy stay `not-installed` honestly (not shipped). |

## Import coverage — mechanically enumerated

`scripts/pkg_import_surface.py` (AST scan of `backend/src/htdt`, kept in-repo for
future rounds) reports:

- Lazy tables: `native_cad._LAZY_EXPORTS` (35 targets) +
  `workflow_application._LAZY_IMPORTS` (25 targets). **Every relative target
  resolves to a real module file and a real top-level attribute** — verified by
  AST, not memory. The only non-package targets are `PySide6.QtWidgets` /
  `PySide6.QtGui`, covered by PyInstaller's built-in `hook-PySide6` (collects the
  whole binding + Qt plugins).
- Literal `import_module`/`__import__` dynamic sites: none outside the lazy
  tables; loop-variable `version()` queries resolved for the `--copy-metadata`
  check above.
- Third-party imports reachable from the package: all present in the lockfile /
  covered by the two `--collect-all` flags or standard hooks (`PySide6`, `vtk`,
  `numpy`, `h5py`, `pydantic`, `fastapi`, `uvicorn`, `starlette`, `pyqtgraph`,
  `pyvista`, `pyvistaqt`, `segno`, `shapely`, `pymupdf`, `yaml`, `matplotlib`,
  `pillow`).

## Frozen-mode / path audit

- `sys._MEIPASS` branches: `build_info.py` (build-info JSON) and
  `native_cad._packaged_application_icon` — both honest, both exercised by the
  branch they guard; no dead code.
- `sys.frozen` is queried once, in `native_diagnostics` BuildIdentity — honest.
- `__file__`-relative reads: `capture_bundle.SCHEMA_DIR` resolves under
  `_MEIPASS/htdt/` in onedir mode — correct once the data is collected (F1).
  `main.py`'s `frontend/dist` dev mount degrades honestly when absent.
- No `sys.executable` re-spawns, no `multiprocessing` — `freeze_support` not
  needed; `--windowed` stdout is NullWriter-safe (`main()` guards
  `stdout.reconfigure`; `print` no-ops; argparse `--version` exits cleanly).
- Spaces/non-ASCII: install root is under `%LOCALAPPDATA%` (may contain both);
  all path joins go through `pathlib`; file-association commands quote `"%1"`;
  `--data-dir` / bootstrap pointer both honored.
