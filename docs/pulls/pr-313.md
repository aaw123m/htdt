## Summary

Round-2 security pass over `backend/src/htdt` + `frontend/src` (see `docs/reviews/round2-security.md` for the full finding inventory). Three verified fixes with regression tests in `backend/tests/test_security_review_round2.py`:

**R2-F1 — `migration_guard` rollback `extractall` residual (round-1 F4).** `_restore_pre_migration_backup` now streams members through `_extract_member_bounded`: actual decoded bytes are counted before each write, capped per-member at `member.file_size` and archive-wide at `_MAX_ROLLBACK_EXPANDED_BYTES`, so a swapped data-dir archive can no longer amplify disk usage past its declared sizes. `_validate_archive_member` additionally rejects symlink (`S_IFLNK`) and non-regular/special modes, and duplicate member names fail closed. One subtlety: `MigrationOpenError` is a `RuntimeError`, so the in-loop size abort needed `except MigrationOpenError: raise` ahead of the wrapped-error handler or the real rejection reason was masked.

**R2-F2 — unbounded user-picked file reads (round-1 F8 class).** Five sites read a user-selected file via `path.read_bytes()` with either a post-read size check (`import_underlay`, which materialized the full file before comparing to `MAX_SOURCE_BYTES`) or no bound at all (the three mesh imports, `load_sofa_dataset_profile`). All now use `ingress.read_file_bounded` — stat preflight + bounded read — and `IngressTooLargeError` (a `ValueError`) already flows through the existing dialog error handlers.

**R2-F3 — XML entity expansion.** The codebase's only two `ElementTree.fromstring` call sites (`summarize_adm` on the BW64 `axml` chunk, `parse_spectral_xml` on TM-27/33 documents) now reject `<!DOCTYPE`/`<!ENTITY` payloads via `xml_guard.contains_xml_doctype` before parsing. Verified empirically on the pinned interpreter (Python 3.12 / expat 2.7.1): internal entities still expand and pyexpat exposes no billion-laughs knobs, so a ~300-byte document amplifies arbitrarily. Both parsers are currently test-reachable only; the guard keeps them safe when wired to UI.

**Verified clean, no changes needed:** FastAPI legacy app (loopback Host/Origin boundary, per-route body caps, pydantic mutations, SPA path containment, no CORS middleware), capture_receiver hardening, all remaining ZIP readers (`capture_bundle`, `project_bundle`, `native_backup`), all subprocess call sites (argv-form only), no pickle/eval/`dangerouslySetInnerHTML` anywhere.

**Deferred with sketches (need product decisions):** Swagger UI on the loopback legacy API, SOFA `file_bytes` vs `h5py.File(path)` TOCTOU, and per-launch-token auth on the local boundary.
