## Summary

REV56-OPS: issues #598 / #601 / #602 — three fail-closed append-only authorities for operations-stage verification, plus schema v33 (18 tables) and JA UI labels/display helpers. Unassessed inputs read `unknown`/failure states; no state claims "safe"/"verified" without evidence.

- **`cad_security_authority.py` (#598)**: sealed declarations for networked AV security posture — `SecurityAssetDeclaration` (reachability × lifecycle, `decommissioned` only via revocation workflow), `CredentialRecord` (metadata only — no field can hold secret material; `account_ref` rejects credential-bearing strings; former-holder flag for handoff review), `ManagementSurfaceDeclaration`, `SecurityObservation` (evidence_class-gated), `SecurityRiskRecord` (`accepted` requires owner+review date), `RemoteServiceAuthorization` (`consent_ref` required), `SecurityTestEvidence` (`authorization_ref` required), `AccessReviewRecord`. `evaluate_security_review` → 8-dimension checks → ladder `not_applicable → high_risk_exposure → mitigation_required → risk_accepted → reviewed_with_limitations → reviewed`; zero evidence → `unknown`.
- **`cad_control_scenario.py` (#601)**: `ControlScenario` (ordered steps, per-step feedback + timeout, failure-notification channel required when notification is required), `ControlScenarioRun` pins scenario id+sha (verification is revision-scoped), `ControlScenarioQualification` via `evaluate_scenario_qualification` → `draft / not_executed / stale / unverified / failed / qualified_with_deviations / qualified`. Runs against other revisions never qualify the current one.
- **`cad_safe_listening.py` (#602)**: separates "what the system can produce" (`SplCapabilityDeclaration` — rp22/measured/calculated require `source_ref`) from "what humans may be exposed to" (`ExposureLimitProfile` — NIOSH TWA / WHO windowed / declared-policy criteria; `laeq_windowed` forbids exchange rate, `laeq_twa`/`dose_pct` require it). `ExposureGateDecision` records human approval for exceedances; `evaluate_exposure_assessment` → `unknown / within_limit / gate_required / approved / approved_with_controls / blocked`. A quiet plan still gates when declared capability peak exceeds the limit's `peak_ceiling_db`.
