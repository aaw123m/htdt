## Summary

The `acquisition` page exists in `MeasurementPageWorkspace._CONTEXT_IDS` (added by the #869 acquisition-context commit) but was never registered in `CANONICAL_WORKSPACE_CONTEXTS[MEASUREMENT]` — so typed navigation could not resolve `measurement/acquisition` and deep links such as the first-run wizard's ベースライン測定へ had no route. Adds the missing `WorkspaceContext("acquisition", "掃引測定", …)` entry, which restores both the context-rail tab and deep-link normalization (`workspace_context_label`/`normalize_workspace_context` now resolve it).

Refs #869
