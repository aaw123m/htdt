## Summary

Closes out four structural leftovers from the REV28/REV29 reviews of the native store and the round-13 hash sweep.

**UI-thread sqlite reads** — cheap read paths no longer open a fresh `connect_sqlite` (~2–4ms each) or sit outside the borrow/fence protections:
- `SceneRepository.read_blob`/`has_blob` run on the pooled `_read()` and probe `sqlite_master` for the lazily-created `htdt_content_blobs` store instead of running `ensure_content_blob_store` DDL on a read.
- `CadSystemVariantRepository._read` now honours the same `_reopen_fences_for` wait + `held()` recheck as `SceneRepository._read` and passes `reopen_root` — a pooled handle could previously slip into the release→swap window and turn the rename into WinError 32.
- `CadMeasurementRepository._read` delegates to the scene repository's pooled per-thread connection; 20 read-only sites that paid a fresh connect per call now borrow it.

**db-only swap transient resurrect (storage GC)** — `_unlink_pass` now requires each digest's `htdt_storage_gc_pending` row to still be present before unlinking. If it is gone, the database underneath is not the one the delete pass committed against (a db-only file swap or a completed sibling pass); unlinking could strand a resurrected `cad_measurement_assets` row over a missing file — a permanent `missing_referenced` integrity failure. The delete is refused and left for the next pass to re-plan.

**`database is locked` under saturated readers** — `_begin_immediate` only bounds BEGIN-time starvation; a `COMMIT` that cannot upgrade RESERVED→EXCLUSIVE (rollback-journal mode — the native store never enables WAL) also fails `database is locked`. Both GC transactions now run inside `_run_write_pass` (3 attempts, linear backoff): every attempt re-proves reachability, pending state and file identity from scratch, so retries stay fail-closed, and exhaustion propagates the `OperationalError` rather than silently swallowing.

**hash-sweep param-skip reduction** — `backend/tests/test_round13_hash_sweep.py`: 222 passed / 143 skipped → **256 passed / 109 skipped**, with zero pass→skip regressions (verified by a per-param junitxml diff against `main`). Every converted param still exercises the same provisional-hash-equals-sealed-hash invariant. Mechanisms, all generic:
- class sweep tries the single-literal payload first, the pairwise-distinct payload as a fallback (via `_attempt_class_sweep` returning a skip reason instead of `pytest.skip` mid-check);
- `_distinct_model_payload` offsets nested-model literals by the outer field ordinal so siblings like `bounds_min`/`bounds_max` come out ordered;
- `_satisfy_model_validators` fills defaulted fields the model validators still require (explicit Literal members, sample containers) with a bounded candidate pool kept only when it shrinks the error set;
- `**kwargs` builders get the return model's synthesized payload merged in (seal fields excluded — the builder overrides them), and `_call_builder` peels off kwarg keys the builder derives itself.

Remaining skips are domain-semantic (dict-annotated params that genuinely expect models, module-level-unresolvable builders, deep cross-field couplings) and are left as documented residuals.
