# Round 3 review — React frontend & frontend↔backend contract

Branch: `devin/rev3-frontend`. Scope: `frontend/` (React 19 SPA + TypeScript,
Vite) plus the HTTP/JSON contract with `backend/src/htdt/main.py`,
`models.py`, `placement_constraints.py`, `readiness.py`, `acoustics.py`,
`rew_api.py`. Rounds 1–2 covered only the Python backend/tests
(`docs/reviews/round1-*.md`, `round2-*.md`); this is the first frontend pass.

## Fixed in this branch

| # | Severity | Location | Finding | Fix |
|---|----------|----------|---------|-----|
| 1 | medium | `api.ts` `api()` | **Unreadable 422 errors.** FastAPI returns `{"detail": [{loc, msg, type}, …]}` — a list — for validation failures, but the wrapper typed `detail` as `string` and threw `payload?.detail ?? HTTP …`. A 422 therefore surfaced as `Error: 4,5,…` (array coerced) or `[object Object]` fragments instead of the validator messages. | Added `describeDetail()`: string passthrough, array → `msg` fields joined with `'; '`, object → `JSON.stringify`. All panels now show real validator text (e.g. `value is not a valid integer`). |
| 2 | medium | `main.tsx` | **No error boundaries.** All five root panels render in one React tree with no `ErrorBoundary`; a render exception in any panel (e.g. malformed API payload reaching Plotly) unmounted the entire app — including the project selector needed to recover. | New `PanelErrorBoundary` (`ErrorBoundary.tsx`) wraps each panel independently; a failed panel shows an inline `このパネルの表示に失敗しました` notice with a 再試行 reset button while the rest of the app stays mounted. |
| 3 | medium | `App.tsx` `reloadProjectData` / `MeasurementSessions.tsx` `loadProject` / `PlacementConstraints.tsx` `reloadConstraintSets` / `SearchSpace.tsx` `reload` | **Racy project/context loads.** These fired `Promise.all` fetches keyed by the current selection and applied results unconditionally — under rapid project/context switching the *last response* (not the last request) won, leaving lists for project A visible under project B selected. | Monotonic `useRef` sequence counters: each load bumps the counter before fetching and drops the response if the counter moved. |
| 4 | medium | `RewReadonly.tsx` `preview` / `SearchSpace.tsx` `generate` | **Stale async results overwrite newer selection.** FR preview for measurement A could land after the user picked B (backend echoes the request's `measurement_id`, so a payload check can't detect it); `generate` pages/specs likewise applied out of order — pagination double-click could show the older page. | `previewSeq`/`generateSeq` refs bumped on selection change and on each call; stale responses and their errors/loading clears are dropped. |
| 5 | medium | `ComparisonReports.tsx`, `PlacementOverview.tsx`, `RewReadonly.tsx` projectId effects | **No effect cleanup.** `api().then(setState)` chains had no cancellation — setState on unmounted components and stale applies when `projectId` changed twice quickly. | `cancelled` flag + cleanup in each effect; both `.then` and `.catch` guarded. |
| 6 | medium | `App.tsx` `saveContext` / `compare` / `runAcoustics`; `FeatureCandidates.tsx` `analyze`; `ConstraintBuilder.tsx` `addRule` | **Client validation didn't mirror backend rules**, so invalid input round-tripped to a 422 (previously an unreadable one — finding 1): room width/depth/height accepted `0`/negatives (`RoomSnapshot` `gt=0`), mic `sample_rate_hz` accepted non-integers (UMIK-1 must be 48000), comparison bands accepted `low ≥ high`, acoustics `max_hz`/`sound_speed_m_s` unbounded (backend `Query`: `0<max_hz≤2000`, `250<speed<400`), feature band unchecked (`0<low<high≤2000`, prominence `(0,30]`), and every constraint kind accepted payloads the `placement_constraints.py` validators reject (wall_clearance: needs ≥1 bound & `0≤min≤max`; axis_range: needs ≥1 of fixed/min/max & `min≤max`; pair_distance/linked_placement: `entity_a≠entity_b`, bounds `≥0`, `tolerance≥0`; movement_budget: `max_distance_m≥0`). | Added `positive`/`integer` helpers (App) and `boundPair` (ConstraintBuilder); every listed rule is now checked before the POST with Japanese error strings matching the UI. |
| 7 | low | `App.tsx`, `MeasurementSessions.tsx` | **Duplicated `parseList` helper** — two identical copies of the `[,;\n]` split-trim-filter. | Moved to `api.ts` as a shared export; both import it. |
| 8 | low | `main.tsx` children (`MeasurementSessions`, `ComparisonReports`, `PlacementOverview`, `RewReadonly`) | **Five `<main>` landmarks on one page.** Each supplemental panel rendered its own `<main className="shell">`, so screen readers see five competing main regions. | Only `App` keeps `<main>`; supplemental panels use `<div className="shell">`. |
| 9 | low | `plots.tsx` `usePlot`, `FrequencyPlot`, `RoomPlot` | **Re-plot on every render + unhandled promise.** `data`/`layout` were rebuilt inline each render, so `[data, layout]` deps were always new → `Plotly.react` ran on every parent re-render (each keystroke elsewhere). The `Plotly.react` promise was un-awaited with no `.catch` → silent unhandled rejection on WebGL/plot errors. Cleanup also re-read `ref.current` instead of the mounted node. | `data`/`layout` wrapped in `useMemo` (plot only re-renders when inputs change); `.catch` logs render failures; cleanup purges the captured node. |
| 10 | low | `App.tsx`, `MeasurementSessions.tsx` file inputs | **`accept` didn't match backend importer.** App picker allowed `.txt,.dat,.frd` but not `.csv`; MeasurementSessions allowed `.txt,.csv,.frd` but not `.dat` — both inconsistent with the importer's accepted set. | Both now `accept=".txt,.csv,.dat,.frd"`. |
| 11 | low | `App.tsx` `chooseMeasurementFile` | **Stale file preview.** A slow `fileToBase64` + `/api/import/preview` for file A could overwrite `measurementBase64`/`preview` after the user picked file B — preview of A shown under B's filename. | `measurementFileSeq` ref; stale base64 write, preview apply, and error are all dropped. |

## Verified clean (no action)

- **XSS surface**: zero `dangerouslySetInnerHTML`, `innerHTML`, `outerHTML`, `document.write`, `eval`/`new Function`, `javascript:` URLs, or dynamic `href`/`src` sinks anywhere in `frontend/src`. All rendering goes through React escaping; the only DOM imperative calls are `document.body.classList` (App theme) and the root `getElementById` mount.
- **Fetch wrappers**: a single `api()` in `api.ts` is the only wrapper — no parallel/forked fetch utilities. (The only helper duplication found was `parseList`, fixed as item 7.)
- **Listener/timer leaks**: no `addEventListener`, `setInterval`, `setTimeout`, or subscriptions outside React effects; Plotly is the only imperative resource and its `purge` runs in effect cleanup (now on the captured node).
- **Type safety at API boundary**: strict tsconfig; no `any`, no `as unknown as` double-casts; the only unchecked cast was `{ detail?: string }` on the error payload (item 1). Response types are declared TS interfaces — they can't drift *silently*, but see contract checks below.
- **`useEffect` deps / stale closures**: every effect references only props/state in its own render scope; no mutable-ref-in-effect-escaping-deps patterns found. The missing pieces were *cancellation*, not deps (items 3–5).
- **Contract spot checks** (frontend payload ↔ pydantic model): `POST /contexts` body matches `RoomSnapshot`/`Speaker`/`MicrophoneSnapshot` fields incl. `geometry_kind`/`footprint_vertices`; `POST /comparisons` matches `ComparisonCreate` incl. `ExcludedBand` `high>low`; `GET …/measurement-readiness` response matches `readiness.py` (`machine_ready`, `manual_confirmation_required`/`blocked` statuses); `GET …/acoustics` response matches `acoustics.py`; `GET /api/rew/measurements/{id}/frequency-response` returns `RewFrequencyResponse` echoing `measurement_id`; constraint-rule payloads match every validator in `placement_constraints.py` (now also enforced client-side, item 6); measurement import has no extension whitelist backend-side — content is parsed — so widened `accept` lists (item 10) are consistent.
- **Dead components**: every exported panel/component is reachable from `main.tsx`/`App.tsx` (checked by identifier census) — none dead.
