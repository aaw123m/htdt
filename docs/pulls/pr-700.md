## Summary

REV57-DISP adds three fail-closed measurement authorities under one schema migration (NATIVE_SCHEMA_VERSION **38**, 16 tables + 12 indexes), covering issues #625/#626/#633. All records are content-sealed append-only models following the REV57 pattern (`<prefix>:<sha256>` identity, repositories verify sha + persisted parents).

**#625 — `cad_direct_view_display.py`**: `DirectViewDisplayState` pins every materially relevant control (panel tech, firmware, picture mode, local dimming, ambient adaptation, eco — UNKNOWN never defaults to off). `DisplayStimulusContext` makes stimulus part of identity (window size/APL/surround/sequence order/hold/EOTF/metadata). `evaluate_direct_view_qualification` fails closed per claim: a single-APL evidence set never supports across-content peak claims (`APL_COVERAGE_MISSING`), transient peaks never promote to sustained (`PEAK_PROMOTED_TO_SUSTAINED` → unsupported), contrast kinds never conflate, instrument-floor blacks are bounded (never infinite), temporal dimming (ABL/ASBL-class) attaches as observed/provider-documented evidence — never "calibration drift", and per-seat off-axis claims report `unverified_seat_refs` instead of averaging.

**#626 — `cad_observer_metamerism.py`**: `DisplaySpectralState` binds system kind + SPD evidence (spectroradiometer-measured requires instrument binding; tristimulus-only can never carry an SPD). `ObserverModelProfile` pins IEC TS 61966-13:2023+COR1:2025 / ANSI CTA-6035 / CIE 2006 cone fundamentals — IEC/CTA profiles refuse construction against `projected_reflected` systems. Verdicts keep instrument spectral mismatch / standard-observer difference / observer metameric failure separate; every verified verdict carries `METER_CORRECTION_NOT_OBSERVER_PROOF` — meter-corrected is never perceptually identical for all observers. `PerceptualMatchRecord` keeps the nominal target immutable (a user white offset is a recorded delta); multi-observer records require a panel/sample identity class and retain no health/genetic data.

**#633 — `cad_viewing_environment.py`**: `ViewingEnvironmentObservation` captures room state independently of display output — ambient illuminance vs incident-on-image-surface (never room lux), surround luminance/periphery/chromaticity/CCT with honest spectral evidence class (CCT alone never claims a D65 spectral surround), stray light, walls, blinds, automation scenes. Profiles map to explicit requirement sets (ITU BT.2166 most strict; BT.2035/BT.500 subsets; project_defined/normal_use). Broadcast profiles are method profiles — a residential room is never "defective" for missing BT.2166 (`PROFILE_SCOPE_NOTE`). `compare_viewing_environments` separates lighting changes from display calibration changes; `prior_change_axes` stales evidence independently.
