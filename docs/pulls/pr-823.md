## Summary

Adds the #809 qualification-authority layer on top of the existing `cad_benchmark` import/evaluation harness (schema v85).

**What's new (`cad_benchmark_qualification`, 3 sealed records + fail-closed evaluator):**
- `BenchmarkSceneMapping` — pins a corpus scene (via `AuthorityRef` to the admitted `BenchmarkSourceAsset`) to the HTDT phenomenon/`solver_path` it qualifies, plus declared observables and the applicability domain: band, boundary-model family, `curvature_class` (the BRAS RS8 curved-surface lane stays separate from planar).
- `BenchmarkPreregistration` — frozen run spec created before comparison (case hash, provider id/version/config hash, evaluation profile, declared observables, planned convergence axes). `run_mode` separates `preregistered_unfitted` from `informed_calibrated`; informed runs must link their prior unfitted evidence and name every tuned parameter — Aspöck's uninformed/informed split is structural.
- `evaluate_qualification` — any divergence from the frozen spec raises `FrozenConfigurationError`; verdicts follow §8 (`PASS_WITHIN_DOMAIN`, `FAIL`, `INSUFFICIENT_REFERENCE_QUALITY`, `INSUFFICIENT_INPUT_AUTHORITY`, `NUMERICAL_NONCONVERGENCE`, `OUTSIDE_APPLICABILITY`, `UNSUPPORTED_OBSERVABLE`). Convergence evidence gates PASS independently of experimental match.
- `BenchmarkQualification` — sealed verdict capped at `EXTERNAL_BENCHMARK_VALIDATED` (requires `external_measured` evidence class); analytic/numerical corpora cap at `NUMERICALLY_VERIFIED`. `OWNED_ROOM_VALIDATED`/`PRODUCTION_RECOMMENDATION_ELIGIBLE` are unrepresentable — capability can never be presented as validation, and #801's owned-room gate stays separate. `predictive=True` only on unfitted runs so the gate can demand blind evidence.

**Persistence:** `CadBenchmarkQualificationRepository` with three append-only `_SealedStore` tables (`cad_benchmark_scene_mappings`, `cad_benchmark_preregistrations`, `cad_benchmark_qualifications`), full `_ROW_BINDINGS` + `_ReplayProbe` audit wiring, v85 migration.

**Tests:** `test_issue_809_qualification.py` — 16 cases covering the verdict ladder, informed/unfitted enforcement, frozen-config violations, level caps, and repository integrity; schema/audit/row-integrity suites green (68 tests).
