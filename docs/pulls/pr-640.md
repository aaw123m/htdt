## Summary

Three new sealed authorities (native schema v30, 16 tables + 8 indexes) implementing REV56-TRANSPORT issues #582/#583/#591. Fail-closed throughout: unmeasured components are UNKNOWN, sha/version mismatches stale evidence, and verdicts are produced only by evaluation functions — never asserted.

### #582 A/V latency — `cad_av_latency.py` + repository

- `AVLatencyPath` (path_id+version, path_sha256 seal): per-stage `LatencyComponentKind` (device_processing / filter_implementation_delay / buffering / transport / video_frame_processing / display_scanout_emission / audio_output_electrical / acoustic_propagation) with nominal/measured/range latency + `LatencyEvidenceClass`; a value cannot ride on `unknown` evidence. `composite_latency_seconds()` returns None when any stage lacks a value — "zero delay" is impossible by construction.
- Sign convention locked to `audio_late_positive`; `AVSyncCompensationEntry` for declared compensations (LIP = `hdmi_lip_automatic` requiring `lip_evidence_ref` into `cad_hdmi_transport` evidence).
- `AVLatencyProfile` (`avlatprof:`) — versioned perceptual profiles; seeds: `itu_r_bt_1359_1` (detectability [-45,+125] ms, acceptability [-90,+185] ms in our sign convention) and `atsc_is_191` ([-15,+45] ms).
- `AVLatencyPathMeasurement` (`avlatm:`) + `AVLatencyQualification` (`avlatq:`) via `evaluate_av_latency_path()`: no measurement → `insufficient_evidence`; stale path/profile → `stale`; `lip_protocol_reported` cannot carry physical observations; `protocol_physical_mismatch` flags LIP-vs-measured divergence; within acceptability → `qualified_within_profile` else `exceeds_profile_bounds`.
- Composes with (doesn't re-derive): `AVSignalPath` (#570) pin by id+version+sha, `cad_video_latency` (#1005) display latency, `cad_hdmi_transport` (#1041) LIP readback, correction-qualification (#568) filter delay.

### #583 HDMI design & verification — `cad_hdmi_verification.py` + repository

- `HDMISignalProfile` (`hdmiprof:`): required signal declared before verification (mode + `required_features` + `required_bandwidth_gbps` + `hdcp_required`); `requires_earc` must appear in required_features.
- `EDIDArtifact` (`edid:`): raw sha256 + versioned `parser_version` interpretation + `EDIDInterceptionKind` (native_sink/repeated/synthesized/emulated).
- `HDCPStateObservation` (`hdcpobs:`): auth state recording only — no circumvention modeling; `authenticated` requires `negotiated_version`.
- `LinkStateObservation` (`linkobs:`): tmds/frl/unknown + negotiated rate only with real evidence class (marketing rejected).
- `HDMIVerificationRecord` (`hdmi-ver:`): 7 verdicts (pass_stable / pass_with_limitations / intermittent / fail_negotiation / fail_link / fail_feature / insufficient_evidence) with failure-reason taxonomy and `DiagnosticBypassTest` that never overwrites route evidence; `StressScenario` for intermittent/thermal/switching.
- `Rp28VerificationProfile` (`rp28:`, standard_id `cedia-cta-rp28`): 6-domain skeleton seeded by `seed_rp28_profile()` — RP28 text is licensed, so `mapped` requirements need user-entered `requirement_text`.
- `evaluate_hdmi_qualification()`: `theoretically_supported_unverified` when no record exists, `stale` on path sha mismatch; HDMI version labels never imply features.

### #591 Networked AV — `cad_network_av.py` + repository

- `NetworkAVPath` (path_id+version seal): endpoint/switch nodes with ports (speed/medium/VLAN/PoE/LAG) + links validated to existing ports.
- `NetworkMediaFlow` (`netflow:`): provider profile (aes67/dante/st2110/avb/ravenna/vendor_other/generic), unicast/multicast invariants, codec/channel/rates/bitrate/latency/`ClockRequirement`/redundancy.
- `NetworkTransportObservation` (`netobs:`): packet_quality/qos_state/multicast/redundancy_event/stress_soak — all counters optional (None=UNKNOWN, no fabricated zeros); QoS ladder endpoint_marking_declared→switch_policy_observed→end_to_end_behavior_verified; stress_soak needs duration; redundancy_event needs description.
- `NetworkTimingObservation` (`ptpobs:`): PTP domain/grandmaster/offset/path-delay/lock/clock-class/failover; signed offset needs `units_note`.
- `evaluate_network_av_qualification()`: media ladder DISCOVERY→CONTROL→MEDIA_STREAM_QUALIFIED gated on capacity+packet_quality verification; evidence-absence → `insufficient_evidence`; required-capability failures (PTP/redundancy/multicast/QoS) → `failed`; `stale` on flow mismatch.
