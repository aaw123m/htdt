## Summary

REV24-CONTRACT track: closes the row-integrity coverage hole that let
twenty canonical-payload tables escape verification.

The completeness invariant derived its declared set from
`NATIVE_BASELINE_DDL` only. Tables installed by domain schema-convergence
functions (`capture_*`, `cad_adaptive_extended_*`, `physical_space_models`,
`cad_calibration_*`, `cad_measurement_*`) and inline migration steps
(`cad_raw_mesh_repair_bundles`) never appeared in that set, so a tampered
duplicated column on any of the 20 tables raised nothing — the exact bug
class R150-LATE hit with `cad_late_field_artifacts`.

Changes:

- Bind all 20 tables in `_ROW_BINDINGS`, including column→field renames
  (`plan_id`←`calibration_plan_id`, `quality_report_id`←
  `measurement_quality_report_id`, `started_at_utc`←`started_at`) and
  nested payload paths (`cad_raw_mesh_repair_bundles`,
  `cad_measurement_quality_reports.profile.profile_sha256`).
- `capture_connected_space_documents`: extra check re-derives
  `connected_document_id` from the stored payload via the domain hash.
- `cad_calibration_verification_plans.created_at_utc` deliberately
  unbound — the insert stores the *registration* timestamp, not the
  contract's own `created_at_utc`.
- `assert_row_integrity_registry_complete` now derives the declared set
  from the actual migrated schema (`installed_payload_tables()` runs a
  scratch `ensure_native_schema`), so future migration-installed tables
  cannot slip.
- `scan_native_row_integrity` additionally reports declared live tables
  missing from both registries as drift; foreign tables (test probes,
  CI markers) stay the authority audit's unclassified-table domain.
- `native_authority_audit._TABLE_POLICY`: remove 10 dead duplicate keys
  that shadowed earlier `OPERATIONAL_METADATA` entries (incl. a
  malformed one-tuple for `htdt_storage_gc_pending`) — last-wins
  semantics preserved, no behavior change.
- `tests/conftest.py`: move the top-level-widget destruction fixture
  suite-wide (any Qt test can leak an unparented top-level). Uses
  `deleteLater` only — teardown must not fire `closeEvent` on test
  doubles that never modeled the close contract (e.g. viewport plotter
  fakes).

Regression coverage: new drift tests in `test_native_row_integrity.py`
(convergence-table columns, connected-document identity, unregistered-
declared-table flag) and a source-level contract test asserting
`_TABLE_POLICY` has no duplicate/malformed entries.

Audit notes (checked, no gap found): backup/restore snapshots the whole
database via `sqlite3.backup`; asset-manifest coverage complete
(`relative_path`+`sha256` scan); migration upgrade tests already cover
v11→v13 install paths; runner/calibration/measurement read paths
revalidate bindings fail-closed; hybrid-provider evidence promotion
rejects synthetic→validated transitions.

Known environment flake (unchanged): `test_evidence_lifecycle_rejects_
illegal_promotions` under `-n 4` hits Windows MAX_PATH; passes
standalone. `test_room_viewport_r14.py` VTK OpenGL warnings are the
VM's lack of GPU; tests pass.
