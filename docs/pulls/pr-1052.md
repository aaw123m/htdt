## Summary

The opt-in `.htdtcapture` watch folder is attacker-writable on shared machines/sync targets, but the scanner classified entries with `is_file()`/`stat()` — following links — and the settle→route window was unguarded. Two fixes in a new `capture_watch_guard` module:

**lstat classification.** `scan_capture_watch_dir` canonicalizes the root (strict resolve) and classifies each `.htdtcapture` dirent by `entry.lstat()` — never by following it. Non-drops get an explicit skip reason: `link_external`, `link_internal`, `reparse_point` (NTFS junction/cloud/app-exec via `st_reparse_tag`), `broken_link`, `not_regular`, `unreadable`. Skips take `seen` markers from the link's own signature (unchanged = silent, re-pointed = re-reported), emit once per change on a new `entries_skipped` signal capped at `SKIP_REPORT_LIMIT`, and land in the watch failure queue as non-retryable `unsupported` records — never an inbox row.

**Verified staging closes the settle→route TOCTOU.** Delivered drops route through `staged_capture_drop`: `lstat` → `os.open(O_RDONLY|O_NOFOLLOW|O_BINARY)` → `fstat` identity check vs the scanned dirent → bounded chunked copy (`MAX_TOTAL_BYTES`/`MAX_ENTRIES`, cancel-aware) into a private `htdt-watch-*` tempdir → post-copy identity re-check. `build_launch_intent` sees only staged bytes; originals are never written; ingest/ZIP-bomb gates are unchanged. Descriptor bundles must name a relative `bundle_path` resolving inside the canonical root (`descriptor_external` otherwise); link/reparse members block the stage (`bundle_member_blocked`). `WatchStageError` reasons flow through `classify_stage_failure` — permanent refusals → `unsupported`, transient (`changed`/`vanished`/`io_error`) → the existing bounded retry.

**Canonical root contract.** The watch epoch identity is the resolved path: a root spelled through a junction/symlink watches the resolved target; re-pointing the root link arms a new epoch; an unresolvable root is a transient gap (epoch kept, only the resolve attempted). Containment uses `normcase`+`commonpath` component-wise — UNC spellings never compare inside a drive-letter root.

Full threat model + Windows contract: `docs/issues/issue-1019-watch-symlink.md`. Windows-verified live on this box: `st_reparse_tag` discrimination (symlink `0xA000000C` vs junction `0xA0000003`), `mklink /J`, strict-resolve of dangling links, UNC fail-closed containment.

Tests: 21 new (`test_issue_1019_capture_watch_links.py`) — classification, swap detection (link-between-scans, inode swap at open, forged-signature rewrite), descriptor containment, interrupted-copy cleanup, runner E2E (link → skip record, zero route calls, zero inbox rows; junction-spelled root still works). Regression: watch runner + #1014 isolation + #1022 queue + launch router/intents all green (66 tests).
