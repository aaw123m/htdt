## Summary

REV56-DECISION implements the cross-cutting trust layer for optimization and recommendation surfaces, closing #577 (evidence-aware decision rule) and #604 (uncertainty propagation / robust design). The invariant: **a numerically better objective never auto-implies a recommendation** — when uncertainty can reverse an ordering, the system abstains and says why.

> Code landed on `main` via merge commits `ee278881` (implementation) and `9e9d149a` (review doc `docs/reviews/rev56-decision.md`), per the repo's merge-test self-merge convention. The diff on this PR is a small metadata commit on the same branch; the PR body documents the whole change for review.

New sealed authorities:

- `cad_decision_rule.py` — `DecisionRuleSpec` (`decision-rule:<sha256>`) pins the decision type, criterion, declared uncertainty sources, practical-equivalence threshold, guard band, and risk policy. `RecommendationEvidenceVerdict` (`decision-verdict:<sha256>`) records verdicts in the DR10–DR70 taxonomy (`clearly_superior_with_declared_evidence` / `superior_with_limitations` / `evidentially_indeterminate` / `practically_equivalent` / `insufficient_evidence` / `incomparable` / `conflicting_objectives` / `constraint_pass_with_guard_band` / `constraint_not_yet_conforming` / `constraint_fail`). `UncertaintyCompositionManifest` enforces a no-double-counting manifest: common-mode sources cancel pairwise, declared-correlated groups combine linearly inside the group then RSS across groups, independent sources RSS; an empty or all-excluded manifest yields no resolution → `insufficient_evidence` (fail-closed). Evaluators: `evaluate_pairwise_preference`, `evaluate_limit_conformity` (ILAC-G8 guard bands), `evaluate_pareto_dominance` (`robustly_dominates` / `dominance_uncertain` / `tradeoff` / `nominal_only` / `insufficient_evidence`).

## Literature grounding

- **ILAC-G8:2019** guard bands — `GuardBand` separates specification limit from acceptance limit (`w = TL − AL`); conformity near a limit reports `constraint_pass_with_guard_band` / `constraint_not_yet_conforming` instead of a bare pass/fail.
- **Probabilistic / worst-case Pareto dominance** — dominance under uncertainty is a four-state verdict, not a boolean; `nominal_only` dominance names the nominal leader but marks superiority `with_limitations` and never upgrades to a recommendation.
- **Thydal et al. 2021** (Appl. Acoust. 178:107939) — p-box / interval UQ for room-acoustic material properties motivates the `pbox` and `bounded_interval` representations and the aleatory/epistemic split.
- **Pilch 2020** (Appl. Acoust. 170:107495) — uncertainty in geometric/placement inputs motivates `placement`-kind inputs and the placement-tolerance composition tests.
- **Abstention decision theory** — `insufficient_evidence` / `evidentially_indeterminate` / `incomparable` are first-class verdicts; `EvidenceRequest` records *what* evidence would resolve the abstention (value-of-information), not just that it abstained.
- **ISO 3382-1 JND context** — practical-equivalence thresholds must be declared per-criterion with an explicit basis (`PracticalEquivalence.threshold` + `basis`); the code never invents a universal JND, and JND-sub improvements cannot be advertised as improvements.
