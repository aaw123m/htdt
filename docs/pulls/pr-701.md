## Summary

REV57-PROJ: four fail-closed projector-domain authorities (schema v37→v38, 17 tables).

- **#619 SpatialProjectionAuthority** (`cad_spatial_image_authority`): `CadSpatialMeasurementPlan` seals layout (`ansi_9_point` requires exactly 9 points; `center_only` exactly 1 center), quantity axes, per-point viewpoints, screen + projector optical state, stabilization requirements. `CadSpatialMeasurementSet` keeps raw per-point observations (units mandatory, chromaticity x/y paired, instrument sha-pinned) sha-bound to the plan; `field_measured` vs `predicted` stay distinct. `evaluate_spatial_uniformity` is profile-bound — no invented thresholds: `criterion_unbound` when no criterion is bound, `insufficient_coverage` with `missing_roles` on partial grids, `insufficient_evidence` on unstabilized/empty evidence. A single center reading can never upgrade to a uniformity claim; verdicts aggregate worst-of-viewpoint. `CadSpatialDerivedMap` pins source-set sha + interpolation algorithm/version/grid + extrapolation flag so heatmaps can't launder raw coverage.
- **#622 ProjectionGeometryAuthority** (`cad_projection_geometry_authority`): `CadPresentationGeometryBinding` seals the presentation profile (content/projected aspect, lens memory, zoom/shift, keystone/warp/anamorphic states, scaling, masking). `CadImageGeometryMeasurement` requires `test_pattern_identity` (SMPTE RP40/DPROVE practice) and reads all 11 `GeometryQuantity` axes incl. per-edge `CadCropAttribution` and `CadMaskingEdgeState`. `evaluate_presentation_geometry` never infers geometry from throw math (no measurement → `insufficient_evidence`), fails on anamorphic/equal-aspect conflicts, and reports raster-consuming corrections (`digital_keystone`/`warp_geometric_processing`/`scaling_crop`) as `verified_with_digital_correction` + `correction_costs` — a CAD-16:9 that is actually cropped is never `verified`. `CadLensMemoryRecallRecord` seals per-cycle recall repeatability.
- **#624 HushBoxCoDesign** (`cad_hushbox_authority`): `CadProjectorInstallConstraints` seals the manufacturer operating domain (source-document pinned — no universal enclosure ΔT). `CadEnclosureFan.cfm` requires `AirflowBasis` (free-air rating never reads as installed airflow). `evaluate_enclosure` keeps thermal/acoustic/optical/serviceability axes independent: protection events or documented-max inlet violations → `failed`; fan escalation or recirculation → `thermally_limited`; acoustics without `same_state` comparability → `not_comparable`; `post >= pre` or fan escalation → `fan_escalation_negates`. "Projector noise reduced" alone is never a qualified enclosure.
- **#627 OpticalRadiationSafetyAuthority** (`cad_optical_safety_authority`): `risk_group` (IEC 62471-5 RG0–RG3) and `laser_class` (IEC 60825-1 class 1–4) are separate sourced fields — never the same quantity. `evaluate_optical_safety` fails closed: no constraints → `local_review_required` (never an improvised safe distance), unmatched lens accessory → `lens_accessory_applicability_unknown`, in-path position inside documented hazard distance → `safety_zone_conflict`, placement drift → `stale_after_change`, service states → `service_state_not_user_safe`. `remote_power_capable` is recorded but never credited as a safety control; no interlock-defeat guidance.

Repositories ×4 follow the sealed append-only pattern (idempotent save, ConflictError, per-column integrity checks). Wired into `NATIVE_BASELINE_DDL`, `_migrate_37_to_38`, `_ReplayProbe` audit replay, `_ROW_BINDINGS`, `_LIFECYCLE_TABLE_LABELS`, and JA display lines (`spatial_uniformity_line` / `geometry_evaluation_line` / `enclosure_qualification_line` / `optical_safety_line`) with honest UNKNOWN rendering. Issue-verification manifest entries added for all four issues.

## Literature basis

- **#619**: IEC 61947-1:2002 (successor to ANSI IT7.215/IT7.228) electronic-projection measurement practice; IEC 62906-5-1:2021 / ISO 21118:2020 nine-point luminance grid → `ansi_9_point` layout + center/edge/corner roles; ISO 26431-1:2008 and SMPTE ST 431-1:2006 / RP 431-2:2011 as profile-bound criterion sources; AVIXA Systems Performance Verification Guide's installed-system measurement principle (predicted ≠ field_measured).
- **#622**: SMPTE RP40 / DPROVE test-material practice → mandatory `test_pattern_identity`; digital keystone/warp consumes raster and destroys effective resolution — kept distinct from optical zoom/lens-shift via `CorrectionKind`; lens-memory recall repeatability modeled on manufacturer install docs (Sony VPL-XW7000ES, JVC DLA-NZ900 class).
- **#624**: Manufacturer-documented cooling/install domains (Sony/JVC install manuals: intake/exhaust, ambient limits, clearances); free-air fan CFM ≠ installed airflow (`AirflowBasis`); CEDIA showcase co-design practice — acoustic attenuation, cooling, optical transmission and service qualified together.
- **#627**: IEC 62471-5:2015 risk groups (RG0–RG3) for image projectors vs IEC 60825-1:2014 laser classes — separate classification systems; hazard distance + restricted height evaluated only against manufacturer-documented rules; HTDT returns `local_review_required` rather than deriving a safe distance itself.
