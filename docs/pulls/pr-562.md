## Summary

Deep review of the capture ingestion/inbox/promotion surfaces (`capture_inbox.py`, `capture_ingestion_transaction.py`, `capture_entity_promotion.py`, `capture_mesh_ingestion.py`, `capture_receiver.py`, `capture_import.py`, `capture_compatibility.py`, `CaptureInboxPage`). Four real defects fixed, each with a regression test; verified-clean surfaces and residuals recorded in `docs/reviews/rev53-capture.md`.

**Discarded repair writes in the idempotent/verify paths.** `_resolve_persisted_quality` backfills `quality_state`/`quality_payload_sha256`/`quality_ruleset_version` on pre-#337 `unresolved` rows — but `ingest()`'s existing-run branch ended with `connection.rollback()` and `verify_persisted_ingestion()` closed without commit, so the UPDATE (plus `_register_capture_revision`/`_persist_capture_bundle` repairs) was discarded while the returned result reported the repaired state. A legacy `unresolved` run stayed unresolved forever → `require_quality_state` permanently blocked promotion. Both paths now `commit()`.

**`_world_to_scene_by_space` arbitrary winner.** Docstring promises "the newest one per space" but iterated `list_promotions()` (`ORDER BY promotion_id ASC` — content-hash order), so a second promotion for one (document, space) made the winner effectively random and could apply a stale world→scene authority silently. Now sorts by `(created_at_utc, promotion_id)` so last-write = newest.

**Watch-folder rejections labeled `document_open`.** `route_capture_intent` passed the constant `CAPTURE_ARRIVAL_SOURCE` instead of the `arrival_source` parameter to `import_capture_artifact`, so only the success path got honest provenance — every watch-lane rejection was staged labeled `document_open`.

**CLI imports invisible in the Inbox.** `htdt-capture-import` staged rejections but not successes; a committed import stayed invisible until another lane's `reconcile_orphaned_ingestions` picked it up — and then carried `restart_recovery` provenance instead of `cli_import`. `main()` now stages the rebuilt plan after commit (staging failure warns on stderr, exit 0 preserved).

**Stale test:** `test_runner_never_promotes_and_rejects_junk` was permanently red on main — it predates `stage_rejected` and asserted junk drops leave no inbox row. Updated to the current contract (rejected-envelope row) and now also asserts `arrival_source == WATCH_ARRIVAL_SOURCE` (regression for the provenance fix).
