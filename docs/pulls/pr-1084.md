## Summary
`backend/src/htdt/room_objects_panel.py` was a flat 4-column `QTreeWidget` (`setRootIsDecorated(False)`). This PR adds instant search, a 2-level kind-group hierarchy, visibility state filters, and in-list temporary isolation on top of the existing `Room controller.isolate_entities`/`clear_isolation` — no new scene truth.

- 検索: `objectsSearch` `QLineEdit` matches name / kind key / JA kind label / `speaker_role` / stable `entity_id` (`_entity_search_haystack`, casefolded). 状態フィルタ `objectsFilter`: `全て`/`選択中のみ`/`非表示`/`ロック中`/`問題あり`. ゼロ件は非選択行に条件+「リセットで全表示に戻せます」と明示（`objectsFilterReset`）。
- グループ: `entity_group_key` maps `body_geometry.kind=='mesh_asset'` → `取込メッシュ`, else `entity.kind` (`_OBJECT_GROUP_ORDER`). Group headers are `ItemIsEnabled`-only; collapse state persists via `_collapsed_groups`; primary entity's group auto-expands so 3D pick→list sync never hides it.
- 問題あり: `entity_problem_reasons(document)` — チャンネルロール未割当, ロール重複 (both mirroring the room journey gates), and entity centre outside the room footprint/height. Display-only signal; rows get `⚠` + reason tooltip.
- 一時隔離: panel emits `isolationRequested`/`isolationClearRequested`/`focusRequested`; `RoomWorkspace` wires them to the existing `isolate_selection`/`clear_isolation`/`fit_selection`. `隠す`/`ロック` remain persistent (`view_state.hidden_ids`/`locked_ids`); `隔離` restores the pre-isolation hidden set. Summary line shows `隔離中`, `表示 N/M`, and `フィルタ外の選択 X 件` when the selection is filtered out.
- Identity: every row keeps `entity_id` in `_ENTITY_ROLE` (col 0) + `_entity_items` map; `item_for_entity` is public. All show/hide/lock/unlock/delete emits resolve by stable ID — never by tree row index.
- `isolate_selection`/`isolate_kind`/`clear_isolation` now call `_sync_objects_panel()` after `_render()` so `隔離中` and row markers stay fresh.
