## Summary

Fixes the R130D rigid-wall / absorbing-halo interference identified by the #938 reproduction-isolation diagnostic, with a numerical regression gate.

**Defect.** The pinned PFFDTD engine (`aa319f6c…`, also upstream HEAD — no upstream fix exists) builds its absorbing boundary set `bna_ixyz` in `_load_abc` from grid dimensions alone: every strictly interior node at index `1`/`N-2` per axis joins the ABC set, regardless of the `bn_ixyz` room-boundary mask. `nb_update_abc` then applies the absorbing update to those nodes *after* the boundary update, so a wall voxelized at index 1 absorbs instead of reflecting — measured tail/head RMS `0.0100` vs `1.3275` for a properly separated wall (~130×).

**Fix.** `pffdtd_boundary_halo.py` — driver-side exclusion, no upstream edit:
- `apply_boundary_halo_separation(engine)` removes `bn ∩ bna` nodes from `bna_ixyz`/`Q_bna`/`Nba` (+`V_bna`); called after `setup_mask()`, before `allocate_mem()` in `cad_candidate_wave_execution.py` and in all four direct-`SimEngine` legs of the reproduction-isolation driver.
- **Inert on separated masks** — removing a disjoint set cannot change the trace, so pinned trace hashes hold.
- `enforce_boundary_halo_separation` is the fail-closed `UNSUPPORTED/NOT_VALIDATED` gate for untreated adjacent masks.
- Treatment provenance recorded under `compatibility_patch['boundary_halo_separation']` (pre/post ABC-set sha256, excluded count, convention version).

**Evidence (committed, frozen metrics — none retuned after results).**
- `benchmarks/acoustics/issue947_boundary_halo_regression_evidence.json`: 4 legs, wall@1 untreated `0.0100` → treated `1.2950`; wall@2 bit-identical (inert); excluded count = assessment count (714).
- `benchmarks/acoustics/issue947_postfix_rerun_{evidence,summary}.json`: full reproduction-isolation rerun under the fix — **run25/run62 values match, run76 bit-identical** (production masks are already separated); the driver's halo-adjacent probe now rings → verdict honestly `HALO_ADJACENCY_NO_LEAK_OBSERVED`. The PR #295 CI artifact expired (404), so its baseline was synthesized from the committed run25 summary's identical 6-level schedule (recorded in evidence); post-fix legs still PASS against it.
- PPW self-convergence re-evaluated under the fix: **stays FAIL** — the #938 cause is pre-asymptotic discretization, not this defect; no gate promotion.

`scripts/run_issue947_boundary_halo_regression.py` reruns the 4-leg probe and exits non-zero unless all verdicts hold; `test_issue947_boundary_halo.py` adds 10 unit tests (assessment, enforce, exclusion exactness, inertness, guards). MFEM legs remain `UNRESOLVED_ENVIRONMENT_BLOCKED`.
