## Summary

Implements issue #866 (REV66 slice): the sealed geometry intake chain `SOURCE_GEOMETRY -> HEALTH_CHECK -> REPAIR_PROPOSAL -> EXPLICIT_ACCEPTANCE -> DERIVED_GEOMETRY_REVISION -> SOLVER_READINESS` over imported scene geometry — full provenance, no silent mutation of the source model.

**Domain module** (`htdt/cad_geometry_intake.py`, new):

- `GeometryIntakeSubject` (`gis-`) — sealed, deterministic projection of `SceneDocument` into solver-facing parts (room boundary + physical entity bodies world-transformed), declared openings, unit authority. Every mesh is normalized through `encode_body_mesh_bin` → `import_raw_visual_mesh`, so provenance is truthful (`htdt_meshbin_v1`) and coordinates round-trip through f32.
- `GeometryIntakeReport` (`gdr-`) — 13 defect kinds across 3 severities with `source_model` vs `solver_limitation` origin, evidence dict, consequence and suggested action: `open_boundary_edges`, `non_manifold_edges`, `disconnected_regions`, `duplicate_or_overlapping_faces`, `inverted_normals`, `degenerate_or_tiny_features`, `portal_opening_ambiguity`, `material_assignment_gap`, `coordinate_unit_anomaly`, `not_watertight`, `solver_unsupported_condition`, `geometry_unavailable`, `diagnostic_evidence_gap`.
- `GeometryRepairProposal` (`grp-`) — proposals only; automatic kinds map onto the bounded raw-mesh repair ops, operator-required kinds (`assign_material`, `declare_units`, `resolve_portal`, `remove_disconnected_fragment`) carry parameter slots.
- `GeometryRepairAcceptance` (`gra-`) — exact-cover decision record (who/what/when + `accepted_parameters`, validated per action kind).
- `DerivedGeometryRevision` (`gdv-`) — immutable derived geometry linked to subject/report/proposal/acceptance; parts carry `unchanged_source` / `repaired_mesh` (+`repair_lineage`) / `replaced_mesh`; residual defects are re-diagnosed rather than assumed fixed.
- `GeometrySolverReadinessVerdict` (`srv-`) — `supported` / `degraded` / `unsupported` / `unknown` against `AcousticSolverAdapterDescriptor` + optional `SolverCapabilityManifest` (a `portal_region_coupling` UNSUPPORTED row becomes a `solver_limitation` blocking reason). `readiness_evidence_state` deterministically reports `current`/`stale_geometry`/`stale_solver`/`stale_manifest`; `assert_geometry_solver_execution_permitted` fail-closed-gates solver runs.

**Persistence**: `CadGeometryIntakeRepository` (new) over five `_SealedStore` tables; `NATIVE_SCHEMA_VERSION 97` DDL + `_migrate_96_to_97`, `NATIVE_SCHEMA_TABLES`, `_ROW_BINDINGS`, `_ReplayProbe` x5 + `_RepositoryChain('geometry_intake')`, `test_cad_schema` ledger row.

**UI**: `GeometryIntakePanel` (new, offscreen-testable) — defect tables split by origin, locate affordance emitting `locateRequested(entity_ids)` via headless `defect_locate_targets`, per-action accept/reject with inline operator-parameter editors, readiness verdict panel.
