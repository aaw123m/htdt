## Summary

Round 9 of the review program: full i18n sweep of the shipped Qt surface plus an accessibility pass. The product convention is **hardcoded Japanese literals** (`localization.py` exists but no widget calls `tr()` — see deferred item in `docs/reviews/round9-i18n.md`), so all fixes translate in place.

What changed:

- **`room_editor.py`** (the known deferred item): ~60 English canvas-overlay/tree/statusBar strings → Japanese (mode labels `idle/sketch/edit` → 待機/作図/編集, room tree rows 部屋·頂点·高さ, group labels スピーカー/リスニング・測定点/家具, all sketch/cancel/dimension status messages).
- **`native_editor.py`** base chrome inherited by every editor window: dock titles (`Room`→部屋, `Inspector`→インスペクター, `Objects`→オブジェクト, `Scene`→シーン), toolbar actions (保存/元に戻す/やり直す/削除/移動/回転/すべて表示), snap toggles, view-mode labels (上面/正面/右側面/透視/全体表示), status counts.
- **`native_cad.py` launch surface**: recovery dialog title/body + all 5 choice buttons (`_RECOVERY_CHOICE_PRESENTATION`), launch-intent outcome dialogs, data-update dialogs, `report_launch_failure` titles/text, already-running dialog + stderr, argparse help → Japanese.
- **Functional fixes, not just strings** — two lookup tables still keyed on English dock titles after earlier renames, so they silently no-opped:
  - `workflow_legacy_bridge._CONTEXT_DOCK_TITLES`: 'Room'/'Inspector' → '部屋'/'インスペクター' (context highlighting actually works again)
  - `measurement_workspace._unify_right_context_docks`: `preferred_titles`/anchor → Japanese (dock ordering restored)
- Workspaces/panels: measurement (REW file filters, 合成フィクスチャ, source/quality labels), prediction (tree cols, run/freshness detail), optimization suite (headers, Pareto columns, fidelity combos, GP rows, adaptive/extended/robustness detail blocks), field explorer, standards evidence labels, system expansion, room workspace/video (PASS/FAIL→合格/不合格 display + counting), acoustics panel, equipment library, geometry import, commissioning wizard, playback chain (ohm→Ω), theater workflow.
- **Accessibility**: all 5 `setAccessibleName` values → Japanese. Verified: no icon-only controls exist (every action carries text), destructive confirms set `setDefaultButton(Cancel/No)`, `QDialogButtonBox` gives Esc-reject, tab order follows `QFormLayout` construction. `&` mnemonics remain absent BY DESIGN (Japanese Windows convention — unreliable under IME); documented in the review doc.
- Kept English deliberately: REW, dB, Hz, SPL, GP, Pareto, channel ids (FL/FR/…), file-format labels (`JSON (*.json)`), internal status codes (PASS/FAIL in models), exception text (generic-Japanese via `user_facing_error`; raw English only in the opt-in Details pane), diagnostic log-file lines.
