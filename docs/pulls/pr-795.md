## Summary

REV61 deep-review of the solver/prediction/optimization numerics slice (`backend/src/htdt/` compute modules) — 9 confirmed defects fixed, each with a regression test proven red on the unfixed tree (`git stash`). Review doc: `docs/reviews/rev61-compute.md`; tests: `backend/tests/test_rev61_compute.py` (11 tests).

**Fail-open / crash-level defects**

- `compute_coverage_metrics` divided by `total_spatial` → `ZeroDivisionError` on designs whose points are all non-spatial roles (repeatability/diagnostic-only), making `evaluate_campaign_design`'s intended `no_spatial_coverage_points` verdict unreachable. Now emits 0.0 shares.
- `evaluate_adaptive_claim` missed two gate states: `partially_converged` fell through to `qualified_adaptive_estimate` (unconverged evidence is not evidence), and a `stimulus_band_insufficient` stimulus could still qualify when `excitation_support` claimed `identified`. Now `not_converged` / `band_limited_estimate`.
- `evaluate_isolation_qualification` evaluated `relative_reduction_target` criteria with the SPL-cap margin (`limit − estimated_receiving_spl`) — comparing a required *level difference* against an absolute SPL. Reduction targets now compare `level_difference_db − limit_db` over measured difference-metric bands.

**Fabricated-evidence defects**

- `evaluate_splice` evaluated margins and predicted-vs-measured RMS at summed samples outside both isolated curves' measured range — `np.interp`/`magnitude_at` flat-clamp to edge values, so out-of-domain samples produced phantom cancellations or `device_state_mismatch`. Band indices are now restricted to the shared measured domain; none shared → `unknown`.
- Isolation band verdicts put any measured band's `value_db` into `level_difference_db` regardless of metric (an absolute receiving SPL under a "difference" name), while directly measured `receiving_spl` bands never fed `estimated_receiving_spl_db` at all — the strongest possible SPL evidence produced `unknown` criterion verdicts. `level_difference_db` now carries only difference metrics (dnt/dn/d/R′/R); `receiving_spl` bands populate `estimated_receiving_spl_db` directly.
- `_normalization_offset` `band_average` averaged the response over all in-band points but the target only over interpolation-covered ones — asymmetric sample sets bias the offset. Now paired.
- A lone spatial point got a fabricated `nearest_neighbor_m = 0.0`, tripping `points_below_declared_spacing`; spacing stats now stay `None`.
- `instantiate_campaign_template` placed +Y outside-area points at `mins.y + spacing` instead of `maxs.y + spacing` — any zone with y-extent ≥ `spacing_m` swallowed them back inside the declared area. Now anchored to `maxs.y`.
