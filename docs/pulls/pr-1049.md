## Summary

First bounded slice of the #807 flat-namespace decomposition. The **measurement** domain — the only candidate of `measurement`/`acoustics`/`calibration` with all four real layers and a clean internal shape (45 modules, ~50k lines, 0 internal layering violations, fan-in 58) — moves into a layered package, and `scripts/package_boundary_audit.py` becomes a reproducible baseline/diff gate.

- **Boundary**: `htdt.measurement.{domain(27), services(7), persistence(6), ui(5)}`; documented direction `ui -> services -> persistence -> domain` enforced by a new `package_import_direction` audit rule. Packaged edges into still-flat modules are ranked on the same axis (`kernel:-1 … application:4`), so nothing escapes classification by leaving the package.
- **Shims**: each flat `htdt.<stem>` file is `import htdt.measurement.<layer>.<stem> as _impl; sys.modules[__name__] = _impl` — the old path returns *the canonical module object*, so name reads, `from`-imports, and attribute **writes** (e.g. tests monkeypatching `_utc_now`) behave exactly as before. No lazy `__getattr__` escape hatches, no global state.
- **Contracts**: all 45 moved files are byte-identical except import lines (verified mechanically); sealed authorities hash identically through old and new paths — no contract, authority-SHA, or DB-schema change.
- **Audit modes**: default report (1108 nodes / 5311 edges / cycles / size budget / Qt crossings / persistence coupling), `--write-baseline` records `scripts/package_boundary_inventory.json` (26 violations + 4 cycles = managed debt, not a fail), `--diff` fails on **new** violations, new/merged cycles, or newly oversized modules.
- **Tests**: `test_issue_954_domain_split.py` — 99 tests: module-object identity across all 3 import forms × 45 stems, monkeypatch parity, `PACKAGE_LAYERS` exhaustiveness, no sibling-imports through shims, sealed-hash equality, baseline round-trip + diff classifier, PySide6-free domain shim import. `test_issue_807_boundaries.py` still green (one stem-keyed lookup fix).
