## Summary

Refs #968 — a sealed re-measurement queue generated from the sealed quality epoch, surfaced in the measurement workspace and convertible to a campaign plan.

**Generation (`build_remeasure_queue` + `CadRemeasureQueueService.generate`)** scans every committed measurement at the current scene head and classifies each:

- `RETAKE` report → queue item carrying verbatim `failed_criteria` / `retake_reasons` / `remeasure_instructions` / `missing_evidence` from `measurement_retake_guidance(report)`, plus `RemeasureRequiredInputs` (entity/position/direction, `channel_role`, `source_speaker_ids`, routing, `acquisition_context_id`, mic/playback, `sample_rate_hz`, `calibration_file_sha256`) resolved from the effective binding and the bound `CadAcquisitionContext` — never fabricated.
- `UNKNOWN` → soft item only when all missing evidence is in `SOFT_REEVALUABLE_EVIDENCE` (recoverable without recapture) and no capture-only evidence applies (`repeat_measurements` without a same-binding sibling); those go through `soft_reevaluate` → honest producer, **not** re-measurement.
- Everything else → `skipped` with a stated reason (`passed`, `no_current_report`, `report_unreadable`, `superseded`, `not_normally_eligible`, `target_not_in_current_scene`, `undetermined`).

**Sealing/lapse:** `queue_sha256`/`rqueue-<sha[:24]>` hash the full payload; `evaluation_set_sha256` pins every evaluation row (including report-less and unreadable rows, with the error string verbatim) so `status()` → `current` | `lapsed_scene` | `lapsed_evaluations` fails closed on dismiss/convert until re-generation. One poisoned report payload is isolated per-measurement (batched read falls back to per-measurement reads; resolver failures land in `skipped`) instead of breaking the whole queue.

**Events:** sealed `rqev-` rows — `dismissed` requires a non-empty reason, `converted` pins the runner plan; items resolve terminal-once, foreign/unqueued events rejected.

**Conversion:** `convert_to_runner_plan` emits one exact-binding `RunnerCellSpec` per pending item (`channel_role`, `source_speaker_ids`, `target_entity_id`, `repeat_index=0`, `purpose='measurement'`, `notes='remeasure:<mid> report:<rid>'`) under the queue's scene pins; identical scene-pinned plans de-dupe (concurrent conversion is a no-op).

**Persistence:** schema v117 adds `cad_remeasure_queues` + `cad_remeasure_queue_events`; repository re-validates the scene binding on read; audit + row-integrity probes added.

**UI:** new 測定 → 再測定キュー context (`remeasure`, between 品質 and 比較): status card with lapse verdicts + counts, items table with per-item conditions + jump-to-measurement + dismiss-with-reason dialog (blank reason refused), soft card with 再評価, skipped card with stated reasons, キャンペーンへ変換 gated on `current` + pending>0.
