## Summary

Round-9 deep review of the optimization journey (spec authoring → candidate generation → progress UX → apply → Pareto), with three verified fixes and the findings table in `docs/reviews/round9-optimizer.md`.

**Compute — paged candidate generation no longer rescans the full raw space.**
`generate_search_space` must enumerate the entire Cartesian product to compute `candidate_set_sha256`/`feasible_candidate_count`, so every page request (UI prev/next, `iter_cad_candidate_pages`, the extended lane's `_all_base_candidates`) re-ran O(raw) constraint checks — making extended generation quadratic over base pages. `generate_search_space` now also returns `all_candidates`; `generate_cad_candidates` serves pages from a 4-entry LRU keyed on `search_spec_sha256` (which pins axes/limit/both compiled payloads; spec rows are immutable). `require_search_spec_authority` still replays per call and `cancelled` still aborts cached reads.

**Compute — joint execution per-candidate variant resolution was O(N²).**
`run_joint_execution` found each candidate's persisted SystemVariant via `list_variants(document_id)`, which replays `materialize_system_variant` on every variant row — while the run appends one row per candidate. New `CadSystemVariantRepository.variant_for_sha256` uses the UNIQUE `variant_sha256` index; the returned row still goes through `_validated_variant`.

**UX — joint execution no longer freezes the UI.**
`JointOptimizationPanel._execute_selected` ran `execute_spec` synchronously for runs up to 50k candidates. It now runs on a `NativeWorkerPool` with live `実行中: 候補 n/total` progress and a `実行を中止` button (the backend already accepted `is_cancelled`/`on_progress`). Workspace `before_deactivate`/`dirty_state`/`closeEvent` gate on `joint_optimization_panel.is_running()`/`dispose()`.

**Polish — JP surfaces.** Joint spec tree shows JP mode/stale labels (`配置 + DSP`, `変更あり: 部屋リビジョン変更`) instead of internal codes; extended lane routes 5 raw `{exc}` status messages through `operation_error_message` and JP-ifies `missing capability`/`current`/`stale`/`raw · feasible`; base lane `候補preview`/`1 command` → `候補プレビュー`/`1コマンド`.
