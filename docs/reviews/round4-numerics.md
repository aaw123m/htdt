Branch: `devin/rev4-numerics`. Base: `main` @ `05e16f0`. Scope:
`benchmarks/` manifests + `scripts/run_r*/validate_*.py` harness code and the
numerical paths they exercise — `comparison.py`, `cad_benchmark.py`,

## Fixed in this branch

| # | Severity | Location | Finding | Fix |
|---|----------|----------|---------|-----|
| 1 | medium | `acoustic_bakeoff_observation.py` `evaluate_monotonic_convergence_observable` | A solver emitting an **all-zero finest field** (`reference_rms == 0` with nonzero error) produced `relative_rms = inf`; `BakeoffObservableEvidence`'s finiteness contract then raised `ValidationError`, so the evaluator **crashed instead of returning `fail` evidence** — precisely the case a convergence gate exists to reject. Verified: `ValidationError: observable evidence metrics must be finite`. | `relative_error` is emitted as `None` when the computed value is non-finite — the same convention `_relative_error` already uses for zero expected magnitude. The monotonicity/tolerance violations were already appended before evidence construction, so status is `fail` with an accurate summary. |
| 2 | medium | `acoustic_bakeoff_observation.py` `evaluate_sampled_observable` | **No `acceptance_relation` check.** The function rejected *unsampled* observables but silently scored a sampled observable carrying `monotonic_convergence`, `matches_peer`, `must_differ_from_peer`, `repeatable_same_seed`, or `continuous_overlap` by plain abs/rel tolerance — e.g. a `must_differ_from_peer` authority would produce a pass/fail verdict **without ever evaluating the peer contract**. Verified: a `must_differ_from_peer` observable with one sample returned a tolerance verdict. Blast radius is zero today: every non-`matches_reference` observable in `r100a_manifest.json` has `samples: ()`. | Reject `acceptance_relation != 'matches_reference'` with a clear error, mirroring the guard the convergence evaluator already applies in the other direction. Ordering keeps the existing "no expected samples" message reachable for unsampled relations. |
| 3 | medium | `comparison.py` `compare_frequency_responses` | **No input validation** on the plain `FrequencyResponse` dataclass. Verified: empty `frequency_hz` → raw `IndexError` at `a.frequency_hz[0]`; zero/negative/NaN/inf frequencies → raw `ValueError`/`OverflowError` from `math.log2`; length-mismatched `level_db` → `IndexError`/silent misalignment; NaN `level_db` → **plausible-looking wrong metrics** (mean=-1.0, rms=1.0 for a single NaN point — worse than propagating NaN, and `ComparisonResult` is a dataclass with no finiteness check, so the poison survives until `allow_nan=False` canonical JSON rejects at persist). Non-finite band/reference/exclusion bounds similarly produced garbage or `ComparisonResult` objects that cannot be serialized. | `_validate_response` (non-empty, equal lengths, finite, positive frequencies — required by the log2 interpolation domain) + finite checks on all band tuples, all raising `ComparisonError`. Non-monotone axes stay legal — the documented scalar fallback is untouched, and `COMPARISON_ALGORITHM_IDENTITY`/SHA256 are unchanged so persisted replay semantics are identical on all previously-valid inputs. |
| 4 | medium | `cad_benchmark.py` `evaluate_observable` + `_band_values` | **Reference and prediction values were paired positionally after independent band filtering — only counts were compared, never the frequencies.** Verified: reference grid `[100, 200]` Hz vs prediction `[150, 250]` Hz with identical values returned `PASS, error=0.0`. Same for `complex_transfer`. Separately, a non-finite frequency **silently dropped** its sample through the `band[0] <= f <= band[1]` filter (NaN compares false), shrinking the evaluated set, and a non-numeric payload crashed on `float(...)` instead of reporting `UNKNOWN`. | `_band_values` now converts all samples eagerly and returns `UNKNOWN` on non-finite or non-numeric frequencies/values; callers compare the filtered frequency lists elementwise — `pred_freqs != ref_freqs` → `UNKNOWN` ('missing or misaligned'). Exact float equality matches the harness's replay-exact culture. |
| 5 | medium | `cad_benchmark.py` `EvaluationProfile.tolerance_overrides`, `BenchmarkObservable.tolerance` | **`gt=0.0` admits `inf` → fail-open tolerance.** Verified: `tolerance_overrides={'obs': inf}` produced `PASS` for `error=9e9`; `BenchmarkObservable(tolerance=inf)` likewise `PASS`ed arbitrary error. Overrides were also never validated for `nan`/negative/0, and — deeper — the evidence records only `profile_id`/`version`, not the override content (see deferred item B). | `allow_inf_nan=False` on `tolerance`; an `EvaluationProfile` model validator requires every override to be finite and positive. |

## Verified clean (no action)

- **RNG determinism:** every stochastic path found is explicitly seeded — `pra.random.seed(numpy=seed, libroom=seed)` in the pyroomacoustics runner, `random.Random(committed_seed)` in `cad_listening_session.py`, and `stochastic_rays` manifests *require* `random_seed` authority (`AcousticBenchmarkFixture` validator). No unseeded RNG or dict-order dependence in the comparison/bakeoff paths — all evidence payloads sort keys via canonical JSON.
- **`acoustic_pffdtd_adapter.py` / `_polyhedral_geometry.py` / `_impedance_adapter.py` / `_causal_boundary.py`:** degenerate projections, zero-volume meshes, source-floor spectra (`eps`-scaled), non-finite traces/weights/grids — all raise before arithmetic. `finite_record_pressure_transfer` rejects a source spectrum ≤ `eps·max(1,‖Q‖)` on the scored grid.
- **`cad_validation_metrics.py`:** trend/separation/repeatability/applicability models re-derive every reported aggregate (counts, ratios, floors, gates) at ±1e-12 and reject mismatches; NaN can't pass the `ge=0` fields; zero-floor separation gets an explicit `None`-ratio branch.
- **`acoustic_bakeoff.py` `observable_tolerance_violations` / `validate_bakeoff_run` / `validate_bakeoff_decision`:** missing evidence under a declared tolerance is a violation (fail-closed), resource budgets and required-gate coverage are enforced, and a `fail` hard gate can't produce a `selected` decision.
- **`cad_benchmark.py` importer:** format tag, coordinate-convention refusal on position data, required observable fields, and the full semantic-hash self-check on construction are all present and fail closed.
- **Run scripts** (`run_r100b_mfem_*`, `run_r100b_pffdtd_*`, `run_r130d_general3d_validation.py`, `golden_path_preflight.py` as touched): solver pins (`source_commit_sha`), uniform-grid integer-step checks (`isclose(..., abs_tol=1e-12)`), per-level refinement ordering, asymmetric-adjacency detection, plane/stencil reconstruction bounds — all guarded; `_match_modes` greedy nearest-eigenfrequency matching on sorted expected modes is deterministic.
- **`acoustics.py` numerics:** `first_destructive_hz` guarded by `excess > 1e-12`; mirrored-receiver degenerate handled; mode formulas bounded by `max_hz`.
- **`stochastic_sample_keys`/`_relative_rms` zero-magnitude path** in `acoustic_pyroom_stochastic.py` already returns `None` rather than inf — the pattern fix 1 now mirrors.
