## Summary

Refs #1002 — 実測 ETC ピーク ↔ 予測反射パスの対応レビュー面。最近接ピークで対応を誤確定しないため、宣言済みの対応権威（`cad_reflection_correspondence` ペアリング/セット/評価、#564 registration、永続化済み deterministic path artifacts）だけを UI で照合する新しい比較面を、測定ワークスペースの `correspondence` コンテキストとして追加。自動最近接マッチャーは実装しない。

## 構成

- `htdt.reflection_correspondence_review` — Qt 非依存ビューモデル。
  - `derive_etc_display_curve(dataset)`: 実測 IR → 表示専用 ETC 包絡（平滑化 |h|²、ピーク 0 dB 正規化）。観測イベントはここから生成しない（捏造禁止）。
  - `predicted_path_from_guidance_entry(entry, scene_revision_ref)`: `load_reflection_guidance_view` の永続化エントリ → `PredictedReflectionPath`。`interaction_refs` 先頭は sealed deterministic path（`path_id`+`semantic_sha256`）ピン。
  - `build_correspondence_review(...)`: ペアリングを `deterministic_acoustic_path` ピン（フォールバック: 完全 dump 一致）で正確な予測行へ結合し、観測行は `measurement_ref.ref_id == measurement_id` でスコープ。可用性は `no_measurement / no_ir_dataset / no_registration / no_predicted_paths / ready` — 欠落時は理由＋IR を持つ測定一覧を提示。
- `ReflectionCorrespondencePanel`（`correspondence_panel`）— 左: ETC 包絡（InfiniteLine カーソル、宣言済みゲート区間 LinearRegionItem、予測到達点線、登録状態）。右: 遅延生成 `RoomViewport3D`＋3 テーブル（予測/観測/対応: 状態・Δt・DOA・matching_algorithm・evidence dimensions・role・参照）。ペアリング行クリック → バインドされた予測/観測行を相互選択（要件 3）＋ 3D 強調。
- `RoomViewport3D.render_reflection_correspondence_overlay` — `correspond-*` 俳優（`_OVERLAY_ACTOR_PREFIXES` 登録、`pickable=False`、ASCII テキストのみ）。非選択パスは 1 バッチ点群、選択パスのみ `pv.Line`/`pv.Sphere` を生成（実行時負荷）。曖昧集合は全員 `semantic.warning` で同時表示し「正解色」を与えない。
- 仮説保存: 選択予測行×観測行/カーソルゲート → `build_manual_hypothesis_pairing`（`manual_expert_label` + `ambiguous` + time_alignment のみのシール済み仮説）。正典評価器は time-only を構造的に qualified できない。保存測定は一切変更しない。
- 導線: 品質詳細カード「反射対応を確認」ボタン + Room acoustics ツール帯「反射対応」→ `WorkspaceDeepLink(MEASUREMENT, 'correspondence')`。`CANONICAL_WORKSPACE_CONTEXTS[MEASUREMENT]` に `correspondence` 登録。
