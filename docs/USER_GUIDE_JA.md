# HTDT ユーザーガイド

Home Theater Digital Twin（HTDT）は、部屋の形状・機器配置・実測データを1つの
デジタルツインにまとめ、スピーカー配置の最適化と予測を行う Windows
デスクトップアプリです。このガイドは現在の実装に基づく操作手順書です。

画面のほぼすべての入力欄・表の列・状態表示にはツール表示（ホバー）と
WhatsThis（Shift+F1 → クリック）で「その項目が何を意味するか、単位は何か、
どんな値が有効か」の説明が付いています。分からない用語はまずそこを見てください。

## 起動とワークスペース

初回起動では「概要」ワークスペースが開き、プロジェクトが未作成なら
初期プロジェクトが自動で作られます。画面下端の推奨操作ボタンが
次にやるべき作業を示します。

ワークスペースは上部タブで切り替えます:

| タブ | 役割 |
| --- | --- |
| 概要 | プロジェクトの到達度と次の推奨操作 |
| 部屋 | 部屋形状・開口・スピーカー・座席・壁材の編集（CADエディタ） |
| 測定 | REW 測定の取り込み・割り当て・計画実行・品質確認・比較 |
| 最適化 | 配置の探索・候補生成・検証 |
| プレゼン | セッション組立・ビューポイント再生・A/B比較・レビューパッケージ出力 |
| 映像調整 | ディスプレイ測定の取り込み・診断・調整提案・調整前後の比較 |

左側にはプロジェクト内の実体（スピーカー、座席、測定など）の一覧があります。

## 基本用語

| 用語 | 意味 |
| --- | --- |
| シーン | 部屋の形状・配置・機器の現在の設計 |
| シーンリビジョン | 編集のたびに記録される不変のスナップショット |
| 権威 | その情報の正本となる記録。表示値は必ず権威に結び付きます |
| 出典 | 値の出どころ（実測・派生・予測・手入力など） |
| 不明（UNKNOWN） | 値が存在しない状態。0 や推測値で埋めません |
| 古い（Stale） | 依存する権威が変わり現行ではない状態。無効とは限りません |
| キャプチャ / 受信ボックス | HTDTCapture 等から取り込んだデータの仮置き場 |
| ステージ / 昇格 | 取り込み済み / プロジェクトの権威へ正式登録済み |
| システムバリアント | 同一 Digital Twin 上の代替トポロジー提案 |

アプリ内の「用語集」（後述）にはこれらを含む全用語の説明があります。

## 部屋ワークフロー（「部屋」タブ）

画面上部のガイドが現在の進行位置を示します。5 つの手順:

1. **部屋形状を保存** — 部屋の外形（矩形・凹型）を描き、保存します。
   保存すると最初のシーンリビジョンが作られます。
2. **壁と開口を設定** — 壁・ドア・窓などの開口を配置します。
3. **スピーカー・機器を配置** — スピーカーを置き、役割
   （FL / C / FR / サブウーファー等）を設定します。役割が未指定・
   重複のままでは測定割り当てに進めません。
4. **座席（受音点）を配置** — 測定マイクを置く聴取位置を置きます。
   MLP（主受音点）が測定・予測の基準です。
5. **壁材・吸音処理を設定** — 吸音材・拡散材などのトリートメントを
   配置します（音響評価に使われます）。

どの手順も「保存されたシーンリビジョン」の内容で判定されます。
編集中の下書きは手順の完了に数えられません。

## 測定ワークフロー（「測定」タブ）— 6 つの手順

画面上部のガイドが 6 手順のどこにいるかを示します。手順は推奨順で
あって強制ではありませんが、部屋の保存だけは先に必要です
（部屋がないと下位の操作は使えません）。

1. **部屋を保存** — 測定を記録するには先に部屋を保存します
   （「部屋」タブで行います）。
2. **機器の準備** — 「校正」ページで測定に使う機器（マイク・AVR）と
   その確認状態を整えます。
3. **計画を作成** — 「キャンペーン」ページで音源 × 測定位置 ×
   リピート回数を選んで測定計画を作ります。
4. **計測を実行** — 計画を開き、セルごとに計測を進めます。
   「実行を開始 / 再開」で途中から続けられます。
5. **取り込みと割り当て** — 「インポート」ページで REW の結果
   （API または .mdat / テキストファイル）を読み込み、
   「割り当て」ページで測定位置・入力役割・音源への意味付けを
   確定します。取り込み済みで未確定の項目が残ると
   この手順は完了になりません。
6. **品質の確認と比較** — 「品質」ページで各測定の品質チェック
   （クリッピング / SNR / 使用可能帯域 / タイミング基準 / 極性 /
   IR 窓 / 校正 / 繰り返し精度）を確認し、「比較」ページで
   測定どうしの差を評価します。

### 測定の品質で気をつけること

- 品質証拠が足りない測定には「再測定を推奨」が表示されます。
  何が欠けているか（SNR 証拠、校正ファイルの由来など）は
  再測定ガイダンスに列挙されます。
- 測定の dB 値が絶対 SPL 基準か相対形状かは「レベル基準」で
  決まります。基準が違う測定同士は絶対レベルでは比較できません。
- 古い測定（部屋配置が変わる前の取得）は「古い」と表示され、
  現在の配置とは区別されます。

## 最適化ワークフロー（「最適化」タブ）— 6 つの手順

1. **部屋を保存** — 最適化もまず保存済みの部屋が必要です。
2. **探索設定を保存** — 目的（何を良くするか）と探索範囲を定義して
   保存します。
3. **候補を生成して適用** — 探索を実行し、候補を比較します。
   複数の目的を同時にこれ以上改善できない候補の集合が
   パレートフロントとして表示されます。
4. **実測候補を記録・計測** — 採用した候補を実際に配置・測定して
   記録します。
5. **検証条件を事前登録** — 検証で使う条件（帯域・分割など）を
   先に登録します。
6. **比較と検証を確認** — 予測と実測の一致度、ばらつき耐性などの
   検証結果を確認します。

最適化が「利用不可」と表示されるときは理由コード
（部屋未保存、スピーカー未配置、測定の共通タイミング未検証など）が
表示され、それぞれに対応ヘルプが付いています。

## ヘルプと用語集の使い方

| 場所 | 内容 |
| --- | --- |
| `Ctrl+K`（コマンドパレット） | すべての操作・ヘルプトピック・画面への移動を検索。`help`、`用語`、`ショートカット` などで絞り込めます |
| 「用語集・ヘルプ」ボタン（測定タブ） | 登録済みの全用語を一覧・検索。各用語に意味・単位・関連ヘルプがあります |
| 「なぜ？」/「ヘルプ」ボタン | 利用不可やエラーの理由を説明するダイアログ。関連するヘルプトピックへ飛べます |
| ツール表示 / WhatsThis | 入力欄・表の列・状態表示に意味・単位・妥当値を表示 |

エラーダイアログの「ヘルプ」ボタンは、そのエラーコードに対応する
トピック（操作エラーの意味と対処）を開きます。

## データとバックアップ

- プロジェクトは `.htdtproject`、キャプチャパッケージは
  `.htdtcapture`、バックアップは `.htdt-backup` ファイルです。
  エクスプローラーからダブルクリックで HTDT が起動して開きます
  （`.htdt-backup` はプレビュー表示のみ。復元はアプリ内の明示操作です）。
- ユーザーデータは `%LOCALAPPDATA%\HomeTheaterDigitalTwin` に
  保存されます。アンインストールしてもユーザーデータは削除されません。
- 「アンドゥ履歴」で編集操作を遡れます。「概要」の保存・復元・
  バックアップ機能はデータ管理画面にあります。

## インストール

セットアップ（`HTDT-Setup-<version>.exe`）はユーザー単位で
`%LOCALAPPDATA%\Programs\Home Theater Digital Twin` にインストールします。
管理者権限は不要です。インストール不要の zip 版（portable）も
`HTDT-portable-<version>.zip` として配布されます。

詳細: [README の Windows stable release](../README.md#windows-stable-release)
