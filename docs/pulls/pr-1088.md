## Summary

Adds the missing human-review step before anything leaves a project. `cad_project_data_privacy` already shipped the canonical authority (`ProjectDataClassification`, `SensitiveArtifactPolicy`, `ExportRedactionManifest`, `evaluate_export_eligibility`) and fails closed for external sharing — but every export surface went straight from "pick destination" to a worker with no review of classifications, send scope, or omit/degrade reasons. This PR wires a preflight review into all four export paths without duplicating that authority.

- `export_preflight.py` (new): `analyze_*` enumerates what would leave (bundle tables + managed assets, or generated member files) with sizes, proposed/stored classifications, and heuristic risk flags (address/serial/secret/customer/credential/network/photo — review aids, never verdicts). `record_confirmations` persists operator confirmations as sealed `ProjectDataClassification`s; `build_manifest` seals the allowlist `ExportRedactionManifest` and raises when nothing is eligible; `evaluate_elements` runs the canonical `evaluate_export_eligibility` per element; `inspect_exported` re-opens the written artifact, checks the member set against the approved selection, re-scans text members, and the verdict lands in `<dest>.preflight-verdict.json` plus `privacy/preflight-verdict.json` inside the bundle (the one new member `_validate_bundle_members` accepts).
- `export_preflight_dialog.py` (new): per-element table (kind/size/risk/class/rights/verdict/include), scope radios 完全再現用（非公開保存） vs 外部レビュー用（最小限の項目）, source revision+SHA pin, exact included/excluded counts + bytes, degraded warning, 出力する/保留/キャンセル.
- `project_bundle.py`: collection split out of `export_project_bundle` into `collect_project_bundle` → `BundleWritePlan` (the exact plan the dialog reviews and the writer serializes); `apply_exclusions` drops withheld tables/assets and records `BundleOmission`s; `export_project_bundle(write_plan=, extra_members=)` stays backward compatible.
- Wiring: bundle export → preflight pool task → dialog → reduced write plan + in-archive verdict; install handoff + analysis export → member preflight, `exclude_members` on write (digests always match the shipped set); presentation review/proposal → whole-package gate (sealed packages can't drop members — any ineligible category blocks).
- Honesty: private-archive scope ships everything (the gate exists for humans, not automation); external scope can never include unclassified / undeclared-rights / `credential_or_secret` / `unknown_classification` elements — they are documented `excluded_refs` or the export stops. Reproducibility is recorded `degraded` whenever anything is excluded; source-change between collection and write re-runs the preflight; cancel/hold touches nothing; no network sends and no auto-sanitization is claimed.
