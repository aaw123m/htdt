## Summary

HTDT-native automated sweep measurement authority (REV66, #869): the engine that generates, plays, records and derives impulse responses without REW in the loop — plus its sealed evidence chain. `MeasurementAcquisitionEngine` runs `precheck -> ready -> armed -> playing_recording -> processing -> quality_check -> completed / failed / cancelled` with an explicit reason on every transition; a completed recording is never automatically valid.

- `SweepStimulusGenerator`: deterministic log-sine — `params_sha256` = f(spec, `SWEEP_GENERATOR_VERSION`), exact sample-rate binding.
- `AudioIOBackend`: explicit device/channel/rate binding, no silent fallback. `WasapiAudioBackend` is a fail-closed stub on this build; `FakeAudioBackend`/`FakeBackendScenario` deterministically simulates latency, drift, clipping, xruns, noise, truncation, cancellation and device loss (simulated completion is test evidence only — `backend_is_simulated` stays on the record).
- `TimingReferenceResolver`: wired loopback → `qualified`; onset detection / declared sync → `limited`; nothing → `unqualified` — unqualified timing never silently aligns into validity.
- `ImpulseResponseDeriver`: versioned inverse-sweep deconvolution; raw audio and derived IR are separate evidence artifacts; `derivation_version` is pinned per record.
- Quality gate: `clipping_detected` / `insufficient_snr` / `capture_truncated` / `xrun_detected` / `device_lost` / `calibration_missing|invalid` / `synchronization_unusable` / `excessive_noise` / `inconsistent_repetitions` / `cancelled` / `backend_unavailable` / `open_failed` — each a distinct reason under `QualityGateThresholds`.
- Level safety: `ArmConfirmation` requires the operator to echo the armed device/channel/level; `LevelSafetyPolicy` fails closed over limit.
- Evidence: three sealed tables on native schema v97 (`cad_sweep_stimulus_definitions`, `cad_sweep_acquisition_runs`, `cad_sweep_acquisition_stage_events`); raw + IR bytes land in `ManagedAssetStore` and `cad_measurement_assets` in the same transaction; audit/row-integrity/lifecycle labels wired.
- UI: new `掃引測定` context in the measurement workspace — honest empty enumeration, stage + blocked reason + next permitted action, verdict + evidence identity, sealed save. Default backend is the WASAPI stub (no real audio path wired); the fake is injected in tests.
- REW boundary: untouched — interop stays delegated evidence; documented in `docs/issues/issue-869-native-sweep.md` along with what remains device-only.

`backend/tests/test_issue_869_native_sweep.py`: 79 tests covering every stage/verdict path, tamper detection, asset round-trip, and the page driving a fake run end-to-end.
