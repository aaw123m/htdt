## Summary

REV58-MEASELEC: five sealed, fail-closed qualification authorities for measurement-electrical concerns (issues #699, #651, #649, #665, #693), each with append-only schema-registered persistence, replay-probe audit wiring, lifecycle labels and Japanese evidence lines. Schema v48 → v49 adds 18 native tables.

**#699 `cad_interface_loopback`** — `CadLoopbackObservation`, `CadInterfaceTransferCalibration`, `CadInterfaceCorrectionQualification`. The I/O path is an exact identity (`CadInterfaceIoPath.mismatches_against` reports material diffs and honest `unknown_*` fields). Combined `dac_analog_adc` loopbacks can never claim single-side DAC/ADC truth — `component_truth_valid` stays `invalid` unless the calibration kind is a single-side kind *and* carries `CadDeembeddingEvidence` (independent reference instrument). `digital_loopback` verifies routing/format only and cannot carry analog transfer quantities; `complex_response`/`latency_delay` require `CadPhaseSemantics` pinned to a #609 timebase sha; `usb_integrated_capture` rejects analog loopbacks. `sample_rate_applicability` reports exact/validated/mismatch separately from generic path mismatch (REW-style semantics). `usable` band can never exceed `measured` band — edge-hold to DC/Nyquist is a declared policy, not coverage.

**#651 `cad_gain_noise_structure`** — `CadSignalLevelReference` (analog unit mandatory — unlabeled numbers silently mix dBu/dBV/V RMS), `CadNoiseFloorObservation` (typed `noise_class` separates electrical chain / loudspeaker self-noise / room background / hum-EMC / mechanical; `measurement_floor_limited()` within 6 dB of analyzer floor), `CadClippingMarginQualification` (typed mechanism requires the observed threshold), `CadGainStructureQualification` verdict. `CadSnrDeclaration` requires explicit weighting — SNR is never a bare number. A typed clip on a stage without device/port identity yields `clip_stage_unresolved`, never a generic "system clipping" diagnosis. Multi-channel/LFE stress never inherits a single-channel margin.

**#649 `cad_playback_dynamics`** — `CadPlaybackDynamicsState` (per-mechanism `CadDynamicsMechanismRecord`: DRC/dialnorm/night mode/loudness comp/limiter/protection/thermal — `engaged_during_capture` requires runtime evidence), `CadContentMetadata` (applied dialnorm shift requires `decoder_configured_to_apply`), `CadLevelSweepObservation` (≥2 points, verdict taxonomy incl. `limiter_compression_suspected`/`protection_engaged`; confirmed stage attribution requires a named stage), `CadPlaybackDynamicsQualification`. `before_after_comparison` eligibility is gated on state equality — mechanism or identity-field drift yields `state_mismatch` and `causal_attribution_valid: invalid`. Hidden `processing_topology_unknown` mechanisms degrade max-output purposes (`hidden_processing_uncharacterized`).

**#665 `cad_active_crossover`** — `CadMultiwaySpeakerDefinition` (≥2 ways, each with a physical driver identity), `CadActiveCrossoverPlan` (filter specs, alignments, `CadWayRoutingProof` requiring channel+polarity+cross-route checks, `CadManufacturerEnvelope` minimum-HPF protection), `CadDriverAlignmentMeasurement`, `CadActiveCrossoverQualification`. Evaluation ordering is fail-closed: unproven routing → protection/envelope violations → deployed-state mismatch → destructive splices → unmeasured ways. `protection` filters force `mandatory_protection`; `coherent_sum` splices require complex/phase evidence pins, not magnitude-only. `room_correction_eligible` is `valid` only when routing+protection+coherence hold — an unqualified XO never feeds room-correction claims.

**#693 `cad_method_reproducibility`** — `CadMethodProcedure`, `CadReproducibilityCampaign` (design class, disjoint varied/held factors, ISO 5725-style evidence tiers), `CadMethodPrecisionModel` (`CadMetricPrecision` with variance components, `repeatability_limit_r` ≤ `reproducibility_limit_R`), `CadReproducibilityQualification`. `interlaboratory_formal` requires `crossed_factorial` — internal studies never claim formal conformance; `repeatability_only` cannot carry varied factors; ≥2 completed (artifact-pinned) runs per claimed tier. `prediction_gate_eligible`/`decision_gate_eligible` (the #566/#577 consequence gates) open only for an established precision model with a valid between-factor.

## Literature basis

- Loopback/interface cal: a combined DAC→ADC loopback measures only the product of the two transfers — single-side truth needs an independent reference (de-embedding); interface correction semantics follow REW-style cal-file conventions (usable vs measured band, interpolation policy, out-of-range handling) and the USB-mic integrated-path boundary.
- Gain staging/noise: reference-level chains (−20 dBFS = +4 dBu style mappings are per-stage evidence, never global assumptions), noise-floor accumulation and per-stage clip-margin localization; analyzer-floor proximity bounds reported precision.
- Playback dynamics: ATSC A/85 dialnorm and decoder-applied gain shifts, EBU loudness normalization, DRC/night-mode/limiter/protection mechanisms as declared runtime state rather than hidden DSP.
- Active XO: driver-level qualification precedes room correction; polarity/delay/level alignment per way; crossover-band splice evaluation requires complex (phase) sums — magnitude-only traces cannot show cancellation.
- ISO 5725: repeatability (same conditions) vs reproducibility (varied operator/instrument/session) are distinct precision tiers; documented procedure ≠ reproducible result — variance components must be estimated separately, and internal single-factor campaigns confound the varied factor.
