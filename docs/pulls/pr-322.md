## Summary

E2E testing of #321 found that arrow-key nudging a placed `PolygonSketch` vertex remounts the `<g>` on every step because the React key embeds the mapped coordinates (`` `${point.x}-${point.y}-${index}` ``). Focus falls to `document.body`, so consecutive nudges and Delete/Backspace do nothing until the user re-Tabs into the sketch.

Key the vertex `<g>` by index instead — vertex identity follows list position, so a nudge no longer remounts and focus survives across consecutive arrow-key moves and Delete. Removal already refocuses the svg (`removePoint` → `svgRef.current?.focus()`), so the index-shift on delete is harmless.

Verified: `npm run build` clean.
