## Summary

Seals the #839 research synthesis into a fail-closed authority: `StandardsSourceMatrix` records *which* external standards documents HTDT may cite and on what terms — the missing layer between raw source provenance (#418 authorities) and criterion coverage (#805 gap matrix).

- New `cad_standards_source_matrix.py`: `SourceMatrixEntry` pins exact edition identity (`name`/`publisher`/`document_version`/`checked_at`/`source_uris`), #839 §10 precedence, §11 `StandardsProfile` taxonomy class, the HTDT role, §13.1 `source_status` (`executable`/`metadata_only`/`licensed_source_required`/`unsupported`/`source_conflict`/`no_authoritative_numeric_criteria`), definability, and the explicit rights/access/redistribution boundary.
- `builtin_standards_source_matrix()` emits the 12 §12 rows: RP22 v1.2 as the sole `primary_private_theater_profile` (matrix enforces at most one), AURO Rev.12 as default AURO source, Dolby R3.1 as vendor home guidance, DTS:X as `no_authoritative_numeric_criteria`, ITU-R BS.775/BS.2051/BS.1116 as `non_home_reference`, AVIXA A102/A104/V202/D402 as `licensed_source_required`, and AVIXA A103 as `source_conflict` keeping both observed claims (A103.01:2022 detail page vs A103.01:2023 catalog).
- Fail-closed validators: role↔class↔conformance coherence (a production reference can never claim private-home conformance), `executable` requires identified access + derivation-covering rights, `third_party_summary` is never executable, `source_conflict` requires ≥2 distinct claims and `document_version` may not equal any claim, webpage-only sources pin `page_identity`.
- Persistence: append-only `cad_standards_source_matrices` (schema v94) + `CadStandardsRepository.save/get/get_version/list_source_matrices`; replay probe in `native_authority_audit`, table registered in `native_row_integrity` and `require_native_tables`; JA labels + `source_entry_line()` in `measurement_evidence_display`.
- `validate_source_matrix(matrix, profiles=..., gap_standard_ids=...)` audits cross-references — a dangling intended-profile or related-standard id is a recorded error.
- 29 regression tests pin the built-in rows, every validator, seal determinism, repository round-trip + byte tamper, and the JA surface. Docs: `docs/issues/issue-839-source-matrix.md`, issue-805 source-matrix section, `STANDARDS_PROFILES.md` source-matrix section, verification-manifest entry.
