## Summary

Issue #538: auralization evidence & shareability — extends the #57/#515/#784/#518 auralization stack (render legs, comparison player, blinded listening sessions) into a provenance-safe, shareable review artifact. Hard requirement honored throughout: **no result or package ever claims perceptual authenticity beyond the evidence of its underlying solver/measurement path** — confidence is bounded by declared evidence, and the honest `unvalidated`/`no_measured_reference`/`insufficient_signal` states are first-class records, not silence.

New module `htdt.cad_auralization_review` adds four sealed authorities:

- **`AuralizationRoutingDeclaration`** — typed multi-source stem/channel matrix. Every `AuralizationStemRoute` requires `dry_source`, `impulse_authority`, `output_channel`, `gain_db`, `delay_ms`, `filter_identity` — no silent mixer defaults. Unique stem/source ids; layout bounds (`mono_mix` → ch0 only, `stereo` → ch0/1) validated at construction.
- **`AuralizationCapability`** — sealed record pinned to a render spec, artifact and routing declaration (all hash-bound). Carries `ir_origin` (measured|predicted|hybrid, must match the impulse authority kind; hybrid requires declared composition limitations), producer/renderer identity, `validated_bands` with `evidence_id` provenance, acoustic authority states (directivity/material/scattering/diffraction), listener pose, HRTF processing group (declared HRTF requires dataset id+hash+license; individualized requires subject id), headphone compensation, level semantics, and `known_limitations`. `confidence_state` is enforced against the evidence: `measured_reference` ⇒ measured origin; `predicted_validated_for_declared_domain` ⇒ evidence-backed bands; `predicted_with_limitations` ⇒ non-empty limitations; demo/unvalidated ⇒ no bands.
- **`MeasuredPredictedListeningValidation`** — where a measured and a predicted render coexist for the same binding (document, scenario, receiver), computes per-band `level_difference_db` + normalized zero-lag `waveform_correlation` by reusing `_fft_bandpass` (octave/third-octave brick-wall extraction from `cad_ir_analysis`). `comparison_state`: `computed` | `partial` | `no_measured_reference`; per-band `insufficient_signal` when band energy floors out. Fail-closed on ir-kind mismatch, PCM-hash mismatch, sample-rate mismatch.
- **`AuralizationReviewPackage`** + `build_review_package`/`verify_review_package` — deterministic zip (fixed 1980 timestamps, sorted members: `manifest.json` + JA `index.html` viewer + `audio/<artifact>.wav` per comparison). Producer fails closed: missing WAV, byte-digest mismatch, clipped render, or capability/routing linkage drift → no package. Verifier re-opens the archive, enforces safe member names, exact member set == declared assets ∪ {manifest.json}, per-member sha256+size, and re-validates embedded capability/routing payloads. Security assertions (`no_local_paths`, `no_credentials_or_device_identifiers`, `no_unselected_assets`, `rendered_audio_only_no_source_program_assets`) travel in the manifest.

Persistence: schema v17 adds `cad_auralization_routing_declarations`, `cad_auralization_capabilities`, `cad_auralization_listening_validations`, `cad_auralization_review_packages` (append-only, semantic-sha UNIQUE, payload_json); `CadAuralizationRepository` gains save/get/find methods — `save_review_package` re-verifies the zip and rejects packages whose embedded capabilities were never persisted. Audit (`_TABLE_POLICY`) and row-integrity (`_UNBOUND_PAYLOAD_TABLES`) registrations added for all four; this also closes a pre-existing coverage gap on main — REV47-ISS2's `cad_acoustic_geometry_derivations` and `cad_solver_capability_manifests` were unregistered and failing `test_native_authority_audit`.

Deferred UI decision: the listening-session player is backend-only (no Qt surface exists for `ComparisonSession`), so no export button was added — the package is produced/verified programmatically via `build_review_package` + `CadAuralizationRepository`. Documented on the issue.

Tests: `backend/tests/test_cad_auralization_review.py` (16 tests: routing seal/duplicates/layout bounds/required fields, capability confidence boundedness + ir-origin honesty + HRTF group, validation computed/partial/no-reference/fail-closed, package determinism + tamper detection + security rows, repository round-trip). Manifest #538 updated; scoped suite (auralization×4 + schema + audit + row-integrity + new file) green.
