## Summary

REV35-GEOMPORT: enumerates every wall/opening edit operation in the legacy standalone editors (`room_editor.py`, `wall_editor.py`) versus the workflow Room workspace, and ports the four cheap unported items into `room_geometry_input.py` / `room_geometry_panel.py`. The remaining gaps are scoped in `docs/reviews/rev35-geomport.md` for the next REV wave.

Ported (one commit each):

- **Grid snap on floor picks** — `_screen_to_floor` now calls `_snap_floor`, honoring `view_state.grid_snap_enabled`/`grid_step_m` exactly as legacy `RoomEditorWindow._screen_to_floor` did. Affects sketch clicks, vertex drags, and wall drags.
- **Whole-segment wall select** — `_hit_handle` accepts a click within 10 px of any point on the wall body (legacy `_hit_wall` behavior) instead of only the midpoint handle; clicks within 14 px of an endpoint stay vertex-grab territory.
- **All-wall opening outlines in edit mode** — `_render_edit_handles` draws openings for every topology wall (selected wall accent, others `geometry_edge` muted), resolving endpoints by `vertex_id` against the preview vertex set so drags track. Previously only the selected wall's openings showed.
- **Clearance-binding authoring** — wall inspector gains a 参照件数 label, 「追加するクリアランス」 spin (0–10 m, default 0.30), and 「クリアランス参照を追加」 button → `add_constraint_binding` → `replace_room_topology`. Legacy `wall_editor.add_clearance_binding` parity.

Already-ported operations were verified and documented rather than changed (full table in the doc). New regression coverage: `backend/tests/test_rev35_geomport.py` (7 tests).

Deferred with decomposition + estimates in the doc: always-on wall-prism/opening overlay in normal view (needs a UX call), binding delete/update authority (no domain verb exists), wrap-around merge, arbitrary-offset split, binding edit.
