## Summary

The room workspace's right panel (システム拡張/inspector/prediction stack) was a fixed-width column sized only by `_update_responsive_layout` (260–300px), with no way to widen it — long labels and buttons clipped. The viewport and `right_stack` now live in a `QSplitter` so the user drags the boundary. Responsive defaults become splitter sizes *until the user resizes*, at which point `_right_panel_user_sized` latches and the layout stops fighting the drag:

```python
self._content_splitter.splitterMoved.connect(
    lambda *_: setattr(self, '_right_panel_user_sized', True))
# _update_responsive_layout:
if not self._right_panel_user_sized:
    self._content_splitter.setSizes([max(1, w - right), right])
```

The stack's cap rises 320→560px so widening is actually useful, and inner panels' own caps (inspector/geometry/prediction) loosen to follow. The optimization candidates side panel (already in a splitter) gets the same treatment: cap 460→640. Also fixes flush-left text: the トポロジー提案ビルダー card had 0 horizontal content margins.
