## Summary

M3 of the cable-route issue: 3D waypoint authoring/preview/edit for cable runs, implemented as a dedicated edit mode that mirrors `RoomMeasureController`'s pattern (measure mode, entities-page split view — same enter/exit/Esc/marquee/bookmark conventions).

**Authoring input path**
- `RoomViewport3D.set_waypoint_pick_armed(bool)` — while armed, `room-floor`/`room-shell`/`authoring-surface-*` also become pickable, every pick emits `waypointPicked` (domain coords), and entity picks resolve to the face point rather than selecting anything. `pick_popover_enabled` is suppressed and pick candidates dismissed so the mode never collides with entity picking; `disarm` restores pickables + popover exactly.
- `pick_waypoint_domain(display)` — picker first, then an honest fallback: rays through display points 0/1 of the click are intersected with the room boundary (`_ray_room_boundary_domain`: floor plane z=0, ceiling z=height, every footprint wall edge extruded) — never a free-space point.
- `render_cable_route_draft(active, staged)` — in-progress polyline + staged legs under the `cable-route-draft-` prefix in `semantic.stale.hex` (visually distinct from the registered `cable-route-` overlay's accent/warning palette), always non-pickable and non-persistent.

**`CableRunWaypointController` + `CableRunWaypointPanel`** (`cable_run_waypoint.py`)
- `begin(run_id)` resolves the inspection row (fail-closed: run must exist and declare segments) and arms the mode; Esc is the first `cancel_active_operation` entry, `before_deactivate` folds the session like measure.
- Points record to a declared `segment_sequence` only — the segment combo lists declared sequences so undeclared geometry is unrepresentable; `concealment_kind` defaults from the segment's declared `path_kind` and stays editable, `traversed_surface_ids` is whitelisted against `scene_surface_ids` (missing → error surfaced, never saved), `source`/`record_kind`/`note` editable.
- Honest undo/redo: operates only on the recorded point list — scene edits are never touched (verified by scene-hash assertion).
- `commit()` goes through `CadCableRunGeometryRepository.save_geometry` only: re-resolves the latest run version at commit time (stale pin fails closed, never clobbers a newer run), continues an existing `geometry_id` lineage with `version+1` (append-only), clears the draft on success, keeps the session + points on failure.

**Mounting**: `CableRunPanel` gains `この配線の経路を記録` (visible when the selected run declares segments) with the waypoint panel beneath the detail view — the place a run is selected is the place it's recorded. All new controls JA + `accessibleName`; narrow-dock safe (surface list caps at 96px).

**Tests** — `test_issue_1011_cable_waypoints.py` (24): authoring transaction → sealed record with correct pin/fields, dangling-point refusal, declared-segment binding, honest undo/redo, stale-pin re-pin (newer run version never overwritten), append-only version bump, run-gone session end, boundary-ray resolution, draft overlay prefix/non-pickable/Y-flip, workspace wiring + a11y. Also de-pinned two stale `==116` schema-version assertions in `test_issue_1011_cable_routes.py` (schema head is now 118 — pre-existing drift on main).

`docs/issues/issue-1011-cable-routes.md` M3 section updated defer → implemented note.
