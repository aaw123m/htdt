## Summary

REV59-DEPS: three new fail-closed append-only authorities, native schema v52→v53 (12 tables).

**#729 P0 — authority dependency / staleness graph** (`cad_authority_dependency.py`): `DependencyEdgeDeclaration` (depedge-) seals *typed* edges — 13 kinds (`used_as_input`/`derived_from`/`calibrated_from`/`validated_against`/`registered_to`/`configured_by`/`measured_under_state`/`applicable_under_profile`/`assumes`/`requires_capability`/`approved_for_use_by`/`supersedes`/`references_only`; the last is non-influencing) — with an optional `DependencyScope` footprint (target_fields, observables, retained_observables + `residual_independence` for capability-level invalidation where absolute SPL goes stale but relative timing stays current). `SemanticChangeEvent` (depevt-) declares the change class + changed fields — a label rename cannot fire a geometry edge. `DependencyRuleProfile` (deprule-) is the versioned `(edge_kind, change_class) → effect` ruleset; the verdict pins the exact profile evaluated under so rule edits never silently reinterpret history. `evaluate_staleness` computes the transitive closure by fixpoint with per-path severity accumulation (descendants inherit the strongest path limitation) and emits `StalenessAssessment` (stale-): `current`/`stale_recompute`/`stale_remeasure`/`stale_readback_required`/`stale_review_required`/`valid_with_limitations`/`incompatible`/`superseded`/`unknown_dependency`. Fired edge with no matching rule → `stale_review_required` (conservative); subjects lacking declared dependency coverage → `unknown_dependency`, never silently current (fail-closed). `build_revalidation_plan` emits the minimal work set (revplan-) grouped per action kind — `full_recommission` is never a default.

**#725 P1 — evidence attestation / trusted timestamp** (`cad_evidence_attestation.py`): `SignedManifestRecord` (sigman-) seals canonicalization spec + `manifest_sha256` + `ApprovalScope` + referenced-artifact digest refs — a blanket signature does not assert technical approval of everything. `EvidenceAttestation` (attest-) binds manifest×signer by 8 `AttestationKind`s (hash_only → signed_and_trusted_timestamped → external_signature_reference → unknown); `SignatureDescriptor` stores verification-side metadata only (no key material, no signature bytes); `TrustedTimestampPin` anchors RFC 3161-style tokens; `attests_attestation_ref` supports chains. `evaluate_attestation` → `AttestationVerification` (attver-): manifest-binding mismatch or unsupported digest policy → `verification_failed`; hash_only → `integrity_confirmed` (can never claim a signer); trusted timestamp only → `timestamp_confirmed`; signature not checked → `attested_unprovened`; verified sig + trusted time → `attested_verified`; verified sig + declared time only → `attested_verified_declared_time`; key expired/revoked at signing but anchored by trusted time → `attested_verified_historical`; external refs → `unverifiable`. Time authority ladder: trusted_timestamp > declared_time > unknown_time.

**#718 P1 — project archival / schema-migration** (`cad_archive_migration.py`): `ArchiveSnapshot` (arc-) seals schema_version + content fixity hash + `snapshot_semantic_checksum` (separating byte-difference from meaning-difference) + `PreservationScope` + write/readback `ProcedurePin`s (OAIS representation information) + `prior_archive_ref` series link. `evaluate_archive` → `ArchiveVerification` (arcver-): 4 required checks (container_legible/content_hash_match/semantic_checksum_match/schema_version_legible) all pass → `verified_legible`; any required check missing → `partially_verified`; any fail → `verification_failed`; zero checks → `unverified`. `MigrationRecord` (mig-) seals from/to schema versions + migration procedure + comparison policy + declared `FieldChangeIntent`s — write-time status is always `declared`; verification is a separate sealed verdict. `evaluate_migration` → `MigrationVerification` (migver-): unexplained fail → `verification_failed`; required checks missing → `unverified` (unverified migrations claim nothing); semantic checksum match → `verified_equivalent`; checksum difference fully explained by declared diffs → `verified_with_declared_differences`.

Integration: 3 append-only repositories (identical-sha re-save is a no-op; mirrored-column tamper → IntegrityError); `_ROW_BINDINGS` for all 12 tables (count columns via `_list_count` extra check); 3 repo registrations + 12 replay probes in `native_authority_audit`; JA lifecycle-table labels + display label maps and one-line verdict renderers.

## 文献根拠

- **#729**: Mokhov, Mitchell & Peyton Jones 2018 *Build Systems à la Carte* (fine-grained dependency tracking — dirty bit / verifying trace / constructive trace classification; dependency footprint on traces as early-cutoff analogue); make DAG theory (reverse-reachable set from a changed node is the minimal rebuild set); Adler et al. incremental computation (undeclared dependency ⇒ conservative invalidation); capability-scoped invalidation (scope declares retained observables).
- **#725**: RFC 3161 Time-Stamp Protocol (TSA token proves existence-before-time — a separate authority from local `created_at`); NIST FIPS 186-5 (signatures authenticate signer identity contingent on key/identity assurance); X.509 PKI chain; in-toto + SLSA supply-chain attestation (subject+predicate+signer binding, chained provenance); RFC 7515 JWS (one signature serialisation form).
- **#718**: ISO 14721 OAIS reference model (Preservation Description Information — provenance + fixity + representation information retained with the object); migration-vs-emulation literature (CAMiLEON/Bearman — migration is a carrier change under verification; semantic preservation is the claim, not byte identity); format-obsolescence risk management (schema version + readback-procedure pin as the machine-checkable "legible" declaration); OAIS AIP/dissemination units (per-archive fixity + representation info seals).
