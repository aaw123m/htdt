## Summary

Implements bounded slices of #593 (amplifier–loudspeaker electrical compatibility) and #597 (as-built cable/port traceability) as two new sealed-authority modules, plus native schema v27→v28 (4 tables), fail-closed audit/row-integrity registration, and JA display helpers.

**#593 — `cad_electrical_compatibility.py` + repository** (`cad_electrical_qualifications`): `ElectricalQualificationScenario` pins amp spec × speaker spec × cable path × target SPL/distance/band/simultaneous-channel/stress evidence. `evaluate_electrical_compatibility` composes the existing authorities (`cad_amplifier_headroom` scalars, `cad_speaker_impedance` tiers + `AmplifierLoadDomain`/`AmplifierElectricalLimitAuthority`, `cad_speaker_level_transfer` cable loss) into ordered gates: `load_below_amplifier_rating` (band-min |Z| vs amp domain — minimum impedance is taken from curve evidence, so `nominal_impedance_only` downgrades the load gate to `insufficient_evidence`), `amplifier_clipping`, `voltage_margin_insufficient`, `current_margin_insufficient`, `thermal_derating` (sustained/thermally_stabilized stress only), `multichannel_power_limit` (never confuses the spec-sheet "2ch driven" value with real all-channels-simultaneous output — gated via `AmplifierChannelCountCondition.shared_supply_evidence`), `digital_headroom_limit`, `cable_loss_excessive`, `loudspeaker_compression_limit`, `protection_engagement`, `insufficient_evidence`. Verdict `qualified`/`unqualified`/`indeterminate` — indeterminate is never rendered as pass or fail; `dominant_limiter` is picked by a fixed priority map. `CapabilityEvidenceClass` ladder (`spec_sheet_estimate` < `electrically_qualified_model` < `acoustic_output_measured` < `in_room_commissioned`) and an `active` drive lane that rejects amp refs and evaluates only sensitivity→SPL gates.

**#597 — `cad_physical_interconnect.py` + repository** (`cad_physical_interconnects`/`cad_wiring_verifications`/`cad_logical_physical_bindings`): `PhysicalInterconnect` declares the *field* wiring (terminations with anchors+labels+polarity, hops, medium, length, `PathEvidenceState` + `ObservationState`) separately from the logical signal graph. `WiringVerificationRecord` restricts test kinds by path class; `evaluate_physical_path_state` never lets a declaration parade as verification (declared `verified_path` without a passing applicable test → `unverified_declaration` + `promotion_gap`); `evaluate_logical_physical_binding` binds logical refs to physical path sha256 — unbound routes fall to `unverified_routing`, sha drift to `stale`, endpoint mismatch to `mismatched`. `record_service_change` keeps the supersede chain and rejects revisions with no physical delta; `derive_cable_schedule` + `candidate_fault_segments` produce the as-built schedule and fault candidates. Label profiles pin to `standard_id@edition` in the existing `cad_external_standards` registry rather than a new table.

Literature basis (primary sources verified via web_search): required level `target + 20·log10(d/d_ref) + boost + headroom` with V ∝ `10^(Δ/20)`, W ∝ `10^(Δ/10)`; IEC 60268-3:2018 multichannel rated conditions; IEC 60268-5 cl.16.1 minimum-modulus convention (withdrawn 2026-04 — modeled as curve-evidence-or-UNKNOWN, not as a current standard claim); IEC 61938:2018 §11 interconnect practice; AVIXA F501.01:2015 labeling taxonomy; CEDIA RP22 evidence-class ladder reused from `cad_rp22_profile`.
