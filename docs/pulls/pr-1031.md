## Summary

Implements #964: change-diff driven evidence invalidation. One committed `SceneRevision` pair resolves into a sealed `ChangeDiffRecord` (`chdiff-…`, new v114 table) carrying the exact `SceneChange` tuple plus one `SemanticChangeEvent` per mapped #729 change class. `compose_revalidation_queue` synthesizes — never reimplements — the existing authorities: `evaluate_staleness`/`build_revalidation_plan` over declared edges+rule profile, and `build_dependency_impact_report` over sha-pinned watched artifacts, merged into a sealed `RevalidationQueue` (`revqueue-…`).

Fail-closed semantics per the issue: `uncertain`/`unknown_dependency` always produces a `review` item; physical work (`remeasure` → #956 position plan, `re_commission` → #946 authorization) is never auto-started — items carry prepared `AuthorityRef`s and routes instead. `run_queue_software` runs the queue's software items as the single 「変更の影響を検証」 operation, fencing on pre/post head id+hash (`drift_detected` on any move, no false PASS) and recording `unavailable` honestly where no runner is wired. All timestamps pin to `to_revision.created_at_utc`, so recomposition is bit-identical — append-only idempotent saves make restart/cancel/re-edit safe.

UI: `RevalidationQueuePanel` mounts under `DecisionBriefPanel` on the 比較 page with JA item lines, per-route navigation buttons, and a freshness warning when the queue pins a stale head. The workspace wires a real `queue_supplier` (watched artifacts from completed predictions/search specs/measurements, edges+rule profile from `CadAuthorityDependencyRepository`, prepared refs from newest campaign plan + commissioning run) and an honest `software_runner` (re-derives the decision brief for comparison evidence; declines solver/re-import work to its owning surface).

Tests: `backend/tests/test_rev72_evidence_invalidation.py` (13 cases) covering seal round-trip + tamper, per-axis scope precision, fail-closed edges, idempotent recomposition, run fencing, and the panel smoke path. Native schema 113→114 migration + row-integrity + authority-audit wiring included.
