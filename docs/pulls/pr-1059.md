## Summary

Refs #1011 — ships M1 (cable-run inspection + honest 3D display) and M2 (sealed `CableRunGeometry` waypoint authority, schema v116); M3 (3D waypoint authoring) is deferred with a structural note in `docs/issues/issue-1011-cable-routes.md`.

**M1** — `inspect_cable_runs` (`cad_cable_run_inspection.py`) projects each persisted `CableRun` against `SceneRepository.current_head`, `CadSignalPathRepository.list_paths`, and the scene entity table into a read-only `CableRunInspection`: endpoint bindings (bound/unbound/missing, position only when bound), signal-path edge resolution, per-segment `path_kind`/declared length/description, service loop, version lineage, and current/stale/missing freshness. `CableRunPanel` (`cable_run_panel.py`) mounts beside `InstallationPanel` on the placement page and follows the display-length policy. `RoomViewport3D.render_cable_route_overlay` draws only exactly-bound endpoints plus a `経路形状未登録` label at the span midpoint — a line between endpoints is never drawn for a geometry-absent run. Overlay actors are non-pickable under the `cable-route-` prefix so stale/head-drift renders clean them up.

**M2** — new sealed table `cad_cable_run_geometries` (v116 wiring: baseline DDL + indexes, `NATIVE_SCHEMA_TABLES`, `_migrate_115_to_116`, `_ROW_BINDINGS`, audit `_ReplayProbe` + repository factory branch, JA lifecycle label `ケーブル経路ジオメトリ`). `CableRunGeometry` pins `run_id + run_version + run_semantic_sha256 + scene_revision_id + scene_content_hash` and stores per-`segment_sequence` waypoint polylines (XYZ m, ≥2 pts), `concealment_kind`, `traversed_surface_ids`, `source` (authored/imported/as_built_survey) and `record_kind` (design/as_built). `evaluate_cable_run_geometry_divergence` reports declared-vs-geometric lengths as separate numbers (deltas + `unregistered_sequences` + `concealment_mismatch`) without ever rewriting recorded lengths; `evaluate_cable_run_geometry_freshness` reuses the current/stale/missing gate. Legacy length-only runs are untouched and stay valid — geometry is strictly additive.
