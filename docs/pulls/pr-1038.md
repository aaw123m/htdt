## Summary

`MdnsDiscoveryBackend` and `SsdpDiscoveryBackend` were fail-closed stubs on #879; this makes them real read-only wire implementations, stdlib only (`socket`/`select`/`struct`/`ipaddress`/`ElementTree`), no new dependencies.

- `MulticastQueryTransport` protocol + `UdpMulticastTransport` — the injectable network seam (the only raw-network object): one `exchange` sends each datagram once and collects `(payload, source)` inside a bounded `select` window. mDNS joins `224.0.0.251:5353`; SSDP sends M-SEARCH to `239.255.255.250:1900` from an ephemeral port.
- mDNS: PTR queries limited to `scope.approved_service_types`; empty approval runs the DNS-SD enumeration PTR then one typed query round, capped by `max_service_types`. Identity comes only from documented TXT keys — never inferred.
- SSDP: one M-SEARCH per approved ST (`ssdp:all` when none). `LOCATION` fetched only when it lives on the responder's own host; USN/UDN disagreement leaves `stable_identity` empty; an unfetchable description degrades to `partial`/`unidentified` instead of dropping the device.
- Ambient admission: `approved_endpoints` (host match) + `approved_networks` (CIDR membership) gate every advertised endpoint; invalid CIDR raises `DiscoveryScopeError` before any packet leaves — no unrestricted LAN sweep, no writes, no auto-deploy.
- Honesty: down transport → `outcome='unavailable'` (never `failed`, never a fake `completed`); new outcome `cancelled` via `threading.Event`; drop/malformed/dup/cap counts sealed into `DiscoveryRunRecord.notes`; `recheck_binding` propagates `DiscoveryBackendUnavailableError`/`DiscoveryCancelledError` rather than fabricating `endpoint_unreachable` drift.
- `DiscoveryObservation.service_type` (unsealed only — sealed record schemas untouched, so existing stored hashes stay valid).

Tests: `test_issue_949_lan_discovery.py` — 36 cases via `FakeTransport` round-queues: scope rejection (endpoints/networks/STs), duplicate collapse, malformed packets, USN/UDN mismatch, off-host LOCATION never fetched, quiet-LAN empty `completed`, cancel, rescan, identity drift → `replacement_suspect`, and transport-death mid-recheck raising rather than faking a verdict. `TestUnavailableBackendsFailClosed` in the 879 file now injects a down transport for the real backends. 88 tests pass locally; lifecycle manifest: #949 `physical_evidence_remaining` (real-LAN evidence stays under #879's physical gate; `docs/issues/issue-949-lan-discovery.md` documents the procedure).
