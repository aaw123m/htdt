# Arbitrary-room acoustics: hybrid wave + geometric solver for complex 3D rooms

## 背景

現在のHTDTは凹polygon roomをnative 3D CADとして正確に保持できる一方、音響予測モデルの一部は矩形室前提であり、非矩形・開口・キッチン・家具等を含む実室形状では `unsupported` としてfail-closedする。

実際の対象室には、LDKの凹形状、廊下/玄関側への開口、キッチンカウンター、窓・扉、低い天井等があり、単純な直方体近似では低域モード、SBIR、回折、初期反射を十分に表現できない。

HTDT自身に、任意3D形状を直接扱える音響solver layerを追加する。

## 目的

任意形状のHTDT Sceneから、実用上高精度な広帯域音響予測を行えるようにする。

最終的には以下を同一Scene/SceneRevision authorityへ統合する。

- 低域: wave acoustics（FEM / FDTD / BEM等から適切な方式を選定）
- 中高域: geometrical acoustics（ray tracing / image-source系）
- hybrid統合: IR / FR / phase / room mode / reflection / decay metrics
- speaker placement / listener placement / acoustic aim探索との接続
- REW実測によるmodel validation / residual calibration

「形状だけから完全な現実再現」を主張せず、材料・境界条件・speaker directivity・測定校正を明示的にauthorityへ含める。

## 要件

### 1. Scene → acoustic geometry

- 凹polygon roomを3D volumeへ変換する
- opening / door / window / kitchen counter / furniture等をacoustic geometryとして扱える
- openingは単なるwall holeではなく、explicit adjacent AcousticRegionへのPortalまたは明示したBoundaryTerminationとしてauthorityを持つ。未知の隣接空間を無言でanechoic/absorbingとみなさない
- geometryはSceneRevision/content hashへbindingする
- solver入力用のwatertight mesh / surface mesh / voxel/grid等を決定論的に生成する
- self-intersection、non-manifold、open boundary等を検出してfail-closedする
- geometry simplificationを行う場合はrule/errorを明示保存し、silent approximationしない

### 2. Boundary / material model

各surfaceへ周波数依存のacoustic propertyを設定可能にする。

最低限:

- absorption coefficient
- reflection/scattering parameter
- 必要に応じてsurface impedance

wall / floor / ceiling / window / curtain / door / furniture等のmaterial presetを用意できる設計にするが、preset値は仮定として明示する。


### 2a. Object-level acoustic material assignment

room surfaceだけでなく、Scene上の家具・家電・ラグ・カーテン等にもacoustic materialを割り当てられるようにする。

対象例:

- rug / carpet
- sofa / upholstered furniture
- wood cabinet / shelf
- metal / glass AV equipment and appliances
- curtain / blind
- table / desk
- acoustic panel / absorber / diffuser

要件:

- object全体へのmaterial assignment
- 必要ならface/surface単位へのmaterial assignmentへ拡張可能なdata model
- 周波数帯ごとのabsorption / reflection / scattering / impedance
- material preset + custom measured/user-defined material
- preset値の出典・仮定・versionを保存
- material未設定を勝手な「標準材質」で確定せず、default/assumedであることをprovenanceへ残す
- object geometry + materialをprediction identity/hashへ含める
- rugやcurtain等の薄いsurfaceをvolume furnitureと同一扱いにせず、適切なsurface/boundary representationを選べる
- metal/glass主体の家電は高反射・形状散乱として扱える一方、内部構造を未知のまま過剰モデル化しない
- material変更だけでもprediction cache keyが変わり、再計算が必要になる

### 3. Source / receiver / environment model

- point sourceだけに固定しない
- speaker position + acoustic aimを扱う
- source excitation / level / phase referenceとfrequency-dependent directivityを別authorityとして扱う
- 将来的にfrequency-dependent directivity / polar dataを入力可能にする
- current O80 `aim_yaw_deg` と整合させる
- physical cabinet orientationとは分離したauthorityを維持する
- receiverは位置だけでなくorientation、calibration profile、absolute/relative level reference、timing/phase-validityを保持できる
- REW/UMIK-1比較時は既存MicrophoneProfile / AcquisitionContext authorityへbindingする
- temperature / sound-speed modelを最低限のenvironment authorityとして保存し、必要な帯域/solverではhumidity / pressure / air attenuationもversion付きで扱う

### 4. Low-frequency wave solver

まずホームシアター配置最適化で重要な低域を優先する。

初期目標帯域:

- 20–300 Hz程度

出力候補:

- complex pressure
- magnitude / phase
- room modes / eigen behavior
- listening-point FR
- spatial SPL/pressure field
- source/receiver transfer function

solver方式はFEM/FDTD/BEM等を調査し、精度・Windows対応・license・性能・GPU/CPU実装・mesh生成コストを比較して決定する。独自実装ありきにせず、利用可能なOSSを優先調査する。

### 5. Mid/high-frequency geometric solver

wave solverだけで20 kHzまで解こうとしない。

- ray tracing
- early reflections
- path length / delay
- direction
- energy decay
- scattering

を扱うgeometrical-acoustics layerを追加する。

### 6. Hybrid result

wave / geometric結果を出典を失わず統合し、少なくとも以下を表示可能にする。

- frequency response
- phase
- impulse response
- ETC
- direct / reflection path
- spatial field
- RT60 / EDT
- C50 / C80等、計算authorityが成立する指標

solverごとのvalid frequency rangeを保存し、境界外へ無言で外挿しない。

### 7. Prediction authority

既存N70 authorityと同じ原則を維持する。
