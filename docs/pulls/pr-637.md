## Summary

REV56-TARGETS implements issues #579 and #588: a sealed 21-parameter CEDIA/CTA-RP22 v1.2 standards-profile authority plus a separate response-target / spectral-balance authority that keeps "response target", "listening-area uniformity" and "target curve shape" as distinct judgments.

### #579 — `cad_rp22_profile.py` + `cad_rp22_profile_repository.py`

- `RP22StandardsProfile` (`cedia-cta-rp22-v1.2-full`, sha256-sealed) declares all 21 Appendix-A parameters bound to external-standards registry key `cedia-cta-rp22@v1.2` (#599). Each `RP22ParameterSpec` carries definition, measurement semantics, exact 4-level Min. limits plus Rec. tiers (`None` reproduces the standard's literal `N/A` → verdict `not_applicable`, never an implicit pass), HTDT authority mapping with honest `mapping_status` (`supported` / `supported_with_limitations` / `measurement_required` / `unsupported`), required inputs and source reference.
- Exact limit semantics: P1 strict `>`; P8 `boolean_allowed` (L1/L2 allowed-not-required, L3/L4 prohibition); P21 `maximum` (−8/−10/−12 dB); P2's `15/13*` encoded as `RP22AlternativeLimit('auro3d_room_design')` — 13 discrete feeds only credit when the context tag is declared.
- `evaluate_rp22_parameter`: fail-closed `met`/`not_met`/`insufficient_evidence`/`not_applicable`/`unsupported`. Evidence-class strength gates design_prediction < as_built < measured_commissioning — a design prediction never satisfies a commissioning evaluation. Dynamics parameters (P12–14) additionally require a `RP22DynamicsBasis` ranked per evaluation kind so unverified compression/headroom claims are insufficient evidence, not passes; `achieved_level` is recorded independently of `requested_level`. SPL capability (P12–14) is system headroom, never a prescribed listening level (CEDIA clarification 2025-10/2026-01).
- `evaluate_rp22_profile` → `RP22Evaluation`: whole-project `met`/`not_met`/`indeterminate` — any failure fails, unknowns yield indeterminate; `limiting_parameter_ids`/`insufficient_parameter_ids` enumerate causes, no averaged score. `rp22_verification_plan` derives the exact missing evidence per parameter; `rp22_report_rows` emits the 21-row evidence matrix.
- `derive_rp22_design_observations` bridges the existing `rp22_spatial_profile` criterion lane (`scene-layout-derivation-v1`, predicted basis) — derivable spatial parameters (P01/P05/P09) become `design_prediction` observations; nothing underivable is fabricated.

### #588 — `cad_response_target.py` + `cad_response_target_repository.py`

- `ResponseTargetProfile` (`rtgt-<sha24>`, sha256-sealed) pins a `CadTargetCurve` + interpolation rule + validity band + channel scope (screen/wide/surround/upper/lfe/subwoofer/redirected_bass/system_sum/custom) + seat scope + declared `TargetComparisonSemantics` (grid rule, smoothing, weighting, window, aggregation) — a named "house curve" without exact data is not a reproducible target.
- `ResponseTargetKind` taxonomy enforces provenance per kind: `measured_reference_derived` requires source-measurement/transform/algorithm provenance; `external_standard_profile` requires an external binding that may honestly stay `source_version_ambiguous` (e.g. AVIXA A103.01 catalogue "2023" vs store "2022" conflict); `provider_device_profile` requires provider identity + acquisition mode; `unknown` requires a rationale.
- `evaluate_response_target` → `SpectralBalanceEvaluation`: per-seat target deviation and seat-to-seat spread are independent metrics — a uniform but off-target system and a mean-matching system with one failing seat are both visible. Control/holdout seat roles are aggregated separately under the same pinned target (`holdout_vs_control_delta_db`). Out-of-scope channel groups, out-of-range extrapolation, and missing normalization anchors are rejected/honestly recorded (`normalization_failed`/`no_coverage`), never zero-filled.
- `target_identity_differences` reports which semantic fields differ between two pinned targets (optimization vs deployed vs commissioning target identity).

## Literature basis

- CEDIA/CTA-RP22 v1.2 (Sep 2023), Appendix A parameter table transcribed directly from the published document (Min./Rec. tiers, N/A cells, seat/room/system scopes).
- RP22 §11 SPL capability as headroom + CEDIA's clarification that it does not prescribe everyday listening level — enforced via the dynamics-basis hierarchy.
- Welti & Devantier seat-to-seat variance work: target conformance and area uniformity are separate metrics, which the evaluation model keeps independent.
- Harman room-curve / Toole target-curve practice: no universal flat curve — kind taxonomy + explicit semantics instead of assumed targets.
