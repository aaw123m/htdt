## Summary

Implements #948 — the common foundation for external-measurement benchmark qualification, callable from #939's RS8 executor without duplicating its execution judgments.

**`backend/src/htdt/cad_external_benchmark_fixture.py`** (~1900 lines, new):
- `ExternalBenchmarkFixture` (sealed, extra-forbid): binds license id/family, attribution, redistribution permission (auto-derived; `permitted` only for open families like CC BY-SA), origin URI, scene config, coordinate convention, `unit_semantics` (pascal_calibrated/normalized/unknown), `phase_authority`, valid band + basis, declared source/receiver points, boundary-material bindings, and per-file pins — `consumed` (fail-closed import gate) vs `bound` (advisory), with zip-member sha256/size pins. Licensed payloads are verified against the admission manifest, never vendored.
- `read_sofa_measurement` — SOFA `SingleRoomSRIR` reader handling both flat `Data.IR` and nested `Data`/`IR` layouts, `M×R×N` semantics (per-measurement source/listener positions), units taken verbatim from the dataset `Units` attr or the publisher's `Comment` declaration (never guessed), coordinate/convention and finite-sample checks, content sha256.
- `evaluate_fixture_observable` — fail-closed gate order: disjoint band → `unobservable`; semantic blockers (magnitude-only authority vs phase-bearing kinds, non-pascal units vs absolute-level tolerances, unknown units vs amplitude-sensitive kinds) → `unsupported`; no prediction/tolerance → `missing`; else `pass`/`fail`. Missing/unobservable/unsupported never fold into numeric FAIL; calibrated Pa is never conflated with normalized amplitude.
- `FixtureRunSpec` (sealed) pins solver path/revision, mesh resolution, seed, provider id/version/config sha256, evaluation profile, runtime descriptor, and run mode — `preregistered_unfitted` rejects informed params; `informed_calibrated` requires informed params + prior unfitted evidence pin.
- `run_fixture` → sealed `FixtureRunEvidence` (frozen-config drift raises `FixtureIntegrityError`); `replay_fixture` → `reproduced`/`diverged`/`blocked`.
- Providers: `AnalyticDirectPathProvider` (arrival_timing only), `StaticFixtureReplayProvider`.

**`scripts/run_external_benchmark_fixture.py`** — CLI `verify`/`import`/`plan`/`run`/`replay` with fail-closed exit codes.

**Tests**: `backend/tests/test_issue_948_bras_fixture_harness.py` — 35 tests, all green; tamper/unit/band/coordinate mismatches fail closed.

**Real licensed case executed** (no fake PASS): BRAS RS8_01a (CC BY-SA 4.0), publisher-sha256-verified `1_Scene_descriptions.zip` + `3_Surface_descriptions.zip`; `RS8_RIRs_01a.sofa` (351×1×10001 @44.1 kHz, declared Pascal units) imported fail-closed; `S1→R151` arrival observable — measured peak 7.891 ms vs analytic 7.726 ms → **pass**; replay → **reproduced** (bit-identical evidence sha256 `56d87b2f…`). Artifacts committed under `backend/fixtures/bras-rs8-01a/`; see `docs/issues/issue-948-bras-external-measurement-harness.md`.

Honest limits: the 776 MB `2_Source_descriptions.zip` bound pin is `missing` (advisory only, not fetched); the analytic provider only predicts `arrival_timing` — phase/amplitude observables stay `unsupported` until a real solver supplies predictions.
