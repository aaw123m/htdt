## Summary

Implements the software foundation for three P0 issues — continuous quantitative validation of acoustic predictions (#566), a fail-closed material-evidence compatibility gate (#570), and a small-room metric applicability gate (#571). Three new modules, no parallel truth stores: they compose with `acoustics.py`, `cad_material_library` (#771), `cad_surface_scattering` (#1032), `cad_late_decay_estimate`, and `cad_ir_analysis`.

**`acoustic_validation_envelope.py` (#566)** — fixture taxonomy A (analytic/semi-analytic), B (numerical reference — same-algorithm self-comparison requires `same_algorithm_declared_limitation` + an explicit limitation note), C (hybrid-boundary overlap/transition/timing/normalization checks via `evaluate_hybrid_boundary`), D (retained `MeasuredCorpusSlot` — `empty_unknown` forbids measured values/evidence hashes; `populated` requires six provenance classes + evidence sha256). `ObservableThresholdRule` requires a written rationale; `limit=None` honestly reports error distributions instead of forcing PASS/FAIL. `AccuracyEnvelopeRecord` seals solver+version × observable × band × domain × boundary assumptions × fixture set × error distribution × state — `covers()` refuses cross-version/observable/band claims, and there is deliberately no global accuracy score. Retained set: VAL10 (free-field arrivals/−6.02 dB), VAL20 (6×4×3 m rigid modes), VAL30 (image-source first reflection), VAL50 (hybrid 150–300 Hz overlap), VAL60 (empty owned-room holdout slot).

**`cad_material_evidence_compatibility.py` (#570)** — `MaterialBoundaryEvidence` records pin method class (ISO 354 / ISO 10534-2 / ISO 17497-1/-2 / in-situ / declared / derived / inverse / unknown), standard revision, physical quantity, incidence and phase semantics, frequency grid, build-up identity, and uncertainty contributions. `METHOD_PRODUCIBLE_QUANTITIES` makes method→quantity honesty a construction-time invariant (ISO 354 cannot produce a normal-incidence coefficient). The versioned `COMPATIBILITY_RULES_V1` matrix decides eligibility per consumer (`wave_complex_boundary`, `geometric_arbitrary_incidence`, `geometric_scatter_fraction`, `statistical_energy_model`, `hybrid_lf_wave_boundary`, …) → `DIRECTLY_COMPATIBLE` / `COMPATIBLE_WITH_DECLARED_ASSUMPTIONS` / `DERIVED_WITH_UNCERTAINTY` / `INCOMPATIBLE` / `INSUFFICIENT_EVIDENCE` with reason codes. Hard guards: ISO 17497-2 diffusion is never a GA scatter fraction; magnitude-energy evidence never feeds a complex wave boundary; normal-incidence tube data never silently feeds an arbitrary-incidence boundary; ISO 354 evidence on resonant build-ups is refused (ISO 354 excludes weakly damped resonators); single-number ratings never substitute for band data. Conversions require an immutable `BoundaryConversionArtifact` (source id+hash, model+version, assumptions, uncertainty) — derived data caps at `DERIVED_WITH_UNCERTAINTY` and is never relabeled measured.

**`acoustic_metric_applicability.py` (#571)** — `evaluate_metric_applicability` classifies each metric against room context: band below the Schroeder region (`f_s = 2000·√(T60/V)`, modal overlap `N(f)·Δf`) → `modal_non_diffuse` + `MODAL_AUTHORITY_REQUIRED` (requires `modal_decay_record`); transition zone → limited applicability only. `DecayMetricProfile` binds metric + ISO 3382-2 revision + band + positions + method + fit interval (EDT 0→−10 dB, T20 −5→−25 dB, T30 −5→−35 dB enforced) + dynamic range + SNR + aggregation — insufficient decay range/SNR fail closed. `SpatialDecayRecord` retains per-position decay before aggregation (Prinn 2025: LF decay is a field, not a scalar); high spatial variance forbids a single scalar. `ModalDecayRecord` carries per-mode decay with no rt60/t60 fields — modal decay cannot be relabeled. `MetricComparisonEligibility` makes prediction↔measurement `INCOMPARABLE` on semantic mismatch; `evaluate_optimization_metric` refuses inapplicable metrics as optimization objectives and substitutes the correct evidence kind.

## Literature basis

- ISO 3382-2:2008 — T20/T30/EDT procedures, survey/engineering/precision classes, decay-range requirements; ISO 3382-1 — RT JND ≈ 5 %.
- Schroeder 1962 — `f_s ≈ 2000·√(T60/V)` at ~3-fold modal overlap; Morse & Bolt modal density `N(f)=4πVf²/c³+πSf/(2c²)+L/(8c)` and bandwidth `Δf≈2.2/T60` (verified numerically: at f_s the overlap index lands in the ~3 transition zone).
- ISO 10534-2:2023 — tube α is "not comparable" with ISO 354 random-incidence α; Annex E diffuse estimation only for locally reacting materials.
- ISO 354:2003 — diffuse-field absorption; weakly damped resonators excluded from scope.
- ISO 17497-2:2012 — the diffusion coefficient is "not suitable for direct use as an input to current diffusion algorithms in geometric room acoustic models".
- Prinn 2025 — low-frequency decay is a spatial field (per-position evidence retained).
