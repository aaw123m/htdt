## Summary

Implements #888: a headless `htdt <family> <verb>` dispatcher (`htdt.headless_cli:main`, wired as the `htdt` console script in `backend/pyproject.toml`) that runs the sealed commissioning authorities — #869 sweep engine, #875 campaign runner, #876 channel verification, #877 calibration wizard, #878 deployment pipeline, #885 diagnostic orchestrator — reproducibly and without Qt.

**One sealed run record per mutating invocation.** `CadHeadlessRunRecord` (`hrun-…`, new table `cad_headless_run_records`, schema v108) pins `spec_sha256` + canonical spec JSON, `tool_version`/`tool_commit_sha`/`tool_commit_dirty`, `python_version`/`platform`/`env_fingerprint` (sha1 of interpreter+OS+installed dists), `argv_sha256`, `backend_id`/`backend_is_simulated`, outcome/verdict/record_refs/timings. Refused (`unauthorized`), `blocked`, and `failed` attempts seal records too — refusals are evidence.

**Fail-closed exit lattice** (`OUTCOME_EXIT_CODES`): `succeeded`/`dry_run` → 0 only; `failed` 2, `blocked` 3 (precheck blocked, operator gate parked, ambiguous/incomplete/unknown evidence), `unauthorized` 4, `missing_evidence` 5, usage 1, internal 6, `cancelled` 7. `--json` emits a stable `htdt-headless-result-1` envelope `{verb, outcome, exit_code, verdict, reason, run_record_id, run_sha256, records[], data}` on every verb — `records[]` carries `AuthorityRef` pins for every artifact produced.

**Authorization is session-only, never in spec files**: `--arm` gates device I/O on sweep/campaign/channel-verify/calibration/diagnose runs; `--auto-confirm-position` (campaign), `--confirm-hardware` (calibration `await_*` gates), `--authorize-apply`/`--authorize-rollback OP` (deployment one-shot tokens), `--authorize OP` (diagnostic `device_mutation` plans). No credential flags exist — credentials stay vault handles.

**`--dry-run` performs no sealed writes** (engine precheck only / plan build without save / in-memory `WizardStores` / early return before repository creation — verified down to "no `cad-scenes.sqlite3` created"). `--timeout-seconds` arms a cooperative deadline that cancels engines/runners/wizard/orchestrator → `cancelled`. `--plan FILE` reruns re-validate payloads through the sealed store before execution.

New modules: `cad_headless_cli.py` (record model + spec models per verb, `extra='forbid'`), `cad_headless_cli_repository.py` (`_SealedStore` round-trip), `headless_cli.py` (dispatcher). Audit wiring: `_RepositoryChain` + `_REPLAY_PROBES` entry for `cad_headless_run_records` (audit suite green without a `_TABLE_POLICY` row — chain+probe is the coverage).

Docs: `docs/issues/issue-888-headless-cli.md` — verb map, exit lattice, authorization flags, evidence/reproducibility model, what remains device-only.
