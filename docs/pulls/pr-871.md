- `cad_solver_confidence_bound.py` `evaluate_input_envelope` — `solver_envelope_ref`/`capability_manifest_ref` sha-pins were ignored; the solver gate ran on whatever the caller passed. Pinned envelopes now resolve via `_resolve_envelope_refs` (id + sha must match a supplied record).
- `cad_owned_room_campaign.py` `evaluate_campaign_promotion` — a verdict pinning phantom, tampered, or cross-campaign measurement/prereg refs could reach `recommendation_eligible`. A structural-binding pass (refs resolve id+sha; holdout refs land on `role='holdout'` measurements) now floors the ladder at `owned_room_insufficient`.
- `cad_owned_room_campaign.py` `CampaignVerdict` — duplicate `claim_kind` rows silently last-won inside the evaluator; the validator now rejects them.
