## Summary

Screen 9-point (ANSI) measured-quality map rendered on the **evaluated image surface** in the Room 3D viewport — luminance, chromaticity, focus, convergence — sourced only from the sealed spatial-image authority (#619 plan/set/map/evaluation records), never from re-derived screen geometry.

**New module** `backend/src/htdt/room_screen_quality_map.py` — a Qt-free resolver (`resolve_screen_quality_map` + `ScreenQualityMapController`) mirroring `room_treatment_overlay.py`:

- `x_fraction`/`y_fraction` → bilinear position on `evaluation.projection.image_plane_corners` (BL,BR,TR,TL; `y` measured from top → `s = 1 - y`), so rotation/flips/portrait/off-axis are exact for both projection and `DirectViewGeometryEvaluation.surface`.
- Declared `physical_xyz_m` verified against the surface position; `> max(5 cm, 2 % of min dimension)` → `misaligned` marker — never auto-corrected.
- Absolute 6-band color scales per quantity+unit (`scale_color_for`); chromaticity renders the measured x,y pair as its own swatch — never merged into a scalar. Unscaleable quantities → `unscaled` gray markers + read-only reason.
- Heatmap cells draw **only** when a persisted `CadSpatialDerivedMap.rendered_artifact_ref` verifies: bounded `ManagedAssetStore` read → sha256 re-verify → `kind`/`quantity` match → per-cell quads. Otherwise a notice explains why.
- Coverage: persisted `CadImageUniformityEvaluation` verdict preferred; else live `evaluate_spatial_uniformity` reports `criterion_unbound` honestly, with missing roles.
- Stale-reuse guards → read-only: scene-content-hash drift, projector spec sha swap, screen entity swap, plan sha mismatch; per-(point, viewpoint, quantity) binding so one reading is never reused.

**Viewport**: `'quality-map-'` in `_OVERLAY_ACTOR_PREFIXES` (auto-clear); `render_screen_quality_overlay` draws non-pickable disc markers, edge rings, verified heatmap cells, ASCII status text; staleness guard aborts paint on hash mismatch.

**UI**: `RoomVideoPanel` gains a 「スクリーン品質マップ（9点測定）」 section — set/quantity/viewpoint selectors (quantities limited to observed), per-point list, detail readout (value/unit or x,y pair, instrument, uncertainty, stimulus, viewpoint), coverage label, 「再測定手順へ…」 deep link to the Video Commissioning `verify` page; the commissioning workspace gains a 「スクリーン品質マップを開く」 link back to Room placement. `RoomWorkspace` resolves against `current_head` inside the deferred-render block.

**Tests**: `backend/tests/test_issue_1003_screen_quality.py` — 17 tests (ANSI-9 exact positions, center-only, partial corners, rotated/portrait/flipped surfaces, quantity-unit binding, stale eval/spec/screen/viewpoint reuse guards, physical_xyz_m tolerance, verified + tampered heatmap, unscaled → read-only + reason). Adjacent suites green (test_rev57_proj, test_cad_video_geometry, test_room_workspace, test_cad_video_commissioning, test_issue_1009_treatment_overlay, test_cad_video_measurements — 142 passed).
