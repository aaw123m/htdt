## Summary

Implements three sealed, fail-closed metric authorities (native schema v27→v28, 12 tables + 14 indexes; v27 was taken by REV56-TARGETS so the migration renumbered on merge):

**#580 background-noise metric authority** — `cad_room_noise_metrics.py`: `RoomNoiseMetricProfile`/`BackgroundNoiseMeasurement`/`NoiseCriterionEvaluation` with the closed family taxonomy `nc`/`ncb`/`rnc`/`rc_mark_ii`/`a_weighted_level`/`custom`/`other`. NC uses the S12.2-2026 two-step (SIL designation at 500/1k/2k/4k → `NC-<round(SIL)>`, tangency fallback naming the governing band, e.g. `NC-45 (125 Hz)`); NCB uses the Beranek 1989 curve table plus rumble/hiss/vibration qualifiers; RC Mark II uses the MF-band closed form with N/R/H/Q region diagnostics; RNC is deliberately fail-closed (`rnc_curve_table_not_registered` limitation). Operating state and temporal class gate applicability — LF-fluctuating evidence is `out_of_scope` on NC/NCB/RC, all-unknown state is `limited`, per-position spectra are preserved and worst-position wins. Threshold verdicts use a #577-style guard band (`indeterminate_guard_band`). `assert_no_scalar_substitution` hard-errors cross-family relabels (NCB-as-NC); `profile_for_rp22` pins the NCB-1995 profile that CEDIA/CTA-RP22 v1.2 depends on.

**#605 speech-intelligibility authority** — `cad_sti_authority.py`: `SpeechIntelligibilityProfile` (IEC 60268-16:2020+COR1:2025 and legacy-2011 weightings), `STIMeasurement` (mandatory `bnm:` binding to the #580 noise record), `STIPrediction` (mandatory #566 validation ref; simulated methods can never mint a measurement), and `DialogueIntelligibilityAssessment` (per-seat results + worst/percentile, no invented universal thresholds). STI math: octave-band MTR → SNR clipped to ±15 dB → TI → `Σα_k·TĪ_k − Σβ_k·√(TĪ_k·TĪ_{k+1})` (adjacent-band redundancy, Steeneken Table II; perfect transmission returns 1.0 exactly). IR-derived MTR via the band-energy time function. `compare_sti_evidence` returns `incomparable` on any path/method/profile/noise mismatch — before/after claims stay honest.

**#607 content loudness / normalization authority** — `cad_loudness_authority.py`: `ContentLoudnessProfile` (BS.1770-5 production / BS.1770-2026-draft research-only / AES77-2023 / EBU R128 v5.0), `ProgrammeLoudnessMeasurement` (K-weighted dual gating: −70 LUFS absolute + −10 LU relative; surround weight 1.41, LFE excluded), `NormalizationObservation` (off-mode cannot carry `applied_gain_db`), `PlaybackGainState`, and `LoudnessMatchingRecord`. `assert_quantity_separation` hard-errors any LUFS→SPL/capability conversion without a `calibrated_chain_ref`; `normalization_audit_diff` reports `metadata_claim_only`/`partially_realized_in_room`/`fully_realized_in_room` so applied gain vs measured SPL deltas stay visible.

All three repos are append-only with commit-order enforcement (evaluation→measurement+profile, gain-state→observation) and `_assert_sealed` re-verifies id/sha integrity on save so `model_copy`-forged payloads can't slip through. Registry seeds added for ansi-asa-s12-2@1995 (superseded, RP22 NCB lineage dependency), itu-r-bs1770@5 / @2026-draft, aes77@2023, ebu-r128@v5.0.
