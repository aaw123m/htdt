## Summary

Adds the dedicated A/B design-alternative diff overlay (#1007): the Presentation workspace `compare` page gains `重畳（単一画面）` and `差分のみ` display modes beside the existing `横並び`, drawing color-coded diff ghosts of two pinned `DesignComparisonSet` alternatives plus a `差分理由カード`.

Every verdict comes from `diff_alternatives` (`backend/src/htdt/cad_design_comparison.py`) — the sole comparison authority. The UI never derives changed/unchanged from mesh or coordinate differences; `design_ab_overlay.build_ab_overlay_preview` maps the authority's `SceneDiff` straight into render categories:

| `SceneDiff` | category | ghost |
|---|---|---|
| `removed_entity_ids` | 削除（案Aのみ） | red wireframe at the OLD persisted position |
| `added_entity_ids` | 追加（案Bのみ） | green wireframe at the NEW position |
| position/orientation in `entity_changes` | 移動・回転（元→先） | amber origin+destination outlines + arrow |
| same, degraded frame | 位置関係（参考表示） | paired outlines only — never an arrow |
| other fields (size/material/role/kind/…) | 属性変更のみ | blue outline + attribute-diff card row |

Honesty contract:
- Cross-document / mismatched `coordinate_system` / unresolvable pins (hash or revision drift) → explicit `比較不可` state with reasons, never a guessed overlay. A pinned foreign revision can never ghost-display as the current scene.
- Room / wall-topology / semantic-geometry differences degrade `frame_state`: positional correspondence becomes reference-only (paired outlines, both room shells, `AB_OVERLAY_DEGRADED_FRAME_NOTE` appended to the disclaimer).
- Card-row reasons come only from recorded evidence (`semantic_change_summary`, then evidence-ref labels); missing records print `理由未記録`. Evidence refs list their exact `EvidenceAvailability` state — unsupported/missing evidence is never colored as improvement.
- `staleness_note` always names which side (if any) is the current head — pinned pairs stay historical after head advances.

`RoomViewport3D.render_design_ab_overlay` draws non-pickable `abdiff-*` actors (registered in `_OVERLAY_ACTOR_PREFIXES` so every bulk sweep drops them); `compare` page mode switches re-dispatch and re-verify pins on every load; refresh/set-switch clears the layer. Diff-card rows deep-link: click → highlight re-render of that entity. The comparison never mutates the current `SceneRevision`.
