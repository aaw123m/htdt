## Summary

Issue #541 asks for ONE guided video commissioning journey — measurement import → SDR/HDR diagnosis → corrective actions → before/after evidence — for a user calibrating a TV/projector, benchmarked against Home Theater Maestro. The color-science authorities already exist (#80 photometric/HDR/colorimetry, #239/#240 corrected metrics + EOTF, #283 CCMX/CCSS, #285 projector references, #295 test patterns); this PR composes them into a bounded, persisted journey — no parallel color model.

**New authorities** (`backend/src/htdt/`):

- `cad_video_commissioning.py` — `GuidedVideoCommissioningSession` (content-derived `vcs-` ids, `rebind_video_session` supersedes); `evaluate_video_readiness` → READY / READY_WITH_LIMITATIONS / INSUFFICIENT_EVIDENCE / INCOMPATIBLE gate evaluated on the **union** of all session-linked measurement sets (one HCFR export alone is honestly insufficient); `diagnose_video_measurement` → typed `VideoDiagnosisFinding`s (white_point/grayscale/eotf_tracking/peak_luminance/gamut/black_floor…) with per-finding JA plain-language explanations and overall verdict; `propose_video_actions` → `VideoCommissioningProposal` whose actions cite the supporting diagnosis/evidence with `evidence_bound`/`indicative` confidence and explicit limits; `record_video_operator_adjustment` (iteration index, baseline→optional follow-up sha chain); `compare_video_measurements` → comparable metric deltas (`improved`/`regressed`/`inconclusive`) or honest `incomparable` with `incompatibility_reasons` — never a misleading table; append-only status events (`open`→`completed`/`abandoned`) and `evaluate_video_journey` → 7 derived steps (`session/readiness/measure/diagnose/adjust/verify/report`).
- `cad_video_measure_import.py` — ColorHCFR interchange: `*.GrayScaleSheet.csv` (IRE→`w<level>` stimulus ids + XYZ) and `*.PrimariesSheet.csv` (6 primaries) parsed per the documented `Export.cpp` layouts; `format='htdt-video-measurements-1'` JSON round-trips byte-identical with `export_video_measurements`. `.chc` is an undocumented proprietary binary → honest `unsupported` with a JA hint naming the documented interchange. `import_video_measurements` never raises — returns a typed `VideoImportResult` (imported/unsupported/malformed + warnings) and every attempt records an append-only `VideoImportBatch`.
- `cad_video_commissioning_repository.py` + schema v18 — 8 append-only `cad_video_*` tables, conflict/integrity guards (same id + different sha → `VideoCommissioningConflictError`), terminal-state validation, and `journey_state(document_id, session_id)` projecting the full evidence chain.

**UI** — new `映像調整` workspace (`WorkspaceId.VIDEO`): the 7-step journey strip + 6 contexts (セッション/読み込み/診断/対策/再測定・比較/結果). Session form binds surface/mode/target/meter/signal-range; readiness renders the check table; import page lists supported formats + per-session sets; diagnosis renders finding verdicts + explanations; actions page proposes, then records operator adjustments with baseline + optional follow-up set; verify page runs before/after (incomparable → explicit reason line); report page renders the full persisted evidence chain and completes/abandons the session via a confirmation. All user-facing text JA.

**Honesty bounds** — diagnoses only evaluate what the measurement set covers (absent groups → `不明`, not fabricated); corrective actions never exceed the cited evidence; comparisons across disjoint stimulus sets report INCOMPARABLE with reasons; test patterns stay stimulus artifacts, not evidence.

**Verification** — 22 commissioning + 11 import + schema/shell/UX-surface tests green (import round-trip, diagnosis determinism, evidence-chain integrity, JA text). Real-GUI run: created session → evaluated readiness (insufficient → ready-with-limitations after multi-set import) → imported 3 HCFR CSVs → 2 diagnoses → 3-action proposal → 3 adjustments → 2 comparisons (one honest INCOMPARABLE, one regressed deltas) → completed session, journey 7/7.

**Out of scope (per issue)** — meter hardware control, Calman/ColourSpace integration, automatic 1D/3D LUT/CMS writes, `.chc` native read, Dolby Vision. A unified-export report artifact remains future work; the report page today renders the evidence chain, not a PDF.
