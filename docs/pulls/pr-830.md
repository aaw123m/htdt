## Summary

REV63 #814 — evidence-backed applicability/confidence envelope in UI and reports. A 7-dimension envelope presentation, **not** a single score: each dimension maps to an evidence state derived strictly from stored evidence — fail-closed, never inferred.

- `htdt/cad_applicability_envelope.py` — sealed model + fail-closed composer + report/export path.
  - Dimensions (issue order): `representational_capability`, `verification`, `external_validation`, `input_qualification`, `owned_room_evidence`, `uncertainty_limitations`, `context_of_use`.
  - Evidence classes: `externally_validated` > `numerically_verified` > `holdout_validated` > `qualified` > `bounded` > `supported` vs negatives `failed` > `outside_applicability` > `unsupported` > `insufficient_evidence` > `stale` > `absent`.
  - `load_envelope_evidence(scene_repository)` reads the landed repositories document-scoped (#809 qualifications/mappings/preregistrations, #811 input envelopes + claim bounds, #810 protocols/evaluations/verdicts) plus the `cad_solver_capability_manifests` table; `context_for_document` pins adapter/solver-path/scene identity only when the sealed refs agree.
  - Staleness is declared, never silently counted: adapter id/version drift, prereg provider drift, solver-version drift, scene-revision sha drift all move records to `stale_refs` + `staleness_notes`.
  - `context_of_use` emits three decisions (`inspect_prediction`, `compare_candidates`, `automatic_recommendation`); `automatic_recommendation` is permanently `blocked` because no landed authority can mint owned-room-validated evidence.
  - `ApplicabilityEnvelopeReport` (`aer-` id + `report_sha256`) binds external qualifications to their benchmark identity for replayable export; JA line helpers shared by UI + report.
- `htdt/applicability_envelope_panel.py` — `ApplicabilityEnvelopePanel`/Dialog: dimension table (次元/判定/状態/帯域/証拠), phenomenon matrix, claim rows, decision lines; `absent`/`unsupported` map to `SemanticState.UNSUPPORTED` — never a green state.
- `application_pages.py` / `workflow_application.py` — Support-page 「適用範囲エンベロープ」button composes the envelope for the open document (lazy imports).
- `measurement_evidence_display.py` — `applicability_*` JA helpers next to the #810/#811 ones.

**No aggregate confidence number anywhere** — `test_issue_814_envelope.py` recursively asserts none exists in emitted structures. Absent evidence renders `未取得`; a FAIL is never hidden behind an absence (`conflicts` keeps surviving positives visible).

No schema change: the composition layer adds no sealed tables, so `NATIVE_SCHEMA_VERSION` stays put.
