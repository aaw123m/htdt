## Summary

Deeply nested JSON surfaces from `json.loads` as `RecursionError` — not `JSONDecodeError` — and a GLB document with wrong-typed members surfaces `AttributeError`/`TypeError`/`IndexError`/`OverflowError`. Both classes escaped every `except (OSError, ValueError)`/`except (…, JSONDecodeError)` boundary they met, confirmed by feeding 111 crafted hostile inputs through the real entry points:

- **`raw_mesh._parse_glb`** — mistyped document members (`"meshes": "x"`, `"attributes": []`, `"count": 1e999`, `"nodes": ["x"]`, …) and a deep-nested JSON chunk reached `import_raw_visual_mesh` callers as raw `AttributeError`/`TypeError`/`OverflowError`/`RecursionError`, bypassing the documented `RawMeshImportError` contract that `room_workspace` catches. The dispatch now folds those classes into `RawMeshImportError('GLB document is malformed')`.
- **`launch_intents._read_bounded_json`** — a deep `.htdtproject` descriptor crashed `build_launch_intent` on the file-association launch path.
- **`capture_bundle.parse_json_bytes` / `capture_import.import_capture_artifact`** — a deep-nested `manifest.json` escaped `validate_bundle` and broke the staged-failure contract on both directory and zip sources (LAN-upload path).
- **`application_preferences`, `file_dialog_memory`, `commissioning_plan`, `runtime_instance`, `reference_libraries`, `data_relocation`, `native_backup` journal, `activity_center`, `automatic_backup`, `build_info`, `support_diagnostics`, `authority_revalidation`, `rew_api._get_json`** — the same class: a deep-JSON state file bypassed each reader's "unreadable → defaults/diagnostic" contract (startup crash instead of CORRUPT state for preferences).

Each fix is boundary-level only — `RecursionError` (and the GLB mistyped-member classes) folded into the existing reject/degrade paths; no parser refactoring. After the fixes the same 111 probes produce zero uncaught exceptions.

Also verified clean (probes, no change needed): zip traversal/absolute/symlink/11k-member/ratio members, manifest traversal paths, dup-key manifests, REW text/API edge cases incl.
