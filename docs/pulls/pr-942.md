## Summary

REV70 slice of #866 — lands the real IFC source intake and wires `GeometryIntakePanel` into the Room workspace shell, replacing the fixture-only path the issue doc listed as remaining work.

- `build_ifc_intake_subject(document_id, artifact, mappings)` in `cad_geometry_intake.py`: translates a real parsed IFC STEP file (via `build_ifc_import`) into a `GeometryIntakeSubject` with `source_kind='ifc_import'`. Parts pin `AuthorityRef(kind='ifc_entity_mapping')` and the subject pins `AuthorityRef(kind='ifc_import_artifact')` — genuine sealed refs, never fixture-shaped. Unit authority is derived per-part from the artifact's coordinate resolution (declared → `format_specification`; declared-but-unnamed → `custom` + exact scale; undeclared → fail closed). `extruded_area_solid`/`bounding_box` descriptors become world-meter meshes; `faceted_brep` or withheld transforms degrade to honest `IntakePartStub`s. `IFCOPENINGELEMENT` voids are consumed through host `openings` links into declared `IntakeOpening` records (area proxy in m², `is_open = filling is None`); voids whose host can't resolve still surface as stubs so no file content is silently dropped.
- New `GeometryIntakeController` owns the live chain and all persistence: `import_ifc_source` → `run_health_check` → per-action `submit_decision` (exact-cover seals the acceptance) → `derive_revision` → `evaluate_readiness`/`select_solver`. The prior verdict is deliberately retained across re-imports so `verdict_evidence_state` can mark it `stale_geometry`/`current` instead of silently dropping a bound result. The controller takes the dispatch repository as a dependency — the app passes `PredictionAuthorityLane.dispatch_repository` so solver reads verify through the production authority resolvers.
- `GeometryIntakePanel` gains `ifcImportRequested`/`sceneSubjectRequested`/`diagnoseRequested`/`deriveRequested`/`solverSelectionChanged` signals, a solver combo (placeholder row stays selected until the operator picks), a decision-progress label, `mark_decided` row disabling, and a stale-evidence badge on the verdict.
- `RoomWorkspace.bind_geometry_intake` connects everything inside the geometry dock page (below `RoomGeometryPanel`); `locateRequested` maps to the scene-entity selection idiom and reports an honest `対象はシーン内に存在しません` status for IFC-only parts; import failures surface through `_set_operation_error`.
