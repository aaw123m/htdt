## Summary

REV26 roadmap-residual audit + implement pass. The audit found exactly one worthwhile implementable-now item: the built-in StandardsProfile criteria (Issue #170) had **no production observation source** — `StandardsWorkspaceModel.evaluate()` always ran with `observations=()`, so every criterion reported `UNKNOWN/missing_observation` forever regardless of scene contents. This PR wires the promised observation lane for the subset of criteria whose quantity is honestly derivable from scene geometry, plus marks four R150 round docs that had become stale after PR #430/#432/#433.

### What changed

- **New `cad_standards_layout_observation.py`** — the declared `scene-layout-derivation-v1` provider. For each derivable criterion it computes the quantity from the exact evaluation target (seat `acoustic_reference_position`, speaker channel roles, room footprint), persists a `StandardsObservationAuthority` (`predicted` basis, exact SceneRevision/SystemVariant/entity binding) reusing an identical existing record, and feeds a `CriterionObservation` to the evaluator:
  - `rp22.p01` listener→boundary distance (min over seats)
  - `dolby.5.1.2` four role azimuths (signed azimuth about listener forward +Y)
  - `rp22.p05` adjacent-surround horizontal angle (azimuth-consecutive pairs, cyclic)
  - `rp22.p09` adjacent upper vertical angle (same-side L/R row chains only — row ends are not adjacent)
  - Quantities with no honest layout source (recommended-zone membership, upfiring mode, wide/AURO layer membership, all SPL/headroom inputs) are **never derived** — the criterion stays `UNKNOWN` per the fail-closed contract.
- **`StandardsWorkspaceModel.evaluate()`** — derives observations against the materialized target document (variant path re-resolves `baseline_revision_id` + `variant_sha256`), carries prior non-derived observations forward, dedups identical (profile version + hash + observation set) results, and links `reevaluation_of_id` to the prior same-target evaluation.
- **Stale-doc reconciliation** — snapshot/`as of` markers added to `R150_MULTI_REGION_PORTAL_PROPAGATION.md` (PR #265, superseded by #432 multi-Portal reflected paths), `R150_ARBITRARY_REGION_GRAPH_PORTAL_PROPAGATION.md` (PR #270, same), `R150_DETERMINISTIC_GA_ADAPTER.md` (non-claims superseded by #430 late-field + #432), `R150_COMPLEX_PATH_RESPONSE_AUTHORITY.md` ("R160 unimplemented" superseded by #287/#433). `STANDARDS_PROFILES.md` gains the lane's paragraph and a narrowed deferred-scope bullet; `IMPLEMENTATION_STATUS.md` gets a milestone-level row update.
