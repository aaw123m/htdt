## Summary

Adds a sealed domain authority for the **electrical audio path** (AVR / processor / DSP / DAC / preamp / power-amplifier chain) so an acoustic residual is never attributed to speaker/room while upstream electronics were never verified over the theater's actual levels, frequencies, loads and channel counts.

New module `backend/src/htdt/cad_playback_electronics.py` + `cad_playback_electronics_repository.py`, wired into native schema **v80** (base was v79 — a sibling claimed v79 between contract and implementation), audit replay probes, and `_ROW_BINDINGS`.

**Sealed models** (frozen pydantic, digest-derived ids `eapp-`/`etm-`/`ele-`/`peq-`):

- `ElectronicAudioPathProfile` — exact path/state identity: `path_class`, endpoints, ordered stages, device/hw/firmware, sample rate/format, trims, `provider_bypass_label` vs `observed_processing_states`, channels driven, load kind/impedance, supply/thermal state, channel match tolerances.
- `ElectricalTransferMeasurement` — per-channel bound measurement: magnitude/phase/complex refs, gain, `delay_ms` + `delay_method`, stimulus, de-embedding state + interface-correction ref (`de_embedded` requires the ref), method refs `@edition`, digital-path semantics (formats, reference convention, word length, SRC/dither/clock, bit-perfect), drive/load/thermal state, uncertainty.
- `ElectronicLinearityEvidence` — level-sweep points (`linear`/`compressed`/`limited`/`clipped`/`protected`/`indeterminate`/`unknown`) + method-pinned nonlinear quantities (THD, THD+N, harmonics, IMD, difference-frequency, DIM-style) retaining unit/stimulus/bandwidth/level/load; `domain` tag keeps `electronic_path` distinct from `electroacoustic_system` (#192) and `measurement_chain` (#695/#699).
- `PlaybackElectronicsQualification` — sealed verdict record: state, `evidence_composition` (`ideal_electronics_assumed` … `device_transfer_unknown`), valid frequency/level domain, limitation reasons, matching results, `bypass_verdict`, `staled_by_ref`.

**Fail-closed evaluator** `evaluate_electronics_claim` returns the first matching verdict: `unknown` → `stale_after_device_change` (epoch ref mismatch / `staled_by_ref`) → `insufficient_evidence` → `state_dependent` → `interface_confounded` → `processing_detected` (provider bypass label contradicted by observed processing) → `nonlinear_limited` → `channel_mismatch` → `path_unverified` → `measured_processing_effects` → `electronics_qualified_with_limitations` → `electronics_qualified`. Evidence binds only when `profile_ref` id **and** sha match, `path_class` matches, and `evidence_origin == 'measured'` — predicted/simulated/vendor-declared evidence never binds.

**Repository** — `CadPlaybackElectronicsRepository` with append-only `_SealedStore`s: save re-verifies the seal, forged same-id/different-sha redefinition raises `PlaybackElectronicsConflictError`, `get` verifies id+sha+every bound column, `list` verifies `document_id` per row.

**Wiring** — 4 tables + indexes in `NATIVE_BASELINE_DDL`, `_migrate_79_to_80`, `audit_table_modes() == 'replay_canonical'` for all 4 tables, schema ledger `(80, 'migrate native schema to v80')`.

Tests: `backend/tests/test_issue_790_electronics.py` — 50 tests covering every verdict path (including all issue fixtures EAP10–EAP80), seal integrity, validator pinning, repository round-trip/append-only/tamper detection, schema/audit/registry wiring.
