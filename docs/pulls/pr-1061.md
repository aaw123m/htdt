## Summary

Read-only acoustic-treatment coverage overlay on `RoomViewport3D`: every exact-bound `AcousticTreatmentPlacement` draws its **clipped effective patch** (`TreatmentFootprint.patch_uv_polygons`) on the host surface — never the authored rectangle. Same staleness discipline as #999's field overlay: resolution keys off the EXACT current `SceneRevision`, so a scene edit can never leave a stale footprint drawn.

**Transform path**: `patch_uv_polygons` (host-plane UV) → world domain via `plane_origin_m + u·plane_u_axis + v·plane_v_axis` → VTK render space via `domain_to_render` (x, −y, z) — the identical flip convention `room_field_overlay.py` uses.

**Shape**:
- `room_treatment_overlay.py` (new, Qt-free): `resolve_treatment_overlay` + `RoomTreatmentOverlayController` (cache keyed on head revision + placement SHAs). Each resolve lists latest placement versions (`CadAcousticTreatmentRepository.latest_placements_for_document`, new), re-evaluates each binding against the live head, and re-derives the footprint via a new public `derive_treatment_footprint` entry (same `_derive_footprint` the solver uses).
- `RoomViewport3D.render_treatment_overlay`/`clear_treatment_overlay`: `treatment-overlay-` prefix added to `_OVERLAY_ACTOR_PREFIXES`; non-pickable translucent fill + closed outline per patch ring, ASCII-only status text; polygon-offset over coplanar walls.
- `RoomWorkspace`: controller wired in `_render`'s deferred block, gated on acoustics context + acoustics overlay toggle; leaving acoustics clears the actors.
- `RoomTreatmentPanel` 「壁面被覆 (ビューポート表示)」 section mirrors the resolved scene via `coverage_provider`.

**Honesty vocabulary** (explicit, never silent):
- `提案された配置` (accent fill) vs `設置記録` (success fill).
- `実効面積/矩形面積` ratio — an overhanging rectangle reports `clipped` + its ratio instead of painting untreated wall.
- `ホストバインド失効` notices for non-`exact` bindings (`stale_scene_revision`, `surface_removed`, `surface_authority_mismatch`, `legacy_unverified`, …), `ホスト面未設定`, `範囲外` (empty clipped patch), `重複`/`OVERLAP` warnings for same-host patch intersections — viewport ASCII lines + JA panel lines.
