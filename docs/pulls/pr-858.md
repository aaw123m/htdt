## Summary

Issue #838 slice A: delegated measurement provider + file-export deployment authority. Two guarantees drive the design:

1. **REW stays a delegated provider** — orchestrated, never copied into HTDT core. A sealed, version-bound `DelegatedProviderManifest` declares the documented capability surface with per-capability conditions; `automated_sweep` is `licensed_required` (REW Pro upgrade), so a free-tier manifest can never silently gate it as `provider_capable`.
2. **File truth ≠ runtime truth** — Equalizer APO's own docs state unsupported lines are silently ignored, so a written config file can never become verified runtime state. `FileExportDeployment` structurally caps `runtime_state` at `runtime_not_attested`; `post_measurement_verified` is reachable only via bound post-deployment measurement refs on a readback-matched file.

### New modules

- `cad_delegated_provider.py` — `DelegatedProviderManifest` (`dpm-`), `ProviderCapabilityEntry` (supported / licensed_required / unsupported / unknown), `ProviderAcquisitionRecord` (`dpa-`; `observed` requires evidence refs or raw artifact sha, never binds evidence on cancelled/error/capability_rejected), `evaluate_provider_gate` (fail-closed), `build_provider_acquisition` (gate-enforced — `observed` raises when not capable), `REW_DECLARED_CAPABILITIES` + `build_rew_provider_manifest` (merges the sealed #599 `RewEngineSession` identity), `build_htdt_native_import_manifest` (file-provider path). JA labels included.
- `cad_file_export_deployment.py` — `FileExportDeployment` (`fed-`): pins the exact exported-bytes hash, renderer identity, target scope repr, `file_state` (exported → installed → readback_matched/mismatch / blocked), `runtime_state` (two values only), `evidence_mode` (unverified_export < operator_attestation < file_level_readback), `derive_file_export_state`, `evaluate_file_export_verification`.
- `cad_equalizer_apo_export.py` — bounded renderer emitting only the importer-parseable subset (`Device`/`Channel`/`Preamp`/`Delay`/`Filter n:` PK·LSC·HSC·LPQ·HPQ·NO·BP·AP); `verify_exported_apo_config` round-trips the rendered text through the #808 importer and compares normalized semantics — including the `Channel: ALL` → global-preamp accumulation rule. Unsupported parameters raise `ApoExportUnsupportedError` listing every rejected item (HTDT never mirrors APO's silent-ignore).
- `cad_generic_dsp_export.py` — always-available fallbacks: `render_generic_peq_export` (portable parametric spec), `render_generic_biquad_export` (validated RBJ coefficients via the #679 `build_biquad_filter` convention, fail-closed outside it), `render_generic_fir_export` (tap lists + sample rate), `render_manual_settings_handoff` (operator entry sheet). Shared `ExportFilterBand` vocabulary reused by the APO renderer.
- `cad_delegated_provider_repository.py` — append-only `_SealedStore` × 3 tables: `cad_delegated_provider_manifests`, `cad_provider_acquisitions`, `cad_file_deployments` (seal re-verified on save, all bound columns re-verified on get, document_id on list).
