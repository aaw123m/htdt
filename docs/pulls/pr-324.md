## Summary

Round-6 specification-inconsistency audit (full findings in `docs/reviews/round6-spec.md`). Two verified drifts fixed:

- **F1 — the #496 display-unit feature was wired to nothing.** `IMPLEMENTATION_STATUS` declares `cad_display_units` the "one shared conversion policy" binding `display_input.length_unit`/`numeric_precision`, but it had zero production callers: `MetricSpinBox` re-implemented conversion with its own `UNIT_SCALES`/`UNIT_DECIMALS` (inch→SI divided by `1/0.0254` instead of the authority's exact `× 0.0254` — a few-ulp divergence from `display_to_si`; inch decimals 3 vs policy 2), and `SelectionInspector.set_display_units` was only invoked by tests — so the inspector always rendered metres even though the store default is `'mm'`. `MetricSpinBox` now derives `UNIT_SCALES`/`UNIT_DECIMALS` from `cad_display_units` and routes every conversion through `si_to_display`/`display_to_si`; new `bind_inspector_display_length_policy` applies `length_display_policy_from_preferences` at room-workspace construction and re-applies live via `ApplicationPreferenceStore.subscribe` (weakref'd inspector so a closed workspace can't poison unrelated preference commits).
- **F2 — five identity fingerprints bypassed the canonical JSON profile.** `authority_graph.semantic_fingerprint`, `help_registry.fingerprint`, and `project_lifecycle.ProjectDeletionPlan.fingerprint` used `json.dumps` with default separators and `ensure_ascii`; `cad_readiness_planner._action_id` lacked `ensure_ascii=False`; `cad_yamaha_rxa4a._packet_hash` lacked `allow_nan=False`. All are recompute-and-compare digests with no persisted literal values — now delegate to `canonical_sha256`.

Deferred with sketches in the review doc: polygon winding is never normalized while `wall:{from}->{to}` ids and `WallOpening.offset_m` are direction-dependent; `cad_units`' single `'db'` level family conflates SPL/dBFS/gain; the measure-tool readout (`format_measure_result`) doesn't follow the display policy.

Audited and verified consistent (no drift): azimuth/pitch angle convention, phase_deg vs phase_rad domain split, mesh-import unit declarations and axis handedness, `db_spl`/`level_semantics` discipline, Hz/kHz table conversions, scene-revision both-or-neither pinning, seat ear-height → 1.1 m convention, `schema` wire key pin.
