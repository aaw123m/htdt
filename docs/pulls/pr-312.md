## Summary

Closes #35

The import backend was complete and tested but unreachable from the UI — users had no way to run a geometry import. This PR adds the missing native wiring: a guided `GeometryImportDialog` (declaration → QA → repair preview → destination/readiness) plus two controller paths on `RoomWorkspaceController`, reachable from the View menu and the inspector mesh button.

What changed and why:

- `geometry_import_dialog.py` (new): one guided flow for both destinations. Unitless formats (OBJ/PLY/STL) start with no unit selected and `_accept()` refuses until the operator declares one — the "never assume units" contract from `make_mesh_import_authority`, now enforced in the UI. The repair section offers only deterministic (A) / bounded (B) operations, applies them as a *preview* (`make_raw_mesh_repair_plan` + `apply_raw_mesh_repair` + `diagnose_repaired_raw_mesh`), and the exact `RepairedRawMesh`/`RepairedRawMeshDiagnosticResult` pair travels with the `GeometryImportRequest` so conversion lineage stays pinned.
- `RoomWorkspaceController.attach_mesh_asset_declared(entity_id, path, *, source_unit, up_axis, …, repaired_mesh, oversize_decision)`: declared-authority sibling of the legacy `attach_mesh_asset`. Uses `import_entity_mesh_asset` (new optional `repaired_mesh=` substitutes previewed repair geometry while keeping original-bytes provenance) and `apply_mesh_import_decision`; the view catches `MeshImportCancelledError` and asks adopt/rescale/cancel instead of silently trusting the envelope.
- `RoomWorkspaceController.import_room_mesh_geometry(path, *, …, surface_assignments, repaired_mesh, repaired_diagnostic)`: converts to `SemanticAcousticGeometry` and commits `r120_semantic_geometry` as a single undoable `working.replace_document` step (`schema_version` bumped to ≥4), same mechanism as capture semantic promotion.
- `mesh_import_authority.mesh_import_scene_transform(authority, source_vertices)`: new — expresses the `normalize_source_vertices` pipeline as a 4×4 affine so the room path's `SemanticCoordinateTransform` (`provenance='explicit_import_metadata'`) provably matches what the entity path applies per-vertex.

UI reachability: View menu gets `ジオメトリをインポート…` (next to the underlay import section), and the inspector's `meshImportRequested` now opens the guided dialog with the selection as the entity-body destination instead of the blind legacy attach.
