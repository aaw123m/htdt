- `DimmingTemporalProfile` (dtp-) pins the exact lighting state; `TemporalLightWaveform` (tlw-) retains the raw waveform as canonical evidence; `LightingTLMObservation` (tlmo-) separates phenomenon from modulation source (`power_quality_induced` requires a #738 power-event ref); `LightingTLAAssessment` (tlaa-) binds metric→method→domain and refuses superseded `CIE 249:2022`, non-historical `IEEE 1789-2015`, out-of-domain SVM/Mp
