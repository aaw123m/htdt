## Summary

Restructures the 測定 → 比較 page into progressive disclosure, per #970:

- **Fixed basic-3-step strip**: `step_hint` （基本3手順： ① 比較目的 → ② A/B → ③ 判定/差分） plus renamed form rows (① 比較目的 / ② データセット A/B). A new `pair_summary_label` renders the selected pair's source, channel role, target, SceneRevision binding （両側一致/異なる）, `level_compatibility` verdict and registration state at a glance.
- **詳細条件 advanced block**: 除外帯域， 参照帯域 （レベル参照） and per-side 表示スムージング collapse into `comparison_details_block` built with the existing `_advanced_block` pattern (same shape as `optimization_workflow_workspace`). Defaults and semantics untouched; the toggle only calls `setVisible`, so open/close cannot alter selection/band/preview/saved evidence.
- **Nearest-resolvable-reason surfacing** (`_update_selection_reason`, run on every selection/band change): walks the canonical gates in order — missing registration → `ComparabilityVerdict` state → `registration_freshness` (stale/unverified) → pinned band-overlap rule (`overlap_low/high` mirroring `compare_frequency_responses`) → semantic advisories (`absolute_level`, `common_time_phase` unavailable → warning, not a block). Blocked pairs disable 保存 and set `comparison_state_label` to `比較不能（…）` / `stale（古い登録）`; `save_guidance_label` names the concrete next step (create registration, re-register, match band to the A∩B span, or pick another pair when ranges are truly disjoint).
- **State label vocabulary** synced to `プレビュー（未保存）` / `保存済み比較` / `stale` / `比較不能` with matching semantic states — chart displayability stays a separate axis from saveability.
- **Phase lane honesty**: `phase_compare_plot` stays visible; absent phase renders `位相は表示できません` + per-side grounds via `show_plot_state`, partial availability or missing common timing produces an explicit `phase_note_label` note （表示は参考値） — never a silent hidden lane.

Two `test_round8_measurement_journey` tests were red on `main` (they saved measured×predicted comparisons without the registration record the #564 gate already required) — updated to click 登録レコードを作成 first, now green.
