## Summary

`PersistedWindowState` already remembered window geometry, the last workspace and per-project context ids — but not the *inside* of each workspace: scroll positions, the selected measurement/comparison, active filters, collapsible panels and splitter ratios. Revisiting measurement/optimization meant re-finding where you were. This adds a bounded, project-local `WorkspaceViewState` map and wires capture/restore ports through the existing shell router — no navigation reimplementation.

Refs #973

**Schema** (`window_state.py`): `WorkspaceViewState` (frozen pydantic: `scroll_offset`, `selected_entity`, `filters`, `expanded_panels`, `splitter_ratio`, all bounded) stored in `PersistedWindowState.view_states` keyed `"workspace[:context]"`. Corrupt entries drop individually; unknown workspaces are pruned; a broken file still degrades to `None` → default view. Values are non-secret UI state only.

**Shell plumbing** (`workflow_shell.py`, `workflow_application.py`): `WorkspaceMount` gains optional `capture_view_state`/`restore_view_state` ports. `navigate()` captures under the outgoing (workspace, context) key and restores the incoming one; `select_context` does the same across context switches; same-destination re-clicks don't re-restore. `collect_view_states()` feeds the per-project save on close; `_switch_project` calls `reset_view_states()` so project A/B snapshots never mix. Deep links still win — `navigate_to_target` runs `focus_target`/`request_entity` *after* the restore.

**Workspace ports** (UX convenience only — never promotes stale results to current/accepted):

| workspace | captured |
|---|---|
| `MeasurementPageWorkspace` quality | verdict/state/channel/position/search filters, `measurement_id` (col-0 `UserRole`), quality splitter |
| — comparison | preset, dataset A/B seats, band/ref/excluded spins, smooth combos, history `comparison_id` (restored via `selectRow` → sealed record replay, still labelled 保存済み比較) |
| — campaign | plan id, run id (existence-checked via `runner_repository.get_run`), cell index |
| `OptimizationWorkflowWorkspace` | candidates filters + candidate ids + 7 `_advanced_block` panel states + splitter; comparison objectives + pareto `ROLE` selection; validation `ROLE` selection |
| `RoomWorkspace` | dock-page scroll, `view_state.selected_id`, `SelectionInspector` expanded sections, content splitter |

**Honesty invariants**: a vanished selection deselects + focuses the parent widget — no nearest-row guessing (quality shows the honest 「対象の測定…はありません」 note). Vetoed/dirty-state-canceled navigation never restores. Scroll restore is clamped and re-applied on idle so delayed refreshes can't lose it.

**Tests** (`test_view_state.py`, 16): model bounds/roundtrip, corrupt-entry and corrupt-file degradation, workspace round-trip, context-switch capture, deep-link-beats-restore ordering, seed pruning + project isolation, vetoed navigation, composition close→per-project save, and real quality-page round-trip / vanished-selection / index-reorder / delayed-refresh cases. `docs/issues/issue-973-view-state.md` documents the design.
