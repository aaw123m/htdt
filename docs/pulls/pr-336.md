## Summary

Round-9 review of the settings/preferences/persisted-session-state journey (`docs/reviews/round9-prefs.md` has the verdict table + full preference inventory map). 12 findings: 7 fixed here, 5 deferred with sketches.

**High — fixed:**
- **Window state is now per-project** (round-8 deferred item 12). `window_state.py` writes `window-state/<project_ref>.json`; load order is per-project → global legacy file → defaults. `PersistedWindowState.project_ref` makes records self-describing; `_safe_project_ref` restricts filenames to `[A-Za-z0-9._-]`. Per-project saves deliberately do *not* mirror to the global file — that would re-leak the last-touched layout into fresh projects. The round-8 blocker ("composition has no project ref at restore time") was stale: `project_entry` resolves before `_restore_window_state` runs.
- **Relocation was silently dropping real persisted artifacts.** `PERSISTED_DATA_REGISTRY` gained `window-state.json`, `window-state/`, `file_dialog_dirs.json`, `.native-upgrade-state.json` (the upgrade quarantine marker — previously silently deleted on relocate), `htdt-legacy-migration.journal`, `htdt.sqlite3`/`htdt.migrated.sqlite3`/`assets`/`htdt.migrated.assets`, `capture-receiver/` (sensitive, excluded from backups), and `launch-intents/` (transient, never copied). `_component_base_match` classifies numbered siblings like `htdt.migrated.sqlite3.3` by first path segment; `_numbered_siblings` carries them in the copy loop. The unclassified warning now covers foreign directories, not just files.

**Medium — fixed:**
- **`--safe-mode` now covers all persisted state.** `WorkflowApplication` binds `FileDialogMemoryStore.ephemeral()` (in-memory; no read or write of `file_dialog_dirs.json`), skips `_save_window_state` on close, and — via `resolve_startup_document(..., skip_last_opened=not policy.auto_open_last_project)` — skips the most-recent project (which is the crash-suspect since `open_project` stamps it) and opens the next-most-recent, or a fresh "My Home Theater" when the library has only the suspect.
- **Safe-mode composition order**: `self.safe_mode` is assigned before `file_dialog_memory.configure()` so the flag is authoritative when stores are bound.

**Deferred (product decisions, sketches in the review doc):** backup-policy UI for `AutomaticBackupPolicy.save_policy` (no consumer), a consumer or removal for the declarative `RESET_SCOPES`, theme/locale/REW pending keys (already disclosed 「準備中」), and a `startup_destination` preference.

Tests: `backend/tests/test_review_round9_prefs.py` (13 new), plus updated pinned contracts in `test_window_state.py`, `test_native_launch.py`, `test_native_diagnostics.py`, `test_persisted_data.py`. Full suite: 5606 passed locally (`pytest -q -n 4`); no GitHub Actions.
