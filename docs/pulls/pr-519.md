## Summary

REV42: second-pass adversarial review of the whole implementation (report: `docs/reviews/rev42-fullreview.md`). Fixed 5 clear defects found in the REW auto-ingest + measurement batch seams; judgment calls documented, not fixed.

**P1 — `scan_rew_watch_dir` never evicted `seen`.** Files deleted from the watch dir stayed in the `seen` map forever (unbounded growth across a long session). Now evicts keys absent from `observed` (except the `_SCANNED_SENTINEL` baseline marker); a re-dropped file is re-delivered since its entry was removed.

**P2 — `stage_rew_text_files` / `stage_rew_snapshots` left partial rows on mid-loop failure.** A parse/duplicate-name exception after some rows were staged left a half-populated batch plus a raw error notice. Both paths now roll back via `_unstage_batch_entries` before re-raising.

**P3 — REW auto retries were unbounded and notice dedupe was broken.** Fetch failures retried every poll forever; watch-file stage failures re-queued forever; and the stage-failure dedupe key was wiped by the quiet-tick `else` (`_rew_auto_notice_keys.clear()`) in the *same* apply pass → identical error notice every tick. Now: `_REW_AUTO_MAX_ATTEMPTS = 3` caps for fetch (`fetch_failed_uuids`, surfaced as 「N 件は繰り返し取得に失敗したためスキップしました」) and watch files (`watch_wedged:` once-only notice), plus `stage_failed_this_tick` flag so failure keys survive the quiet clear.

**P4 — staged (uncommitted) batch rows were invisible to the dirty-state contract.** `dirty_state`/`before_deactivate` only considered `pending_import` sources, so navigate/exit could strand or silently drop queue rows. New `_pending_batch_ids()` (`uncommitted_batch_item_ids() - _batch_released_ids`) feeds `pending_import`; `keep_draft` releases the token via `_batch_released_ids`, `discard_pending` calls `discard_batch_items`.

**P5 — no removal path for uncommitted batch rows.** Only `discard_batch_committed` existed; a parse-failed row was stuck in the queue forever. New `discard_batch_items(item_ids)` + 「選択項目を削除」 button on the batch card (`_discard_selected_batch_items`).
