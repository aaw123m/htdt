- CLI: `htdt drill list` + `htdt drill run` wired into the #888 dispatcher; mutating run requires `--arm` (otherwise `arm_required`, exit 4), `--dry-run` plans without injecting. `drill.run` added to `SEALED_VERBS` — each armed run seals a `CadHeadlessRunRecord` whose refs carry every authority record the drills emitted.
