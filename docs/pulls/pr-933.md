## Summary

Issue #892: adds a **versioned, redistribution-safe interoperability corpus** plus a **semantic round-trip regression harness** over HTDT's import/export lanes — `EXTERNAL FIXTURE → IMPORT → canonical HTDT state → EXPORT → RE-IMPORT → SEMANTIC COMPARE` where a bounded export path exists, and `IMPORT → canonical state → declared assertions` elsewhere. Comparison is semantic (geometry, channel/routing, filter parameters, measurement axes/units/references, warning/degradation sets) — never byte equality.

### Corpus (`interop_corpus_fixtures.py` + `cad_interop_corpus.py`)

All fixture bytes are **synthesized deterministically in-repo** — nothing third-party is vendored. The sealed `InteropCorpusManifest` (`icm-`, `corpus_version='1'`) pins each `InteropFixtureEntry` (`icf-`, `content_sha256` + `size_bytes`), which declares per fixture:

- provenance: `source_kind`, producer tool/version, licence id, redistribution state — `external_no_license` payloads must be `withheld`, never `redistributable` (validator-enforced);
- `format_family` + `format_version`, units/coordinate semantics;
- `expected_supported_features` / `expected_unsupported_features`;
- the **exact** `expected_warnings` / `expected_degradations` token sets;
- `assertions`: stable dotted paths + `equals`/`approx`/`set_equals`/`contains` comparators, so failures name the exact semantic assertion rather than only a parser exception;
- `round_trip_mode`: `round_trip` | `import_only` | `unsupported_assert`.

### Harness (`interop_corpus_harness.py`)

Verdict vocabulary per fixture run: `semantically_equal` / `degraded_as_declared` / `unsupported_as_declared` / `regression` / `unexpected_failure`; corpus run verdict `passed` / `regression_detected`. Fail-closed in **both** directions: an undeclared degradation and a declared degradation that stopped appearing are each a `regression`; `skipped_unverifiable` assertions never pass; a `qualified` verdict on a declared-unsupported fixture is invented support → `regression`.

Six lanes exercised in corpus v1:

| family | mode | lane |
|---|---|---|
| `rew_text` | `import_only` | `parse_rew_frequency_response` (axes/units/phase-absence) |
| `equalizer_apo` | `round_trip` | `build_equalizer_apo_artifact` → `render_equalizer_apo_config` → re-import → channel/preamp/delay/band compare |
| `camilladsp` | `import_only` | `build_camilladsp_artifact`; mixer stays `opaque:unsupported_command` |
| `clf` | `unsupported_assert` | `qualify_clf` → `unsupported`/`binary_cf1` (binary families unsupported by design, #905) |
| `ifc_step` | `round_trip` | `build_ifc_import` → `build_ifc_export_package` → re-import → room geometry/placement compare (metres) |
| `htdt_project_bundle` | `round_trip` | `export_project_bundle` → `import_project_bundle` → re-export; seq-independent per-table row-set compare; import-minted `htdt_project_documents` row declared via `roundtrip.new_tables` |

### Persistence + wiring (native schema **v111**)

- `CadInteropCorpusRepository` (`_SealedStore`): `cad_interop_fixture_runs` (`icr-`) + `cad_interop_corpus_runs` (`icx-`) — each run record pins the `manifest_sha256` it ran against, so evidence can never drift onto a different corpus revision. Store re-verifies seals on save, validates all declared columns on read, append-only on id+sha divergence.
- `_migrate_110_to_111` + baseline DDL + `NATIVE_SCHEMA_TABLES`; `_ROW_BINDINGS` for every column; `_RepositoryChain` branch `interop_corpus` + two `_ReplayProbe`s; JA lifecycle labels in `application_pages.py`; schema ledger row in `test_cad_schema.py`.
