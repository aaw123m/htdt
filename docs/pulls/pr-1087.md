## Summary

Reorganize the 形状編集 inspector around the current selection target and put every dangerous wall/opening edit behind an honest, uncommitted impact preview — CAD beginners can see *what* they are changing and *what it affects* before anything commits.

**Selection-target inspector** (`room_geometry_panel.py`)
- `selection_title`/`selection_context` header states 頂点/辺/壁/開口 (or なし) with the target ID, dimensions and dependency counts (開口 N 件 · クリアランス N 件 · 編集可/不可理由).
- The four edit hosts are wrapped in `InspectorSection`s; only the sections matching the selected target expand — unselected forms and their dangerous buttons stay collapsed.
- Every numeric field gets a caption with 単位 m · 有効範囲 · 依存値 (e.g. opening offset `有効: 0–len−width` recomputed per selection); out-of-range commits refuse before a preview is even armed (`commit_rejected` event).

**Pre-apply preview** (new `room_geometry_preview.py`)
- 頂点削除/壁結合/壁削除/壁厚変更/開口適用/開口削除 arm a `GeometryChangePreview` instead of committing: JA title + impact lines diffing lost/reassigned/moved openings **by ID**, affected constraint bindings, authoring-model issues; optimization/solver readiness renders 不明, never silenced.
- `preview_host` shows 「この内容で適用」(enabled only when `feasible`; infeasible previews list 実行できない理由) and 「変更を取り消す」 — visually distinct from 「編集終了」, whose tooltip now states it keeps committed changes.
- 適用 commits via `geometry.apply_geometry_candidate` inside `_run` → one `ReplaceRoomCommand` = **one Undo step**, zero intermediate history. 取り消し never touches the document.
- Stale fencing: previews bind `(working.source_revision_id, scene_content_hash(committed))`; `refresh()` drops moved previews and `_apply_pending_preview` rejects them → delayed results can never land on a different SceneRevision.
- `operation_events` records armed/applied/cancelled/stale/commit tuples for the #936 op-count measurement of 壁選択→開口編集→Undo.

**3D ↔ inspector selection** (`room_geometry_input.py`)
- `selected_opening_id` + `select_opening()` (resolves parent wall edge); opening-outline hit-test (≤10 px, 0.5 bias) makes a 3D click on an opening select the *opening* — inspector jumps to 選択: 開口 — while `opening_selector` changes re-highlight the same opening in 3D (`#E8A33D`).

**Esc chain** (`room_workspace.cancel_active_operation`)
- Order: underlay → measure → transform → **armed preview** → geometry edit → working preview → selection clear. The dock-wrapped inner panel is resolved via `findChild("roomGeometryPanel")`; the panel claims Esc through a ShortcutOverride/KeyPress `eventFilter` (no shortcut ambiguity) and forwards unconsumed Esc to the workspace chain — field-focus Esc behaves identically to canvas Esc.
