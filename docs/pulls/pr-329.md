## Summary

Round-8 product review of the **measurement→comparison→report data journey** (REW import → quality → comparison → export/report). Full findings live in `docs/reviews/round8-journey.md`; this PR implements the four safe fixes plus a label-map gap, with regression tests, and defers the rest with sketches.

**HIGH (deferred):** the quality-report leg is severed — `build_measurement_quality_report`/`save_report`/`save_observation`/`save_dataset_level_reference` have zero production callers, so the quality page can never show a current report, campaign cells can never leave `quality_pending`, and `absolute_level_comparable` comparisons are unreachable. Fixing it needs an evidence-capture feature (REW preflight metadata + operator-attested `CadMeasurementQualityEvidence`), not a patch — sketched in the doc.

Fixes implemented:

- **J2 — saved-comparison reload** (`measurement_page_workspace.py`): selecting a history row now re-seats the A/B selectors on the persisted pair (with `any`-preset fallback, and a designed "not in current candidates" state when a side left eligibility) and `_show_comparison` renders the persisted `label_a`/`label_b`, `level_compatibility` verdict and stored mismatch warnings — previously only the metric scalars were shown over an unrelated live preview.
- **J3 — analysis export verdict** (`analysis_export.py`, `workflow_application.py`): `comparison_metadata_entries()` ships `comparison.<id>.{mean_difference_db, rms_difference_db, level_offset_db, shape_rms_db, band spec, labels, level_compatibility, valid_points…}` in the bundle metadata; `_export_analysis_bundle` records `omitted.measurement.<id>`/`omitted.comparisons` entries instead of silently skipping failed authoritative reads, and refuses to write an empty export.
- **J4 — corrupt-row isolation** (`measurement_workflow.py`, `measurement_page_workspace.py`): `measurement_views()` wraps `dataset_for_measurement` per row — one row failing seal/hash/raw-asset re-verification now degrades to a visible `dataset_error` row (`dataset_id=None`, stays fail-closed) instead of an unhandled `ValueError` bricking every listing; `saved_comparisons()` failure degrades to an empty history + error notice.
- **J5 — single-file duplicate signal** (`measurement_workflow.py`, `measurement_page_workspace.py`): `PendingMeasurementImport` carries the batch lane's `_classify_duplicate` result (`exact_duplicate`/`same_acquisition`), preserved across `select_pending_revision`; the import card shows the warning and commit asks for confirmation. Advisory only — explicit re-import stays possible.
- **J6:** `_mismatch_label` covers all 11 advisory codes (previously 5 fell back to raw snake_case).
