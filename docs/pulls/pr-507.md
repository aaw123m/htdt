## Summary

REV38-R150D: completes the decay-law provenance lanes declared by `LateDecayProvenance` and wires the `late_energy_decay` observable end-to-end so `build_hybrid_acoustic_result` can consume decay artifacts for real.

**Producers** (`cad_hybrid_late_energy.py`): `declared_late_decay_law` and `measured_late_decay_law` build `LateEnergyDecayLaw`s with `provenance='declared_model'`/`'measured'` pinned per band (the third lane, `analytic_estimate`, shipped in #506 as `late_decay_estimate_decay_law`). `measured` requires an exact `evidence_ref` binding — an unevidenced measured claim is a fabricated measurement and fails closed.

**Consumption** (`cad_hybrid_late_energy.py`): `build_late_energy_decay_result_envelope` binds a `SUPPORTED` `LateEnergyDecayArtifact` to its exact READY dispatch as a solver result — the missing link every sibling lane already had. `UNSUPPORTED` artifacts are rejected rather than promoted. Execution identity is derived deterministically (`r160-late-energy-decay-execution:{artifact_sha}` + a hashed provenance payload over the exact input refs) because the solve is a pure composition — there is no run record to fabricate. `R160_LATE_ENERGY_DECAY_{SOLVER_ROLE,ADAPTER_ID,SOLVER_IMPLEMENTATION_REF}` declare the lane's adapter-facing identity.

**Snapshot contract** (`cad_acoustic_snapshot.py`): `late_energy_decay` and `late_decay_estimate` are registered as GA-domain observables in `_observable_readiness` — full GA gates (including environment + frequency-domain coverage, which `deterministic_paths` waives) minus the wave-side screen-transfer gate. Previously they were always `UNSUPPORTED`, so no request for them could dispatch READY and no decay artifact could ever reach an envelope.

## Regression tests

`test_cad_late_energy_decay_consumption.py` (12 tests) runs the whole chain on the real GA fixture + real `execute_deterministic_ga` output: snapshot declares `late_energy_decay` READY → READY dispatch → producers → `solve_late_energy_decay` → envelope → `build_hybrid_acoustic_result` promotes `LateEnergyDecay(AVAILABLE)` with the canonical `R160_LATE_ENERGY_ARTIFACT_SCHEMA_REF` encoding. Fail-closed coverage: unevidenced `measured` law, observable-set mismatch on the deterministic request/dispatch, `UNSUPPORTED` artifact binding. `_fixture` gains `extra_requested_observables` for declaring additional snapshot observables.
