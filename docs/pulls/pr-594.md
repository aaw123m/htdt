## Summary

Implements issue #568: a cross-cutting **qualification evidence contract** deciding when a generated or imported correction filter may be called *qualified* for a specific system and listening region. Not a new inverse-filter algorithm and not a new DSP transport.

**New authority** `backend/src/htdt/cad_correction_qualification.py`:

- `CorrectionQualificationRecord` — self-sealed immutable record (`correction-qualification:<sha256>`) binding filter identity (`subject_id` + semantic sha for `calibration_plan` or `fir_artifact`), target curve, declared `ListeningRegion` (mechanically partitioned `design`/`holdout`/`repeatability`), regularization, and `ConstraintDeclaration` (max boost/cut, usable band, headroom, pre-ringing, latency — undeclared = unknown, never unlimited).
- `evaluate_correction_qualification()` runs **8 fail-closed gates**: `identity` (UNSUPPORTED plans fail), `boost_cut` (declared caps + device capability + EQP10 `SpatialCorrectionEvidence` per-band envelopes — local-null over-boost rejected), `usable_band`, `headroom`, `pre_ringing` (FIR pre-echo energy + latency; PEQ passes, unknown topology not_evaluated), `control_fidelity` (physical regression at design points fails), `holdout_independence` (declared holdout must be physically re-measured; zero/partial coverage is limitation, regression fails), `closed_loop_deployment` (observed mismatch fails).
- Two-axis honesty model: `state` = evidence ladder (`INSUFFICIENT_EVIDENCE`→`DESIGN_ONLY`→`SIMULATED`→`MEASURED_AT_CONTROL_POINTS`→`SPATIALLY_HOLDOUT_VERIFIED`→`DEPLOYED_AND_REMEASURED`, plus `QUALIFIED_WITH_LIMITATIONS`/`INCOMPATIBLE`); `scope` = permitted claim (`unqualified`/`candidate`/`qualified_point`/`qualified_region`). The record validator recomputes `expected_scope_for`, so a stored record cannot overclaim its gates. `qualified_region` mechanically requires the holdout gate to pass with every declared holdout physically covered.
- Repeatability positions (design∩repeatability allowed — same-seat re-measurement) are stability evidence only and can never satisfy holdout. Subjective evidence is recorded but never opens a gate. #564 registrations are bound via `RegistrationEvidence` (partition + sealed `ComparabilityState`); incomparable → disqualifier.
- 12 independent observables (target_deviation, seat_to_seat_variance, group_delay, pre_ringing, latency, peak_boost, headroom_margin, capability_margin, before_after_measurement, deployed_state_match, repeatability, worst_seat_deviation) — qualification is not a single bool.

**Persistence & wiring:** `cad_correction_qualifications` table (native schema v21, migration replays baseline DDL), append-only `CadCorrectionQualificationRepository` with `current_for_correction` exact-sha staleness (material filter/device/routing change invalidates the record automatically), `native_row_integrity` bindings, audit `_ReplayProbe`, lifecycle label 「補正修飾レコード」. Minimal UI: calibration-export plan rows show `修飾状態: <JA label>` (stale-sha records render as 未修飾).

**Literature basis:** Kirkeby & Nelson 1999 (JAES 47(7/8)) — frequency-dependent regularization, deep-notch inversion demands unbounded boost (band-level boost caps); Cecchi et al. 2018 (Applied Sciences 8(1),16) — single-point EQ spatial fragility (design/holdout separation, qualified_point vs qualified_region), mixed-phase pre-ringing (pre_ringing gate/observable), out-of-band correction nonlinearity/damage risk (usable_band + headroom); Stefanakis/Sarris/Jacobsen multi-point regularization — evaluation at positions independent of the control set. No invented safety constants: all limits come from explicit `ConstraintDeclaration`/policy/device manifests.
