## Summary

REV44-SURFACES — fixes `docs/reviews/rev43-producers.md` findings 5+6: two production features whose writers/readers existed but were permanently unreachable in the app.

**Finding 5 — prediction matrices.** `create_matrix`/`run_matrix`/`save_provider` were dead: `RoomPredictionController` was constructed without `provider_repository`, so the 行列 UI could only ever show 「行列なし」.

- New `cad_prediction_registration.py` `PredictionAuthorityLane`: resolves the persisted solver stack (snapshot / dispatch / result envelope / artifact authorities via `ExactJsonAuthorityStore`) and registers eligible results through the real `CadPredictionProviderRepository`. Anything unresolvable fails closed — the lane never mints authority it can't justify.
- New `prediction_matrix_dialog.py` + 「行列・プロバイダー管理…」 on `RoomPredictionPanel`: list registrable solver results → register → plan + create a matrix (new `PredictionMatrixService.creation_plan` derives inputs honestly, JA problem strings on failure) → run the latest spec. A matrix with no runs shows 未実行.
- `workflow_application._make_room` wires `provider_repository` + the lane; the R130A lane now persists the `AcousticNumericalFidelityPolicy` model fields so its rows become app-registrable.

**Finding 6 — manual attestations.** `build_applicability_attestation`/`save_attestation` were dead while 手動 mode demands a 登録済み証明 ID no path could mint.

- 「証明…」 per campaign applicability row opens `ApplicabilityAttestationDialog`: register (証明者 + 判定 + required 証拠の参照/内容 — model rejects unbound evidence) or pick an existing attestation scoped to the campaign's pinned spec. Selection fills 経路根拠 with the persisted id and switches the row to 手動証拠.
