REV47-ISS2: implements the genuinely-missing software slices of the issue #2 (arbitrary-room acoustics) phenomenon-specific acceptance contract from the issue #131 backlog comment. Audit first, then only real gaps — the hop-by-hop provenance and dispatch-level capability plumbing already existed; what was missing was the single auditable record naming the chain, a declared phenomenon-level capability manifest, committed fixture classes for occlusion/edge + scattering, and dedicated transition continuity/energy assertions.

### What was added

- `cad_acoustic_geometry_derivation.py` — `AcousticGeometryDerivation`: a frozen, `semantic_sha256`/id-hash-bound record binding every hop exactly (scene revision + content hash, input mesh/diagnostic ids+hashes, semantic geometry, conversion request, compile request, compiled geometry + hashes, topology identity, compiler id/version). `category_decisions` declares 5 categories exactly once; `merged_faces`/`edge_diffraction_treatment`/`scattering_substitution` are validator-forced `NOT_APPLIED` — mechanisms that do not exist cannot be declared or silenced into absence.
- `cad_solver_capability_manifest.py` — `SolverCapabilityManifest` bound to a persisted `AcousticSolverAdapterDescriptor`; rows must cover all 9 `SolverPathPhenomenon` values, `UNSUPPORTED` requires reasons and forbids a band, `SUPPORTED`/`BOUNDED` require a band ⊆ the adapter's `valid_frequency_domain` (`BOUNDED` also requires `bound_description`).
- Native schema v16: `cad_acoustic_geometry_derivations` + `cad_solver_capability_manifests` append-only tables + indexes; repository `save_`/`get_` methods re-validate against retained authorities (canonical compiled geometry, persisted descriptor).
- `benchmarks/acoustics/r100a_manifest.json` → schema `r100a-5`/revision 5 (bound 1:1 to `schema_version`), 12 fixtures: +`geometric-occlusion-edge-v1` (blocked-path integrity + edge-diffraction honesty observables) and +`geometric-scattering-redistribution-v1` (energy presence + seed repeatability).
- Tests: `test_acoustic_geometry_derivation.py` (11), `test_solver_capability_manifest.py` (8), `test_rev47_iss2_acceptance.py` (5) binding the fixture contracts to executable invariants, +4 dedicated transition tests appended to `test_cad_hybrid_numerical_composition.py` (pure-contributor edges, convex energy bound, stored transition authority, no double-count with differing signals).
- `issue_verification_manifest.yaml`: three new pytest checks under issue #2.

Fail-closed throughout: no fabricated capability claims; `UNSUPPORTED` is a typed state, never a success.
