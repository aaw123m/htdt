## Summary

First-run guided wizard (#886) — one canonical path from empty install to report, always derived, never a gate.

- `first_run_wizard_state.py`: pure `derive_wizard_progress(facts)` over a `FirstRunWizardFacts` snapshot assembled from sealed authorities (Overview readiness golden-path steps, `CadCalibrationWizardRepository` + `derive_wizard_state`, `CadChannelVerificationRepository.list_verdicts` `map_state == 'verified'`, `CadCommissioningOrchestratorRepository` + `derive_run_state` furthest ≥ `readback_verify`, `WasapiAudioBackend.available()`). Six stages: project/room → system definition → measurement readiness → baseline → optimization/deploy → completion. Invariants: exactly one `current`; every `blocked` carries an explicit JA reason; a blocked stage claims the resume slot so downstream stages can't claim current.
- `first_run_wizard_store.py`: file-backed `FirstRunWizardRecord` (active/dismissed/completed + last_shown_stage). **Not authority** — records only display intent; a corrupt file returns `None` (fail-open to showing the wizard), progress always re-derives.
- `first_run_wizard.py`: `FirstRunWizardDialog` — JA stage rail (✓/●/○/⛔) + per-stage detail/reason/action; each action is a `WorkspaceDeepLink` (`ROOM/geometry`, `ROOM/placement`, `MEASUREMENT/calibration_wizard`, `MEASUREMENT/acquisition`, `OPTIMIZATION/interventions`, `PRESENTATION`) driven through the shell's existing deeplink navigation. `あとでやる` sets `dismissed` (stops auto-show; menu reopen always works).
- `workflow_application`: `_first_run_facts()` assembles the snapshot (equipment gaps counted from readiness `equipment.binding_missing` notices); `_maybe_show_first_run_wizard` auto-opens only when the record is absent/`active` and progress is incomplete; `_save_wizard_record` on close. Menu: プロジェクト → 初回セットアップウィザード…(&W).
- `native_cad`: `application.enable_first_run_wizard_autoshow()` in `_run_gui` after the window is shown — the only enable point, so test-booted compositions and Safe Mode never auto-open a modal.

No parallel data model (issue's explicit non-goal): the wizard launches the existing authoritative surfaces via deeplinks; it cannot mark anything complete that authority hasn't recorded.
