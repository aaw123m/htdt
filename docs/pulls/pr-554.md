**Defects fixed (all with regression tests in `test_rev50_second.py`):**

- **Phantom journal revision on dropped check results** — REV49 added a drop guard in `_on_check_result` (non-pending step / unknown step_id) but the handler still called `repository.commit(latest, steps)` afterwards, so every dropped result wrote a no-op revision with a bumped `run_rev` and hash chain. Extracted the fold into `_apply_check_result(...) -> list | None`; commit now runs only when a step actually changed.
- **Persistence probe crashed on non-dict JSON marker** — a probe asset that parsed as JSON but wasn't an object hit `marker.get(...)` → `AttributeError`, surfaced by the fail-closed wrapper as a cryptic `unavailable`. Non-dict markers now take the same "re-issue" path as unparseable content.
- **Radius baseline stored display units** — `_baseline['radius']` held `radius_field.value()` while the commit path uses `value_m()`. `set_display_units` re-baselines the Vector3Editors but not radius, so switching mm→inch left a phantom dirty flag that committed a spurious `body_geometry` rewrite. All three sites now compare in SI.
- **`probe_x` missing accessibleName** — the only probe-axis spin without one (Y/Z got them in REV36).
- **`derived_yaw_steps(0)` ZeroDivisionError** — guarded to `ValueError` (session flow already validates `ge=1`; this covers direct API use).
